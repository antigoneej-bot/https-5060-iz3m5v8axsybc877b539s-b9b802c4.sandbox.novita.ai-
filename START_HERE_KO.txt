마음냥 정원 × 달려라 몽이 — 최신 통합 Flutter 소스

포함: 최신 디자인, 정원/게임/답장 기능, 직접 녹음한 명상과 배경 오디오, 영상, 이미지, 폰트, Android/iOS 프로젝트 및 테스트.

사용 방법
1. 압축을 풀고 maeumnyang-mongi 폴더를 VS Code 또는 Android Studio에서 엽니다.
2. Flutter SDK와 전체 JDK 17(자바 컴파일러 포함), Android SDK를 준비합니다.
3. flutter pub get
4. flutter run 또는 flutter build apk --debug --target-platform android-arm64

Android 테스트 빌드는 '마음냥 정원 테스트'(com.mysticcat.journal.preview)로 별도 설치되도록 구성했습니다.
기존 앱의 기록과 별도로 저장됩니다. 정식 배포용 서명키는 포함하지 않았습니다.

이 ZIP은 개발 소스입니다. 최신 웹 프리뷰 디자인은 검증했으나 이번 Android APK 빌드는 완료하지 못했습니다.
새 환경에서는 Android 플러그인 호환성 및 실제 기기 동작을 추가 확인해야 합니다.
구독 가격은 이번 디자인 수정에서 변경하지 않았으며, 실제 결제와 서버 연동은 별도 검증이 필요합니다.
