현재 상태
1차 보완 소스(work77_refine)를 기반으로 2차 기능을 추가했습니다.
설치용 APK/AAB가 아닌 전체 소스입니다. 버전 코드 77과 플랫폼/서명/잠금파일을 유지했습니다.
Flutter SDK가 없어 이번 소스의 flutter analyze/test, 실제 화면 실행, APK/AAB 빌드는 하지 못했습니다.
review/의 기존 77번 성공 로그와 그림은 이번 변경의 검증 근거가 아닙니다.
refinement-review/는 1차, phase2-review/는 이번 2차 구조·문법 확인 결과입니다.

2차 사용 방법
1. 방석 교감
   가꾸는 정원에서 배치된 고양이 방석을 누르면 선택된 고양이가 장애물을 우회해 방석으로 가서 쉽니다.
   고양이나 방석을 다시 누르면 일어납니다. 편집/물주기/심기 모드에서는 해당 작업이 우선합니다.
   움직임 줄이기에서는 이동 애니메이션 없이 쉬며, 방석 이동/보관 시 오래된 방석 위치 상태를 해제합니다.
   6종 고양이 외형, 기존 교감/성장/보상은 유지합니다. 방석 동작은 보상을 지급하지 않습니다.
2. 색칠 작품 전시
   색칠하기에서 완성본 저장 → 작품함 → 정원에 전시 → 확인.
   저장된 완성본의 작은 PNG 사본을 내 정원의 고정 액자로 전시합니다. 자동 공개하지 않습니다.
   새 전시는 기존 액자를 교체하고 원본 색칠 데이터는 보존합니다.
   정원 사진첩에서 ‘전시 내리기’. 이웃/읽기 전용 정원에는 개인 액자를 그리지 않습니다.
3. 감정 카드
   나의 마음 보관함 상단 돋보기: 원문 내용·감정 이름·날짜 검색. 검색 시작 시 카드/전체 기간으로 이동.
   상단 하트: 간직한 카드만 보기. 카드 상세의 간직하기/해제로 저장합니다.
   원문은 복제하지 않고 안정된 저장 ID만 보관합니다. 삭제된 기록은 검색과 간직한 목록에 나타나지 않습니다.
   저장 ID가 없는 옛 형식은 간직하기를 막아 다른 기록에 잘못 연결되지 않게 했습니다.
   편지 기반 카드의 ‘나무에 연결’은 기존 식물 기억 연결을 재사용합니다. 300자를 넘으면 원문 일부를 고릅니다.
   정원 일지 카드는 ‘기억의 나무 열기’ 진입점만 제공합니다. 정원 일지 원문의 직접 연결은 이번 범위에서 구현하지 않았습니다.
4. 정원 사진첩
   가꾸는 정원 우측 카메라 → 현재 화면 저장. 옆 사진첩에서 확대·내보내기·사진 삭제·전시 관리를 합니다.
   자동 촬영 없이 직접 눌러 저장합니다. 최대 8장, 이미지당 180KB 이하의 작은 PNG로 보관합니다.
   가득 차면 새 저장을 막고 안내하며 기존 사진을 자동 삭제하지 않습니다.
   카메라/사진첩 버튼은 촬영 영역 밖에 둡니다. 사진 대상은 현재 가꾸는 정원 화면이며 쉬어가는 정원 촬영은 이번에 추가하지 않았습니다.

저장과 백업
새 개인 보관함은 기존 AES 암호화 Hive 저장소와 private record transaction을 사용하며 계정별로 분리합니다.
사진/전시/간직한 ID는 garden_personal_gallery_local_user 박스에 저장하고 기존 백업 목록에 포함했습니다.
기존 백업의 ‘현재 기록 우선’ 복원 규칙을 유지합니다. 같은 계정의 보관함이 이미 있으면 그 보관함 전체가 우선하며
백업의 사진과 간직하기를 항목별로 병합하는 기능은 추가하지 않았습니다. 빈 보관함 복원은 테스트 항목에 포함했습니다.
기존 백업 전체 용량 제한은 유지됩니다. 기록과 사진이 많아 한도를 넘으면 사진 내보내기/삭제 후 다시 백업해야 합니다.
서버 공개 정원 스키마, 로그인/결제/광고 설정, 재화, 원본 에셋과 서명 설정은 변경하지 않았습니다.
