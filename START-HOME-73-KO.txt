마음냥 정원 1.0.70+73 — 선택한 동반묘가 반겨주는 홈

72번 검증본의 APK·AAB·전체 소스 ZIP을 별도로 보존한 뒤 작업했습니다.
이번 수정은 홈의 환영 경험에 집중합니다. 기존 4페이지 이동과 실제 정원은 유지합니다.

고양이와 이름
- 동반묘 선택은 기존 CompanionJourneyStore의 <owner>_companion_journey_v1에서 읽습니다.
  이름은 기존 StorageService.getCompanionName / CatCareProvider.companionName을 사용합니다.
  저장 키·소유자·형식을 바꾸지 않았습니다. 감정 고양이 ID로 동반묘를 고르지 않습니다.
- 고양이 6종은 기존 companion_motion_<coat>.webp 및 companion_motion.json 그대로입니다.
  기존 CompanionPresence → GardenCatArt → CompanionCoatArt → CompanionMotionArt를 재사용합니다.
- 열린 눈·반감긴 눈·감은 눈·미소 프레임과 기존 꼬리 메쉬 동작을 사용합니다.
  얼굴이나 이미지 전체를 흔들거나 늘여 눈 깜박임을 흉내 내지 않습니다.
- 독립적인 귀 움직임이나 새로운 흉부 호흡 동작을 만들지 않았습니다.
  기존 자동 동작 해제, 움직임 줄이기 설정을 존중합니다.
- 선택이 없는 레거시 상태는 기존 렌더러의 기본 표시 정책을 재사용하며 새 선택을 저장하지 않습니다.
  불러오기 실패를 새 고양이 선택으로 덮어 해결하지 않습니다.

홈 구성
- 이름·짧은 인사·큰 고양이 → 오늘 하루 질문·기존 감정 선택 → 마음 기록하기 → 우리 정원 둘러보기.
- 큰 글자에서는 고양이를 먼저 보여 얼굴이 긴 이름 아래로 밀려나지 않게 배치합니다.
- 고양이를 누르면 기존 교감·돌봄 화면을 엽니다. 방문과 애니메이션만으로 기록을 만들지 않습니다.
- 감정 선택은 기존 5개 진입 묶음이며, 실제 감정 고양이 37종과 기록 형식은 그대로입니다.
- 처음 만남 안내는 얼굴 위 배너 대신 하단 내용에 배치합니다.

유지한 것
- 실제 2.5D 정원과 심기·물주기·내 식물·위치 찾기·장식·확장·낮밤 표현.
- 씨앗·식물·성장·좌표·돌봄·편지·감정·백업·구독·로그인 데이터 및 서버 설정.
- 72번의 정원 공통 진입, 암호화 파일 보존, 색칠 저장 순서 및 Windows/LF 보완.
- 내부 테스트 기능 개방. 정식 출시·프리미엄 테스트 해제·서버 배포·Play 업로드 없음.

그림 자산
새 그림은 고양이가 없는 방 배경 home-room.png이며 홈에만 사용합니다.
기존 정원이나 고양이를 새 그림으로 바꾸지 않았습니다.
준비했던 selfcare-tea.png는 미사용 참고 자산으로 소스에 보존하며 앱 번들에 넣지 않습니다.
빌트인 image_gen의 프롬프트·출처: assets/storybook_ui_v2/PROMPTS.json.

검증 읽기
최종 실행 결과·남은 제한·파일 SHA-256은 review/검증 보고서와 JSON에 있습니다.
6종 화면과 영상은 실제 Flutter 위젯·기존 애니메이션 컨트롤러를 가상 시간으로 실행해 생성했습니다.
가상 로컬 테스트 데이터이며 Android 휴대폰 녹화가 아닙니다.
실기기 설치·업데이트 후 사용자 기록 보존, 실제 클라우드·결제·알림·iOS는 별도 확인이 필요합니다.

서명·복구
기존 업로드 키와 패키지를 사용합니다. 키·비밀번호·key.properties는 ZIP에 넣지 않습니다.
휴대폰의 설치본 서명을 확인하기 전 앱을 삭제하거나 서명 불일치를 삭제로 해결하지 않습니다.
복구는 보존한 72번 소스를 현재 최대 버전 코드보다 높은 코드로 다시 빌드하는 방식으로 준비합니다.
