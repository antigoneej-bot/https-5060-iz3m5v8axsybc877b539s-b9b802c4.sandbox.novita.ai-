1. 처리하는 정보와 이용 목적

감정 기록·편지·고양이·정원
선택한 감정, 마음 온도, 편지와 초안, 저장된 예전 답장, 돌봄·명상·방문·성장 기록, 나무의 기억, 기념일, 고양이 이름, 장식과 아이템, 산책 보상, 기록집에 선택한 문장을 기기에 저장합니다. 자기돌봄 기록과 정원 기능을 제공하는 데 사용합니다. 새 AI 자동 답장을 생성하거나 일기를 외부 생성형 AI에 보내지 않습니다.
로그인
Firebase Authentication의 계정 식별자를 사용합니다. 구글 로그인 시 이름·이메일·프로필 정보가 인증에 사용될 수 있습니다. 카카오·네이버·페이스북 로그인은 선택한 제공사의 계정 ID를 서버에서 확인하고 해시 처리한 연결 식별자, 연결된 Firebase 계정 식별자와 연결 세대 정보를 저장합니다. 이 세 방식은 이메일·친구 목록·게시물·일기를 요청하지 않도록 구현되어 있습니다.
선택한 백업
파일 백업은 사용자가 고른 위치에, 서버 백업은 로그인한 사용자의 서버 저장 공간에 암호화한 기록을 보관합니다. 백업 암호는 서버에 보내지 않습니다. 자동 백업을 켜면 기기의 보안 저장소에 암호를 보관합니다.
Google Play 구독
계정 식별자, 구매 토큰, 상품과 구독 상태를 구매 검증·권한 제공·구매 복원에 사용합니다. 카드번호는 앱이 직접 수집·저장하지 않습니다.
이웃·공동 나무·카드 교류
닉네임, 계정 식별자, 초대 코드, 공개 범위, 이웃·차단 관계, 공개 정원 모습, 응원·선물·교환·초대 기록을 기능 제공에 사용합니다. 공동 나무의 이름·기념일·물주기·공동 메모·확인 상태는 참여자 간 공유에 사용합니다.
신고와 운영
신고자·대상 계정, 사유, 공유 메모의 참조 정보, 처리 상태·담당자·시각, 이용 동의 버전과 시각을 운영과 악용 방지에 사용합니다. 개인 편지 본문은 신고 정보에 포함하지 않습니다.
알림·예약
알림을 켜면 Firebase Cloud Messaging의 기기 토큰, 계정 식별자와 알림 선택을 저장합니다. 알림에 개인 편지·감정 내용을 넣지 않습니다. 클래스 신청 시 계정 식별자, 일정, 신청·취소 상태와 신청 메모를 운영자가 확인합니다.
선택적 사용 통계
사용 통계 공유를 켠 경우 Firebase Analytics에 제한된 기능 이용 이벤트를 전송합니다. 일기 본문과 선택한 감정은 보내지 않습니다. SDK는 앱 인스턴스 식별자, 기기·앱 정보를 처리할 수 있어 완전히 익명인 통계라고 보장하지 않습니다.
선택적 오류 보고 (Firebase Crashlytics)
오류 보고 공유는 기본으로 꺼져 있으며 사용 통계 공유와 별도로 선택합니다. 기록 보관과 백업에서 켜면 Firebase Crashlytics에 오류 유형·호출 위치, 앱·운영체제·기기 및 설치 진단 정보와 제한된 연결 소요 시간을 보내 안정성 개선에 사용합니다. 앱은 편지·감정 원문, 선택한 감정 ID, 이메일·계정 식별자와 인증 정보를 보고서에 직접 첨부하지 않습니다. 사용 통계에도 동의하면 이용 이벤트가 오류 분석에 포함될 수 있습니다.

언제든 오류 보고 공유를 끌 수 있습니다. 끄면 앱의 새 오류 전송을 중단하고 SDK 수집 중지와 미전송 보고서 삭제를 시도합니다. SDK 적용 실패는 안내하며 앱을 다시 실행하면 저장된 끄기 설정을 다시 적용합니다. 이미 전송된 보고서가 즉시 삭제된다는 의미는 아닙니다. 수집을 새로 켜기 전에는 미전송 보고서 정리를 먼저 시도하고 정리에 실패하면 켜지 않습니다. Google의 진단 처리·보관 및 국외 처리에 관한 문의는 운영자에게 요청할 수 있습니다.
광고
광고가 연결된 Android 버전의 무료 이용자에게 Google AdMob 배너가 표시될 수 있습니다. 앱은 비맞춤 광고를 요청하며 일기·감정·마음 점수·추억·친구 코드·로그인 계정을 광고 타기팅 항목으로 전달하지 않습니다. SDK는 광고 제공·측정·부정 이용 방지를 위해 IP, 기기 식별자, 광고 상호작용과 진단 정보를 처리할 수 있습니다. 구독·구독 무료체험 기간과 편지·산책·명상 화면에는 배너를 표시하지 않습니다.

2. 이웃과 공유되는 범위

정원은 나만 보기·이웃에게 공개·모두에게 공개 중 선택합니다. 둘러보기 목록에는 모두에게 공개하고 목록 노출에도 동의한 정원만 표시합니다. 공개 모습에는 씨앗 수, 장식, 나무 성장 단계와 배치 등이 포함되며 개인 편지·감정 통계·개인 기록 날짜는 포함하지 않습니다.

초대 코드를 가진 사람은 닉네임을 확인하고 이웃 신청을 보낼 수 있습니다. 응원·선물의 수신자는 보낸 닉네임, 문구·이모티콘·꽃 종류와 날짜 등을 볼 수 있습니다. 공동 나무의 이름·기념일·공동 메모는 초대를 수락한 참여자에게 공유됩니다.

기록집 또는 파일을 외부로 공유하면 이용자가 선택한 내용이 해당 대상에 전달됩니다. 외부 클래스 제공자에게 별도로 정보를 전달하는 경우 해당 안내를 확인한 뒤 선택해 주세요.

3. 보관기간·삭제·복원

구분현재 보관·삭제 방식
기기 기록직접 삭제하거나 앱 데이터를 삭제할 때까지 보관합니다. 로그아웃은 기기 기록 삭제가 아닙니다. 편지 삭제 시 연결된 마무리 기록·식물 기억·기록집 문장도 삭제하지만 성장과 중복 성장 방지를 위한 날짜는 남습니다.
서버 백업최근 10개를 보관하며 계정 삭제 절차에서 서버 백업을 삭제합니다. 구독 종료만으로 백업을 삭제하지 않으며 기존 백업 복원이 가능합니다. 개별 기록을 지워도 과거 백업에는 사본이 남을 수 있습니다.
이웃·예약·신고각 기능의 삭제 또는 계정 삭제 절차에서 정리합니다. 계정 삭제는 공동 나무와 공동 메모, 공개 정원, 예약, 관련 신고·응원 전송 기록, 알림 기기 연결 등을 정리합니다. 상대에게 이미 전달한 응원은 발신자 ID·닉네임을 제거하고 수신 기록이 남을 수 있습니다. 24시간 효과 종료는 수신 기록 삭제를 의미하지 않습니다.
삭제·부정 이용 방지 표식구매 원문 토큰과 UID를 제거한 구매 토큰 해시 표식, 계정 해시 기반 삭제 상태, 소셜 로그인 연결 식별자·연결 UID·세대 정보가 남습니다. 삭제 중 재생성과 기존 구매 재연결 방지에 사용합니다. 현재 코드에는 이 표식들의 자동 만료기간이 없습니다. 정식 운영 보유기간과 최소 보관 범위는 확정 전입니다.
운영 로그·문의 이메일실제 서버 로그 설정과 운영 이메일 처리에 따른 보유기간 및 파기 절차는 확인 중입니다. 임의의 기간 내에 자동 삭제된다고 안내하지 않습니다. 보관·삭제 문의는 운영 이메일로 요청할 수 있습니다.

앱을 삭제해도 서버 백업, 다른 기기의 사본 또는 외부로 내보낸 파일이 함께 삭제되지는 않습니다. 재설치 후 자동 복원은 보장하지 않습니다. 암호화 백업과 암호를 보관해야 하며, 암호를 잊으면 새 기기에서 복원하지 못할 수 있습니다.

4. 외부 서비스와 국외 처리

Firebase·Google Cloud는 계정 인증, 서버 기능, 암호화 백업, 알림 및 선택적 통계에 사용됩니다. Google Play는 구독 구매·검증, AdMob은 활성화된 버전의 광고에 사용됩니다. 간편 로그인은 선택한 구글·카카오·네이버·페이스북 제공사의 인증 서비스를 이용합니다.

Google의 Firebase 공식 안내에 따르면 Firebase Authentication은 미국 데이터센터에서 처리됩니다. 로그인할 때 인증 정보와 IP·사용자 에이전트 등이 인증·보안 목적으로 처리되며, 인증 정보는 계정 삭제 요청 후 Google의 운영·백업 시스템에서 최대 180일 이내 정리됩니다. 이는 운영자 이메일 삭제 요청의 처리기한이나 모든 서비스의 보유기간을 뜻하지 않습니다.

앱 서버 함수는 서울 리전으로 구성되어 있습니다. 이것만으로 Firebase Authentication·Analytics·광고·지원 업무의 모든 저장 및 처리가 한국에서 이루어진다고 판단할 수는 없습니다. Google은 서비스와 계약에 따라 해외 시설에서도 데이터를 처리할 수 있습니다.

제공사별 계약상 수탁자, 실제 처리 국가, 이전 항목·시점·방법·보유기간과 거부에 따른 영향은 운영 설정 및 계약과 대조하여 확정해야 하는 항목입니다. 아래 제공사 문서는 참고 자료이며 마음냥 정원의 구체적인 이전 고지를 대신하지 않습니다.

5. 정보 보호

기록과 초안에 암호화를 적용하고 서버 백업은 이용자 암호로 암호화합니다. 설정·이용 카운터 등 일부 보조 정보는 앱 전용 저장소에 보관되며 모든 정보가 별도로 암호화되는 것은 아닙니다. 서버 통신에는 HTTPS를 사용하며 인증된 계정을 기준으로 서버 접근을 제한합니다. 개인 기록과 공개 정원 데이터를 분리합니다.

앱 내 서버 계정 삭제는 최근 로그인 확인을 요구합니다. 이메일로 요청할 때에도 해당 계정의 소유자인지 확인할 수 있으며, 비밀번호·인증번호·주민등록번호를 이메일로 보내지 마세요.
