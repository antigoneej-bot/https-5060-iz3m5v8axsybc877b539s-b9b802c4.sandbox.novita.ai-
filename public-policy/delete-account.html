삭제 요청 메일 작성

버튼은 이메일 작성 화면을 엽니다. 자동으로 전송되거나 계정이 삭제되지는 않습니다. 메일 앱이 없으면 위 주소로 직접 보내주세요.

이렇게 요청해 주세요

  1. 제목에 ‘마음냥 정원 계정 및 데이터 삭제 요청’을 적습니다.
  2. 사용한 로그인 방식과 계정을 찾을 수 있는 이메일 또는 사용자 식별 정보, 회신받을 이메일을 적습니다. 전체 계정 삭제인지 일부 정보 삭제 요청인지 알려주세요.
  3. 내용을 확인하고 직접 전송합니다. 운영자는 계정 소유 여부를 확인한 뒤 요청을 처리합니다. 추가 확인이 필요한 경우 이메일로 안내합니다.

비밀번호·일회용 인증번호·주민등록번호·일기 본문은 보내지 마세요.

현재 테스트 운영 중이며, 이메일 요청의 확정 처리기한은 정식 운영 절차와 함께 확인 중입니다. 요청 메일 전송은 삭제 완료 확인이 아닙니다. 진행 상황과 처리 결과는 운영 창구로 확인해 주세요.

앱에서도 삭제할 수 있어요

앱의 ‘기록 보관과 백업’ → 서버 계정 삭제에서 진행할 수 있습니다. 계정 보호를 위해 다시 로그인해야 할 수 있습니다. 완료 안내를 확인해 주세요.

삭제 대상과 남을 수 있는 정보

서버 삭제 절차는 로그인 계정, 서버 백업, 사용자 서버 데이터, 공개 정원, 이웃 연결, 예약, 공동 나무와 메모, 관련 신고·응원 전송 기록 및 알림 연결을 정리합니다. 상대가 받은 응원은 발신자 ID·닉네임을 제거한 수신 기록으로 남을 수 있습니다.

부정 이용과 삭제 중 계정 재생성을 막기 위한 구매 토큰 해시 표식, 계정 해시 기반 삭제 상태, 소셜 로그인 연결 식별자·UID·연결 세대 정보는 남을 수 있습니다. 현재 자동 만료기간은 설정되어 있지 않으며, 정식 운영의 보유기간·최소 보관 범위는 확정 전입니다. 운영 로그와 요청 이메일의 보유기간도 확인 중입니다.

서버 계정 삭제만으로 기기의 오프라인 기록이나 이미 내보낸 파일을 원격 삭제하지는 않습니다. 기기 기록은 앱의 삭제 기능 또는 기기의 앱 데이터 삭제로, 내보낸 파일은 저장한 곳에서 별도로 삭제해 주세요.
