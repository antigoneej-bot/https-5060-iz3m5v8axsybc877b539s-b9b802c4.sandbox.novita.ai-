마음냥 정원 1.0.69+72 — 내부 확인용 빌드

기준: 1.0.68+71, e7858ff83358516c454249a75d4284faa0d54113
작업 브랜치: feature/pre-release-validation-72
이전 소스·APK·AAB는 보존했습니다. 이번 작업은 스토어 업로드나 운영 배포를 하지 않습니다.

변경
- 일반 내 정원 진입은 GardenWorldScreen.owned로 통일했습니다.
  기존 MyGardenScreen 진입도 동일한 재배 화면을 사용합니다.
  배치·장식 이동·확장은 GardenWorldScreen.tools 보조 메뉴에 남았습니다.
  기록·활동 메뉴와 읽기 전용 이웃 정원은 유지했습니다.
- Hive 2.2.3의 실패한 열기 후 비동기 close를 기다리도록 최소 로컬 패치했습니다.
  동시에 여는 호출의 오류 전달도 정리했습니다. 파일·암호화 형식은 그대로입니다.
  손상 파일을 자동으로 잘라내거나 삭제하지 않습니다.
- 색칠 저장은 계정별로 순서를 보장하고, 비동기 작업 전에 그림을 복사합니다.
  화면 재진입의 읽기는 진행 중인 저장이 끝난 뒤 처리합니다.
  검사는 고정 1.2초 대기 대신 이미지·영역·저장 자료 준비 상태를 기다립니다.
- 돌봄 포인트 상점과 빛의 정수를 구분해 안내합니다. 재화는 통합하지 않았습니다.
  출석으로 온기·성장 일수가 쌓이는 기존 기능은 유지했습니다.
  별도 출석·목표 보상 및 빛의 정수 통합은 준비 중으로 구분합니다.
  무료 37마리 감정 고양이와 구독 동반 고양이 외형을 구분합니다.

빌드 구분
- 이번 내부 빌드: UNLOCK_ALL_PREMIUM=true, RELEASE_ENV=internal,
  APP_CHECK_DEBUG_PROVIDER=false. 테스트 개방은 실제 유료 구독이 아닙니다.
- 정식 배포: 테스트 개방을 해제하고 운영용 빌드·결제·광고·개인정보 설정을
  별도로 검증해야 합니다. 이번에는 정식 설정으로 전환하지 않았습니다.
- 기존 상품 ID·가격·권한·로그인·서버·사용자 저장 형식은 변경하지 않았습니다.

검증 결과 읽기
ZIP 루트의 FULL-VALIDATION-KO.md와 FEATURE-CHECKLIST-KO.md 및 원시 로그를 보세요.
과거 보고서는 이 버전의 실행 결과가 아닙니다. 이번 보고서가 우선합니다.
화면 캡처는 실제 앱 위젯을 별도 가상 데이터로 실행한 자동 테스트 렌더링입니다.
Android 실기기·Play 실제 테스트 구매·운영 인증·iOS 결과와 구분해야 합니다.

서명·데이터 보존
새 서명키를 만들지 않습니다. 개인키·비밀번호·key.properties는 ZIP에 없습니다.
기존 로컬 업로드 키의 인증서와 Play 앱 서명 인증서는 다를 수 있습니다.
서명이 다르면 직접 APK 업데이트를 진행하거나 앱을 삭제하지 마세요.
