# 마음냥 정원 1.0.51 (54) — 파스텔 좌우 탐색

승인한 시안을 바탕으로 앱의 홈을 크림·민트·피치·라벤더 톤과 부드러운 글씨로 바꿨습니다.

- 홈 / 정원 / 마음돌보기 / 이웃: 좌우로 넘기거나 고정된 하단 메뉴로 이동합니다. 각 공간 안의 긴 내용은 위아래로 스크롤합니다.
- 오른쪽 위 간편로그인: 기존 계정·소셜 로그인 화면에 연결합니다. 로그인 상태에서는 내 계정으로 표시됩니다.
- 홈 앞쪽 6종 고양이: 눌러서 선택하면 기존 저장된 선택과 정원·마음돌보기에 반영합니다. 선택·성장에서 기존 성장·가족 기능을 엽니다.
- 마음냥 만화책: 홈과 마음돌보기에서 ‘주간·월간 감정 통계’임을 설명합니다. 기존 주간·월간 만화, 마지막 요약장, 상세 통계 기능을 유지합니다.
- 사용법: 좌우 이동, 로그인 위치, 6종 동반 고양이와 37종 감정 고양이의 차이, 만화책 통계, 가로 정원 사용법을 안내합니다.
- 가로 전체보기: 정원 공간의 버튼 또는 실제 정원 상단 회전 버튼에서 진입합니다. 가로 방향을 요청하고 전체 정원 카메라로 시작합니다. 확대·이동할 수 있으며 뒤로 나오면 방향 제한을 해제합니다. 자동 회전으로 돌아가기 버튼도 제공합니다.
- 이전 편지는 오른쪽 위 더보기 → 편지 기록, 다른 기능은 홈 → 기록과 모든 기능에서 엽니다.

## 설치·검증

제공 AAB는 Google Play Console의 기존 앱 내부 테스트 트랙에 새 버전으로 올릴 빌드입니다. 패키지명과 서명은 기존 앱을 유지했고 versionCode를 54로 올렸습니다. AAB는 휴대폰에 직접 설치하는 파일이 아닙니다. 이 작업에서 Play 업로드는 하지 않았습니다.

서버 API나 데이터 구조는 변경하지 않았으므로 이번 UI 업데이트에 서버 재배포는 필요하지 않습니다. 구독 기능 테스트 개방도 유지합니다. 출시 전 구독 잠금 검토와 출석 보상 등 이전에 남아 있던 작업은 이번 UI 작업 범위에 포함하지 않았습니다.

화면 크기 320×640, 390×844, 844×390과 글자 배율 1.0/1.6에서 탐색·선택·레이아웃을 검사했습니다. 정원 가로 방향 요청과 종료 시 해제, 기존 저장·오프라인 동작도 자동 테스트로 검사했습니다. 전체 자동 테스트, 분석, AAB 서명·매니페스트 확인 결과는 Verification.json에 있습니다. 실제 Android 기기와 실제 소셜 로그인은 이번 환경에서 실행 검증하지 않았습니다.
