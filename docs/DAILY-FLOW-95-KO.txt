마음냥 정원 1.0.92+95 — 홈 흐름 정리 / 색칠 힐링 종료

기준
1.0.91+94 영어 교정본(c6bb3a2e1f69416ae73bdbb19e5318ac937e1aa5)을 보존하고
feature/clear-daily-flow-95 별도 작업본에서 변경했습니다.
과거 review의 성공 기록은 이번 버전 결과가 아닙니다. 이번 실행 결과는 전달물의
review-flow95/VALIDATION-KO.txt와 원본 로그에서 확인합니다.

1. 홈의 우선순위
선택한 동반 고양이 → 현재 감정 선택 → 마음 기록하기 → 실제 정원 순서를 유지합니다.
37마리 감정 고양이를 선택하는 기존 기록 경로를 설명하는 한 줄을 추가했습니다.
이웃 이동 버튼은 보조 버튼으로 낮추고 5개 탭과 이웃 소식은 유지했습니다.
이미 저장한 기록의 완료 화면을 다시 열지 않도록, 새 기록 진입 시 완료된 화면 상태만
해제합니다. 저장한 편지와 고양이별 미전송 초안은 삭제하지 않습니다.

2. 오늘 남긴 작은 흔적
AppStateProvider.history의 오늘 기록과 MongiGardenStore의 오늘 물주기를 읽습니다.
원문·개인 편지·새 자동 답장을 홈에 노출하지 않습니다. 현재 중단된 자동 답장 기능을
다시 활성화하지 않으며 이전 답장은 기존 기록 화면에 남습니다.
심어진 식물과 실제 물주기 날짜가 일치할 때만 이름·현재 성장 상태를 표시합니다.
항목을 누르면 기존 실제 정원에서 해당 식물의 저장 위치를 찾아 강조합니다.
없는 식물 ID는 무시하고 새 식물이나 좌표를 생성하지 않습니다.
부족한 기록에 임의 수치·성장·연속 출석 압박을 붙이지 않습니다.
정원 읽기 실패 시 재시도를 제공하고, 로컬 날짜 변경/앱 복귀 시 표시를 갱신합니다.
홈을 보는 행위로 씨앗·정수·돌봄 보상을 추가 지급하지 않습니다.

3. 다시 돌아볼 길
기록이 있으면 주간·월간 만화책/감정 통계와 정원 기록집을 기존 화면으로 연결합니다.
정원의 별도 일기는 '정원 마음 일기 / Garden journal'로 구별합니다.
마음 리포트는 편지와 정원 일기를 함께 읽는 기존 통합 요약이므로 이 관계를
전체 기능 설명에 명시했습니다. 저장소를 합치거나 원문을 이동하지 않았습니다.
한국어와 영어의 기록 탭 그룹이 같은 배치 조건을 사용하도록 보완했습니다.

4. 색칠 힐링 제거
홈 액션·힐링·전체 기능·이전 홈 메뉴에서 색칠 화면으로 가는 경로를 제거했습니다.
구독/무료 기능 소개·카드 추가 보상 설명·사용법·영어 명상 안내도 정리했습니다.
예전에 전시한 작품은 정원 액자에서 유지합니다. 빈 액자에서 색칠 기능을 안내하지 않습니다.
보존 목적의 기존 색칠 저장소/화면 소스/에셋/회귀 검사는 소스 ZIP에 남습니다.
실제 앱 import/export 경로에는 색칠 화면이 연결되지 않습니다.
개인 저장 작품·완성 작품·보유 추억 카드·기존 서버 보상 이력은 삭제하지 않습니다.
구버전 사용자를 위해 서버의 기존 색칠 보상 API는 변경·배포하지 않습니다.

실제 2.5D 정원/좌표/성장/물주기/구역/장식/재화, 산책과 이웃 개선, 5개 탭,

백업 형식, Firebase 보안 규칙, IAM, 서버 소스/설정, 의존성 잠금 파일은 변경하지 않습니다.

다른 환경에서 다시 생성할 경우 '정원 마음 일기 / Garden journal'를 원본에도 옮겨야 합니다.
