# 마음냥 정원 1.0.53 (56)

## 색칠
- 승인한 ‘사랑을 안은 고양이’ 상세 도안 한 장을 새 기본 화면으로 적용했습니다. 37종 전체를 새 도안으로 제작한 버전은 아닙니다.
- 아주 얇은 붓·중간 붓·큰 붓, 같은 굵기의 지우개, 48색, 사용자 색조·선명함·밝기 선택, 최근 사용색을 제공합니다.
- 직접 붓질하는 방식입니다. 선은 위에 남아 가려지거나 지워지지 않습니다. 영역 밖으로 나가지 않도록 자동 제한하는 방식은 아닙니다.
- ‘확대·이동’에서 확대하고 위치를 조절한 뒤 ‘색칠하기’로 돌아오세요. 그림과 아래 도구 영역을 분리했습니다.
- 붓질마다 기기에 저장하며 되돌리기·다시하기, 완성작 보관, PNG 공유를 지원합니다. 저장 실패 시 마지막 붓질을 다시 저장할 수 있습니다.
- 예전 세 도안과 작품·기존 색칠 카드 보상은 ‘이전 도안·작품함 · 색칠 카드’에 그대로 유지했습니다. 새 자유 붓칠 도안은 카드 보상을 자동 지급하지 않습니다.
- 테스트 구독 개방은 유지됩니다.

## 유리종 알림
- 새 유리종 소리 파일과 소리 켜기·끄기를 ‘마이 · 설정’의 이웃·예약 소식 설정에 추가했습니다.
- Android 알림 채널을 사용하므로 알림 권한, 휴대폰 무음·방해금지와 채널 설정을 따릅니다. 앱이 시스템 음량을 올리거나 무음을 우회하지 않습니다.
- 앱에서 새 공지가 확인되면 알려줍니다. 첫 조회의 과거 글과 같은 공지는 다시 울리지 않습니다. 공지 전체 사용자 실시간 방송은 이번 변경에 포함되지 않습니다.
- 아침·저녁·방문·출석 및 고양이 돌봄 알림도 같은 유리종/조용히 설정을 사용합니다. 설정 변경 시 이미 켜진 알림을 다시 예약합니다.
- 앱 실행 중 받은 이웃·예약 알림은 앱에서 처리하며, 중복 수신·짧은 시간의 연속 소리를 억제합니다.
- 앱이 꺼져 있거나 뒤에 있을 때 이웃·예약 푸시의 새 소리를 쓰려면 아래 서버 변경도 필요합니다.
- iOS 알림음 배포·실기기 시험은 이번 Android 업데이트에 포함되지 않습니다.

## 적용 순서
1. Mindnyang-1.0.53-56-TestOpen.aab를 기존 Play 테스트 트랙에 올려 배포합니다. 버전 코드 56, 기존 패키지와 업로드 서명을 유지했습니다.
2. Cloud Shell에 Mindnyang-Bell-Server-v56.py를 올립니다.
3. `python3 Mindnyang-Bell-Server-v56.py`로 기존 gardenApi와 gardenPush의 원본을 내려받고 변경분을 검증합니다.
4. 준비가 완료되면 `python3 Mindnyang-Bell-Server-v56.py --deploy`로 두 함수를 업데이트합니다. 기존 트리거·환경·비밀키·테스트 개방 설정을 변경하는 플래그를 넣지 않았습니다. 원본과 롤백 명령을 남깁니다.
5. 서버 파일이 예상한 원본과 다르면 중단합니다. 검사를 삭제하거나 무시하지 말고 출력 내용을 확인하세요. 두 함수의 배포는 순차적이며 하나가 실패하면 출력과 백업을 기준으로 확인해야 합니다.
6. 업데이트한 앱을 열어 알림 설정을 동기화하고, 실제 휴대폰에서 알림 켜기/끄기·무음·백그라운드 알림을 시험합니다.

이 작업에서는 Play 업로드·실제 Cloud 서버 배포·휴대폰 설치 시험을 수행하지 않았습니다. AAB는 Play용이며 직접 설치하는 APK가 아닙니다.
