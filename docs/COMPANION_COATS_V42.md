# 마음냥 정원 1.0.39+42 — 무료 고양이 선택

- 정원 상단 팔레트 버튼, 마음 돌보기의 `고양이 바꾸기 · 6종 무료`로 선택 화면을 엽니다.
- 치즈태비, 흰고양이, 고등어태비, 검정고양이, 턱시도 고양이, 삼색 고양이를 구독·포인트·광고 없이 선택합니다.
- 선택은 즉시 저장되며, 정원/홈 정원/마음 돌보기에서 같은 모습으로 반영됩니다.
- 기존 이름, 일기, 돌봄 활동과 성장 기록, 아기 모습/자동 움직임 설정을 유지합니다.
- CompanionJourney의 기존 백업 대상 레코드에 선택을 추가합니다. 기존 저장파일과 알 수 없는 새 종류 값은 기존 치즈태비 모습으로 안전하게 표시합니다.
- 변경 전 사용자는 기존 치즈태비를 유지하고, 선택하면 새 시안 이미지로 전환됩니다.
- 저장 실패 시 기존 선택과 기록을 유지하며 재시도 안내를 표시합니다.
- 큰 글씨에서는 1열, 휴대폰 2열, 넓은 화면 3열로 표시합니다.
- 고양이 이미지 변경과 성장 행동은 분리되어 있으며, 종류 선택 자체가 돌봄 일수에 가산되지 않습니다.

## 시각 자산

Built-in image generation으로 승인된 6종 시안을 투명 배경 캐릭터 아틀라스로 제작했습니다.
프롬프트 요지: 동일한 포근한 3D 아기 고양이 6종, 3×2 배열, 무늬만 다르게, 텍스트·장식 없이 투명 배경, 꼬리와 발 전체 포함.
원본 PNG를 변형하지 않고 실제 실루엣 범위를 Flutter에서 나눠 그립니다. 기존 움직임 시간과 반응 효과에 선택한 이미지를 연결합니다.
새 이미지의 기본 자세는 앉은 자세이며, 이 버전에는 종류별 별도 걷기/눈감기 프레임은 포함하지 않습니다.
기존 정원 이동 경로와 반응 효과, 작은 기울임과 호흡은 유지됩니다.
방문한 다른 사람의 공개 정원에는 방문자 자신의 고양이를 덮어쓰지 않습니다. 공개 정원 스냅샷의 고양이 종류 공유는 이 변경에 포함하지 않습니다.
