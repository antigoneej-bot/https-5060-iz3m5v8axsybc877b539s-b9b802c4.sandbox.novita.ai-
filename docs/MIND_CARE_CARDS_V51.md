# 마음냥 정원 1.0.48+51 테스트 안내

## 이번에 바뀐 내용

- 하단 `명상` 탭을 **마음돌보기**로 통합했습니다. 호흡·명상, 소리·휴식, 색칠 힐링, 돌봄 기록으로 이동합니다. 홈의 마음 돌보기와 전체 기능에서도 접근할 수 있습니다.
- **색칠 힐링**: 기본 도안 3종, 12개 영역을 눌러 색 채우기, 파스텔 팔레트와 직접 색 만들기, 확대·축소, 전체보기, 되돌리기, 지우개, 자동 저장, 작품함, PNG 공유/내보내기.
- 작품함은 도안마다 최근 완성한 작품 한 개를 보관합니다. 미완성 그림도 완료로 보관할 수 있습니다. 이후 색칠 초안을 수정해도 마지막 완성작은 유지됩니다. 그림은 현재 기기에 계정별로 저장하며 기기 간 동기화·기존 백업 대상에 추가한 것은 아닙니다.
- **추억 카드**: 6개 장면 × 6종 고양이 × 3개 테두리로 시작하는 108개 그림 조합입니다. 108개를 채워야 하는 완료 목표는 없습니다. 향후 콘텐츠를 추가할 수 있습니다. 고정 도감의 감정 종류를 모으는 방식에서 별도 카드 수집으로 바꿨습니다.
- 수집은 로그인 후 하루 기본 카드 한 장, 색칠의 모든 12개 영역을 채우면 추가 한 장입니다. 날짜는 한국 시간 기준이며 같은 날 재요청해도 중복 지급되지 않습니다. 장면은 무작위이며 해당 활동의 실제 달성 인증을 뜻하지 않습니다. 이번 버전은 수확·방문·명상 완료별 특별 카드 발급까지 연결한 버전은 아닙니다.
- 기존 감정 선택·기록 데이터는 삭제하지 않습니다. 기존 감정 컬렉션 메뉴와 리포트의 수집 진입점은 새 추억 카드함으로 연결합니다. `오늘의 고양이 카드`라는 기존 재미용 뽑기는 별도로 유지합니다.
- **교환함**: 서로 수락한 이웃의 중복 카드만 한 장씩 교환합니다. 제안자는 보낼 카드를 교환함에 맡기고, 받는 사람이 두 카드를 확인한 뒤 수락하면 서버에서 동시에 교환합니다. 마지막 한 장은 남깁니다.
- 제안은 7일간 유효합니다. 만료 후에는 수락할 수 없고 취소/거절로 맡긴 카드를 돌려받습니다. 자동 만료 정리 작업은 없으며 대기 중인 제안은 최대 20개입니다. 최근 교환 내역 100개를 보여줍니다.
- **자랑**: 내 카드에서 대표 카드 최대 3장을 골라 진열합니다. 서로 이웃인 사람은 진열장과 교환 가능한 중복 카드만 볼 수 있습니다. 이웃 진열장마다 하루 한 번 `예뻐요` 응원을 남길 수 있습니다. 공개 인터넷 갤러리나 랭킹은 아닙니다.
- 기본 색칠·수집·교환·진열은 무료 기능으로 표시했습니다. 이전의 구독자용 호스트 고양이 6종·성장·나무 구분과 **테스트 중 구독 기능 개방**은 유지했습니다. 추가 유료 카드팩/색칠팩은 이번에 만들지 않았습니다.

## 앱에서 찾는 곳

1. 하단 **마음돌보기 → 색칠 힐링**.
2. **마음돌보기 → 마음냥 추억 카드** 또는 **전체 기능 → 추억 카드 수집·교환**.
3. **내 카드**에서 카드를 눌러 대표 카드로 진열.
4. **교환함 → 이웃 카드 구경·교환 제안**에서 이웃 선택 → 받을 중복 카드 선택 → 내 중복 카드 선택 → 확인.
5. 상대방이 **교환함**을 새로고침하여 수락/거절. 현재 버전은 교환 푸시 알림을 추가하지 않았습니다.
6. **내 진열장 → 이웃 진열장 구경하기**에서 자랑과 응원.

## 배포해야 실제 휴대폰에 반영됩니다

앱 파일: `Mindnyang-1.0.48-51-TestOpen.aab` (Google Play Console 업로드용, 휴대폰에서 직접 설치하는 APK 아님).

- 같은 앱의 테스트 트랙에 versionCode 51로 새 출시를 만들고 배포해야 합니다.
- 테스트 계정에서 새 배포가 제공된 뒤 Play 스토어로 업데이트하세요.
- 소스 수정이나 파일 다운로드만으로 설치된 앱이 자동으로 바뀌지는 않습니다.

**온라인 카드 수집·교환·진열에는 서버 업데이트도 필요합니다.** 기존 서버에서는 새 동작을 제공하지 못합니다. 코드와 배포 도구를 준비했으며 실제 Google Cloud 서버 배포와 Play Console 업로드는 수행하지 않았습니다.

서버 파일: `Mindnyang-Cards-Server-v51.py`.

본인 Google Cloud Shell에서 프로젝트 `mycatapp-99bc8`를 확인하고 파일을 업로드한 뒤 실행합니다.

```bash
python3 Mindnyang-Cards-Server-v51.py
```

이는 검토용 실행입니다. 기존 `gardenApi` 원본을 내려받아 알려진 v47/v48/v49/v50 소스와 일치하는지 확인하고, 변경본·원본·되돌리기 명령을 준비합니다. 알 수 없는 서버 변경이 있으면 덮어쓰지 않고 중단합니다.

검토 후 적용:

```bash
python3 Mindnyang-Cards-Server-v51.py --deploy
```

기존 `gardenApi`에 카드 모듈을 추가하며 `PREMIUM_TEST_ACCESS=true`를 유지합니다. 실제 결제 상태를 구독으로 위조하지 않습니다. 로그인·App Check·기존 비밀키·다른 환경 설정은 유지합니다. 원본과 `ROLLBACK.txt`는 Cloud Shell에 보관됩니다.
