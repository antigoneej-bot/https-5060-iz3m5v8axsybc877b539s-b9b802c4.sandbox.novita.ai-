마음냥 정원 1.0.89+92 — 91번 예외 경로 안정화

기준: 1.0.88+91, 940c9ee4a55d3e5a5efe0b96da9ef59aad48a2b3.
91번 원본과 배포 파일 보존. 별도 브랜치 fix/reliability-92.
이번 변경은 클라이언트 안정화이며 서버 적용을 요구하지 않는다.
91번에 포함된 미배포 서버 최적화는 그대로 소스에 보존되어 있다.

수정 사항
1. 오류 보고 동의
   OFF 선택을 먼저 저장하고 SDK 수집 중지/대기 보고서 삭제를 각각 시도한다.
   정리 실패가 저장된 ON 값을 남겨 다음 실행에 다시 켜는 문제를 수정했다.
   초기화와 설정 변경은 직렬화한다. ON 실패는 OFF로 되돌린다.
   SDK/디스크 자체 실패는 오류로 반환하며 성공했다고 숨기지 않는다.
   기록할 오류의 본문/개인 식별자는 추가하지 않았다. 기본 OFF 유지.

2. 선택적인 알림 초기화
   채널 생성 실패가 로컬 정원/기록의 첫 진입을 막지 않게 했다.
   알림 초기화는 별도로 직렬화하고 다음 앱 복귀/설정 조작에서 다시 시도한다.
   일시적인 알림 예약 실패 때문에 사용자의 기존 동의와 선택 시각을 끄지 않는다.
   실제 기록 저장소/복원 실패는 기존 복구 경로를 유지한다.

3. 자동 백업 OFF 및 수동 백업
   꺼짐 이후 이전 업로드의 응답이 꺼짐 표시를 덮어쓰지 않는다.
   이미 전송된 백업은 완료될 수 있으며 확인된 마지막 성공 이력은 보존한다.
   업로드 직전 비동기 보안 저장소 조회 뒤에도 계정/활성 상태를 다시 검사한다.
   수동 요청은 진행 중인 작업을 기다린다. 새 변경 또는 자동 제한시간 대기일 때만
   필요한 후속 백업 한 번을 합친다. 실패/완료 미확인 쓰기를 자동 재전송하지 않는다.
   백업 암호, 저장 형식, 소유 계정 검증, 복원 차단 및 실제 기록 내용은 유지한다.

4. 영어 복구 안내
   공급자 기록 로딩 실패 화면을 번역 처리했다. 작은 가로 화면/큰 글자에서는
   안내와 재시도 버튼을 스크롤할 수 있다. 기존 기록을 삭제하는 조작은 없다.

5. 현지 알림 시각
   Android의 실제 IANA 시간대를 읽는다. 앱 언어로 국가를 추측하지 않는다.
   앱 복귀 시 시간대 변경을 감지하여 이미 동의한 아침/저녁 알림만 재예약한다.
   사용자가 정한 시각과 동의 값은 보존하며 권한을 새로 요청하지 않는다.
   다음 날을 24시간 더하기로 계산하지 않아 일광절약시간 전환에도 벽시계 시각을 유지한다.
   알 수 없는 시간대/네이티브 연결 미지원 환경은 현재 기기 UTC 오프셋으로 대체한다.
   이 대체 경로는 미래 DST 규칙을 알 수 없으며 다음 앱 복귀 때 오프셋을 다시 읽는다.
   앱을 한 번도 다시 열지 않은 채 해외 이동한 동안의 재예약, OS 실제 발송,
   제조사 절전 제한, iOS 기기 실행은 이번 자동 테스트로 검증하지 않는다.

보존 범위
디자인, 고양이 6종/이름, 정원 좌표/성장, 개인 기록/암호화 형식, 구독 가격/상품 ID,
내부 테스트 전체 개방, App Check, 패키지 com.mysticcat.journal, 기존 서명키 유지.
의존성 버전/해시는 변경하지 않음. 기존 잠금 파일에 있던 두 플랫폼 인터페이스를
모의 SDK/저장 실패 검사에 직접 사용하여 dev_dependency로만 명시했다.

이번 실행 결과는 전달 ZIP의 review-native92/VALIDATION-KO.txt와 로그를 확인한다.
과거 91번의 검증 자료는 이번 테스트 결과로 합산하지 않는다.
추가 회귀: 대기 보고서 삭제 실패, 동의 저장/SDK 실패, 초기화와 OFF 교차,
백업 중 OFF, 수동 중복 요청, 실패한 쓰기 재전송 방지, 보안 저장소 조회 중 OFF,
알림 채널/예약 재시도, 시간대 변경, DST, 영어 복구 UI.

복구/운영
서버/스토어/실사용 데이터 변경 없음. 코드 되돌림은 보존한 91번 또는 기준 커밋으로 가능.
설치본을 낮은 버전 코드로 직접 덮어쓰거나 앱 삭제로 복구하지 않는다.
문제가 있으면 기준 코드를 더 높은 버전 코드로 재빌드하여 기존 서명/데이터를 보존한다.
로컬 확인 최신 91보다 높은 92를 사용. Play 전체 트랙의 최대 코드는 직접 확인하지 못함.
APK는 기존 업로드 키로 서명되므로 Play 앱 서명과 다를 수 있다. 설치 실패 시 삭제 금지.
이웃 공유/결제 기본 사용은 사용자 확인사항이며, 두 테스트 계정 검증 결과는 아니다.
실제 Firebase 오류 보고 수신, 개인 기록 없는 환경의 백업→복원,
구독 만료/복원/계정 전환, Buddy3 성능, 원격 CI는 미검증 항목으로 남긴다.
USB/브라우저 자동 제어, 서버 배포, 스토어 업로드, 실제 과금은 수행하지 않는다.
