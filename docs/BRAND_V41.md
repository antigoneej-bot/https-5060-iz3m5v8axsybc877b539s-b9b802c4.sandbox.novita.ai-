# 마음냥 정원 1.0.38+41 — 이름과 밝은 아이콘

- Android 설치 이름을 `Mystic Cat Journal`에서 `마음냥 정원`으로 변경했습니다.
- 크림색 고양이, 분홍 하트, 연두색 잎과 꽃으로 밝은 아이콘을 새로 만들었습니다.
- Android 기본·원형·적응형 아이콘, iOS/macOS 아이콘, 웹 아이콘을 갱신했습니다.
- Android 시작 화면 배경을 밝은 크림색으로 통일했습니다. Android 12 이상 시스템 시작 화면에도 새 아이콘을 지정했습니다.
- 앱 식별자 `com.mysticcat.journal`과 기존 서명 키는 유지합니다.
- 기존 v40 파스텔 화면과 앱 기능은 유지합니다.
- 스토어 등록용 PNG: `Mindnyang-Play-Icon-512.png` (512 × 512, RGB).
- Play Console 스토어 등록정보 이름/아이콘은 직접 변경하거나 업로드하지 않았습니다.

아이콘 제작: 내장 이미지 생성 기능. 프롬프트 요지: 크림색 배경에 분홍 하트를 안은 귀엽고 둥근 고양이, 민트 잎과 작은 꽃, 밝고 따뜻한 파스텔, 글자 없이 작은 크기에서도 읽히는 앱 아이콘.

소스에는 비공개 서명 키와 비밀번호를 포함하지 않습니다. 릴리스 빌드에는 기존 `android/key.properties` 및 기존 keystore를 사용해야 합니다.
