# 고양이 돌봄 보완 — 2026-10-25

정원의 노란 고양이를 직접 돌보고, 함께한 날과 첫 순간을 이어가는 기능입니다.

## 실제 반영

- 넓은 정원 상단의 ‘돌보기’ 버튼, 고양이 직접 터치, 발바닥 아이콘으로 돌봄 화면을 엽니다.
- 기존 마음 돌보기 화면도 같은 노란 고양이와 같은 성장 기록을 사용합니다. 온기·상점·착용 아이템 보유 정보는 유지합니다.
- 쓰다듬기·빗질하기·같이 쉬기: 눈을 감는 반응, 작은 호흡 움직임, 동작에 맞는 표시와 안내. 저장이 완료된 뒤 반응합니다. 접근성의 움직임 줄이기 설정에서는 정적인 반응으로 표시합니다.
- 7일·30일·90일의 누적 돌봄으로 단계가 바뀝니다. 기존 그림 전체를 82% → 88% → 94% → 100%로 표시하며 발 위치와 그림자를 함께 유지합니다. 이번 변경은 새로운 성장 단계별 원화나 걷기 애니메이션 교체를 포함하지 않습니다.
- 하루에 여러 활동을 해도 성장 일수는 한 번만 쌓입니다. 연속 출석 의무, 결석 감점, 유료 성장 가속은 없습니다.
- 아기 모습 유지 설정은 외형 크기만 고정하며 성장과 기억을 지우지 않습니다.
- 쓰다듬기, 빗질, 휴식, 몸·마음 돌보기, 편지, 명상, 심기, 물·거름·햇볕의 첫 날짜를 기록합니다. 날짜가 확인되는 7·30·90·100일의 돌봄 기념도 보여 줍니다.
- 기존 돌봄 일수는 한 번 이어받으며 과거 날짜를 만들어 내지 않습니다. 이미 돌본 오늘을 중복으로 더하지 않습니다.
- 이전 이름을 계속 사용하고 같은 화면에서 이름을 바꿀 수 있습니다.
- 홈의 작은 고양이, 정원 미리보기, 넓은 정원, 마음 돌보기에 같은 노란 고양이를 사용합니다. 미리보기의 고양이를 눌러도 같은 돌봄 화면이 열립니다.
- 먼저 천천히 눈을 감으며 인사하고, 가끔 고개를 기울이거나 쉬는 자동 행동을 추가했습니다. 몸을 조각내지 않는 연속 변형으로 아주 작은 움직임만 만들고, 하체·발·접지 그림자를 고정합니다. 기존 산책 애니메이션은 변경하지 않습니다.
- ‘고양이의 작은 움직임’ 설정은 개인 기록에 저장되어 정원과 마음 돌보기에 함께 적용됩니다. 움직임 줄이기, 화면 전환, 앱 백그라운드에서는 자동 행동이 멈춥니다. 사용자가 명시한 정원 전체 움직임 정지도 존중합니다.
- 자동 인사·휴식은 시각적 반응입니다. 앱을 켜 놓기만 해서 돌봄 일수나 보상이 쌓이지 않으며, 편지 내용을 해석해 고양이의 기분을 추정하지 않습니다.
- 편지 본문과 감정 내용은 이 기록에 복사하지 않습니다. 성장 기록은 개인 백업·복원 대상이며 이웃 정원에 공개되지 않습니다.

## 범위와 데이터

- 개인 기록의 기존 소유 범위(local_user)를 유지합니다. 소셜 로그인 계정마다 별도 고양이를 만들거나 기존 데이터를 재배치하지 않습니다.
- 신규 SharedPreferences 키: local_user_companion_journey_v1. 손상된 값은 자동 초기화하지 않고 다시 시도를 안내합니다.
- 이전 고양이 돌봄 수정본의 저장 데이터도 호환합니다. automaticBehavior가 없는 기록은 기본 켜짐으로 읽고 기존 날짜·이름·성장을 보존합니다.
- 기존 CatCareState.growthDays는 과거 출석 통계 호환용입니다. 새 고양이 화면은 CompanionJourney의 실제 돌봄 일수로 성장합니다. 과거 졸업·감정 고양이로 외형 전환 기능을 되살리지 않습니다.
- 각 동작의 성장 반영은 멱등 처리합니다. 주 동작(편지·식물 저장 등)이 성공하고 부가 고양이 기록 저장만 실패한 경우 주 동작을 취소하지 않습니다. 고양이 화면에 저장 문제를 표시하고 다음 돌봄으로 다시 저장할 수 있습니다. 명상 완료는 기존 완료 저널의 재시도 흐름에 포함합니다.
- 이웃 정원의 고양이는 기존 공개 모습으로 표시합니다. 새로운 크기·돌봄 통계를 서버로 전송하는 기능은 포함하지 않습니다.
- 서버, Firebase, 소셜 로그인, 결제, 알림, Android 서명 설정, 패키지명, 의존성, 버전 코드는 변경하지 않았습니다. 서버 재배포는 필요하지 않습니다.

## 확인

Flutter 3.35.4 / Dart 3.9.2에서 기록 중복·재접속·계정 범위·이전 기록 이관·손상 데이터·백업 복원, 360/390px 및 글자 2배의 버튼 조작, 공개 정원의 돌봄 접근 차단, 성장 전후 발 위치 유지 등을 검사합니다. 추가로 자동 동작의 연속성, 발 고정, 동작 정지와 복귀, 정원에서 연 돌봄 화면의 기록·움직임 설정 공유를 검증했습니다. 관련 12개 테스트 파일 63건이 통과했습니다. 전체 저장소 테스트나 실제 휴대전화 실험을 대신하는 결과는 아닙니다. 실제 실행 결과는 동봉한 verification 폴더에 있습니다.

verification/companion-care-motion.mp4는 390px Flutter 위젯을 12fps로 캡처한 자동 인사 예시입니다. 휴대전화 녹화가 아닙니다. 기존 그림을 사용하며 새로운 이미지·오디오 자산은 추가하지 않았습니다.

휴대전화용 APK/AAB는 이 묶음에 포함하지 않습니다. 최종 앱을 빌드한 후 내부 테스트에서 실제 터치·소리·업데이트 후 이전 기록 유지까지 확인해야 합니다.
