# 마음냥 정원 1.0.28+31 — 심은 나무와 추억 관리

기준: 1.0.27+30 전체 소스. 이번 수정은 앱의 로컬 정원·추억 관리이며 새 서버 변경은 없습니다.

## 사용 방법

- 나의 정원에서 심은 나무를 누릅니다. 상단의 `글 수정·삭제` 또는 `나무 삭제`를 선택합니다.
- 작은 나무를 누르기 어렵다면 `기억의 나무 → 내 나무 · 글 수정·삭제`에서 이름으로 고릅니다.
- 글 수정의 `저장`을 누르면 바로 반영됩니다. 개별 추억 삭제도 확인 후 즉시 저장됩니다.
- 이름·기념일·새 추억은 관리창 아래 `저장`으로 반영합니다.
- `추억만 모두 지우기`는 나무의 성장 단계를 유지하면서 이름·기념일·추억을 지웁니다.
- `나무 삭제`는 심은 나무, 이름·기념일·추억, 해당 나무의 성장 단계와 돌봄 날짜를 지웁니다. 꽃 등에는 `식물 삭제`로 표시합니다.

## 삭제와 수정 범위

- 원본 편지, 다른 식물, 빛의 정수, 남은 씨앗, 전체 기록일·돌봄일은 유지합니다.
- 삭제한 나무의 이름과 기념일은 월간 기록집에서도 제거합니다. 과거 정원 구성 스냅샷은 당시 모습으로 유지합니다.
- 사용한 씨앗은 환급하지 않습니다. 다시 심으면 씨앗 1개를 사용해 새 날짜·성장 1단계로 시작합니다.
- 기존 정원 확장 공간과 배치 좌표는 유지합니다. 같은 종류를 다시 심으면 기존 위치에 놓입니다.
- 편지에서 가져온 문장을 편집할 때는 원본과의 연결 해제를 안내합니다. 수정한 문장은 독립된 추억으로 저장되며 원본 편지는 바뀌지 않습니다. 바꾸지 않고 저장하면 기존 연결을 유지합니다.
- 편지로 자라는 자동 `기억의 나무` 성장 지표는 초기화하지 않습니다. 이번 삭제 대상은 사용자가 씨앗으로 심은 개별 식물입니다.
- 공개 정원은 기존 스냅샷 공개 방식입니다. 정원 구성을 이웃에게 반영하려면 기존 공개 정원 갱신 기능을 사용해야 합니다. 개인 추억 글은 공개하지 않습니다.

## 저장 안전성

- 저장 실패를 성공으로 표시하지 않습니다. 글 수정 실패 시 입력창과 입력 내용을 유지합니다.
- 나무 삭제는 정원 저장 큐와 개인 기록 트랜잭션으로 묶습니다. 마지막 정원 설정 저장이 실패하면 삭제된 추억과 기록집 내용을 복원합니다.
- 이 트랜잭션은 실행 중 실패에 대한 복구입니다. 여러 파일 저장 사이의 강제 종료·디스크 고장에 대한 완전한 원자성을 주장하지 않습니다.
- 오래 열린 편집창의 저장은 기록 버전과 식물 존재 여부를 검사합니다. 삭제되었거나 다른 화면에서 바뀐 기록을 덮어쓰지 않습니다.

## 배포

- Play Console에는 버전 코드 31의 서명된 AAB를 올립니다. 기존 30 AAB는 이 수정 전입니다.
- 이번 기능만을 위해 Cloud Shell이나 로그인 서버를 다시 배포할 필요는 없습니다.
- 이전 v30의 gardenApi 공지 저장 보완 배포 여부는 별개입니다. 이번 앱 빌드가 그 서버를 배포하지는 않습니다.
- 로그인·결제·서명키·App Check·패키지명은 그대로 유지합니다.
- 패치 ZIP은 `flutter_app/` 아래 파일만 v30 소스에 적용합니다. 서명키나 서버 비밀 설정은 포함하지 않습니다.
