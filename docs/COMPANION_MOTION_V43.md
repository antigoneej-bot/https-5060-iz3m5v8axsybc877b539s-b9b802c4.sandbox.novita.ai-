# 마음냥 정원 v43 — 6종 고양이 애니메이션

버전 1.0.40+43. 앱 ID 및 기존 릴리스 서명 유지.

## 적용
- 6종별 12개 포즈: 기본, 반쯤 감은 눈, 감은 눈, 웃음, 왼쪽 꼬리, 오른쪽 꼬리, 6단계 사족보행.
- 정원의 `고양이 산책하기`를 켜면 실제 다리 자세가 바뀌는 걷기 장면으로 이동합니다. 왼쪽 이동은 반전하여 표시합니다.
- 선택한 고양이는 정원, 홈 정원, 마음 돌보기에서 기존 움직임 시계를 사용해 눈을 깜빡이고 꼬리를 움직입니다.
- 쓰다듬기/밥 주기/놀이 반응과 정원 선물 반응에는 웃는 표정이 나타납니다.
- 선택 화면에서도 눈 깜빡임, 꼬리 움직임, 웃음을 미리 볼 수 있습니다.
- 자동 행동을 끄거나 시스템 동작 줄이기를 사용하면 자동 애니메이션을 멈춥니다. 백그라운드/비활성 화면에서도 시간을 멈춥니다.
- 이름, 종류 선택, 성장 및 돌봄 기록을 변경하지 않습니다. 6종 모두 무료 유지.

## 렌더링
실제 3D 모델 대신 고양이 종류별 12장의 3D풍 이미지 장면을 재생합니다. 걷기에는 별도 다리 포즈를 사용합니다.
꼬리는 한 장의 고양이 표면 중 꼬리 영역만 연속적으로 휘어 움직이며, 서로 다른 꼬리를 겹쳐 그리지 않습니다. 하나의 고양이를 통째로 그리며 몸통과 팔다리를 분리해서 이동시키지 않습니다. 측정한 발 접점과 얼굴 중심을 맞추고 같은 모드에서 크기를 고정합니다.
공개 정원 방문 시 방문자 본인의 고양이 종류를 덮어쓰지 않는 기존 동작을 유지합니다.

## 이미지 제작
Built-in image generation을 사용해 승인된 6종 그림체를 바탕으로 종류별 3열×4행 투명 아틀라스를 제작했습니다.
프롬프트: 같은 고양이 12포즈, 앞모습 눈 뜸/반감음/감음/미소/좌우 꼬리와 오른쪽을 향한 6단계 사족보행, 무늬와 체형 유지, 배경/텍스트 없음.
원본 이미지의 표시 픽셀과 알파를 유지한 lossless WebP 변환으로 용량을 줄였습니다. 전체 애니메이션 자산은 약 8.3MB입니다.
동작 미리보기 영상은 앱에서 쓰는 동일 Flutter painter로 렌더링했습니다.

실기기 테스트와 Play Console 업로드는 수행하지 않았습니다. 자동 검사 및 번들 검증 결과는 별도 Verification.json을 참조하세요.
