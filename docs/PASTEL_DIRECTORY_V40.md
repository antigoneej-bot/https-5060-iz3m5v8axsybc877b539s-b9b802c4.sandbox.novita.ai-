# 마음냥 정원 1.0.37+40 — 파스텔 전체 기능

1.0.36+39의 전체 기능 화면을 마음냥 정원의 기존 파스텔 디자인으로 바꿨습니다.

- 10개 카테고리의 칩과 기능 박스에 분홍, 살구, 민트, 라벤더, 버터색, 하늘색 등 서로 다른 색을 적용했습니다.
- 기존 GardenPathCard의 비대칭 둥근 모서리, 부유·살짝 기울기·터치 반응을 재사용했습니다.
- 제목과 메뉴는 Gamja Flower(감자꽃), 설명은 Gowun Dodum(고운돋움)으로 표시합니다. 기존 탑재 폰트를 사용하므로 별도 다운로드가 없습니다.
- 홈·마이의 전체 기능 입구도 같은 부유형 박스로 바꿨습니다.
- 검색창은 둥근 형태로, 도움말은 펼쳐보기로 정리하고 꽃잎 배경을 적용했습니다.
- 기기의 애니메이션 줄이기 설정이 켜진 경우 이 화면과 입구의 부유 효과를 멈춥니다.
- 32개 기능의 이동 경로와 기존 구독 조건, 도감 오류 수정은 유지했습니다.

공용 GardenPathCard에 선택형 아이콘 및 글자 크기 속성만 추가했습니다.
기존 호출부는 기본값을 유지하므로 다른 화면의 디자인은 바뀌지 않습니다.

실제 Android 기기에서의 확인과 Play Console 업로드는 별도입니다.
