- GitHub 분석에서 --no-fatal-warnings를 제거. 기존 정보 수준 항목은 유지하되 새 경고는 CI 실패로 처리.
- 주간 상세 화면의 무료 접근 차단/권한 있는 빈 상태 접근 회귀 검사를 추가.
