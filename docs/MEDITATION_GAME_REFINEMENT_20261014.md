# 명상·게임 사용 흐름 보완 — 2026-10-14

이번 수정은 앞선 1~4번 핵심 경험 수정에 이어, 사용자가 승인한 5번(명상·게임)을 반영합니다.

## 명상
- 오디오에 '듣기 마치기'를 추가했습니다. 일시정지는 위치를 유지하고, 마치기는 해당 음원을 정지·초기화합니다. 중간 종료를 완주로 기록하지 않습니다.
- 앱 안에서 다른 화면/대화상자를 열어 명상 화면을 가리면 오디오와 영상을 멈춥니다. 돌아와도 자동 재생하지 않습니다. 기존 오디오의 잠금화면/백그라운드 재생은 유지합니다. 영상은 앱 이탈 시 멈춥니다.
- 영상에 음량·진행 시간·처음으로·마치기를 추가했습니다. 오류 시 버튼을 없애지 않고 안내와 재시도 경로를 남깁니다. 빠른 연속 조작을 막고, 재생 준비 중 화면을 떠나도 뒤늦게 재생하지 않도록 확인합니다.
- 자동 종료에 3·5·10분을 추가했습니다. 기존 15·30·60분도 유지합니다. 기본값은 타이머 없음이며, 원본 음원/영상 길이는 바꾸지 않았습니다. 타이머는 최대 재생 시간으로, 짧은 음원은 먼저 끝납니다. 자연음 반복은 사용자가 선택합니다.
- 타이머의 음량 조절이 실패해도 종료 시점에는 정지를 시도합니다. 설정 실패 상태를 정상 타이머처럼 표시하지 않습니다.
- 글 안내는 펼쳐 읽도록 정리했습니다. 완료 후 직접 선택한 느낌에 맞게 안내하며, 원하면 '내 마음 돌아보고 돌봄 고르기'로 연결합니다. 느낌을 1~10점으로 임의 환산하지 않습니다.

## 달려라 몽이
- 일반 플레이·연습·무한 도전에 준비 화면과 3초 카운트다운을 적용했습니다. 준비 중에는 캐릭터·게임 시간·소리를 멈춥니다.
- 앱 이탈/복귀 후에는 사용자가 계속하기를 눌러야 재개합니다. 카운트다운 중 앱을 나가도 복귀 후 새로 준비합니다. 연타로 여러 카운트다운이 생기지 않습니다.
- 무한 도전에도 일시정지를 추가했습니다. 종료 확인을 취소하면 준비 화면에서 이어갈 수 있습니다. 무한 도전의 뒤로가기 허용 상태를 명확히 하여 종료 확인이 반복되지 않게 했습니다.
- 주먹·점프 버튼은 누른 상태가 보이며 스크린리더 조작을 제공합니다. 화면 이탈/정지 때 누른 손가락 상태를 비웁니다.
- 로딩 실패 화면이 준비 화면에 가려지지 않게 했습니다. 소리 로딩을 기다리느라 게임 조작이 늦어지지 않게 했고, 종료 이후에 이전 소리 로딩이 뒤늦게 재생되는 경로를 차단했습니다.
- 이번 수정은 실제 진입 경로인 RunnerGameScreen/EndlessModeScreen에 적용했습니다. 예전 대체 진입 화면 MongiPlayScreen의 UI는 별도로 바꾸지 않았습니다.

## 유지한 것
일반 판 20/25/30개 목표와 60/75/90초, 연습/무한 도전의 시간 정책, 장애물·속도 곡선·충돌 물리·보상량·부활 거래·자동 결과 저장을 유지했습니다. 체감 난이도나 효과음을 실기기로 확인하기 전에 수치를 임의로 조정하지 않았습니다. 미디어 원본·결제 정책·서명키·Firebase 설정·기존 데이터·의존성도 변경하지 않았습니다.
