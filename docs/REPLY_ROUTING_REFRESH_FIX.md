# 마음냥 정원 답장 연결 수정

대상 버전: 1.0.11+14

## 확인한 원인

1. 감정별 완성 문안 72개는 소스에 있었지만, 기존 상황별 답장에 먼저 해당하면 새 문안 경로까지 도달하지 않았다.
2. 고양이 선택 ID는 답장 엔진에 전달되지 않았다. 고양이 이름은 서명에만 사용됐다.
3. 이전에 저장한 답장은 문안 파일을 교체해도 그대로 재사용됐다. 바깥쪽의 오래된 캐시가 갱신한 답장을 가리는 경로도 있었다.
4. 다른 주제에 남긴 부정 피드백이나 이전 엔진의 부정 피드백이 새 문안 선택까지 막을 수 있었다.

## 수정 동작

- 명확하게 표현한 감정에 맞는 완성 문안을 기존 상황별 조합보다 우선한다. 기존 72개 문안 본문은 변경하지 않는다.
- 선택한 고양이의 감정 ID를 전달한다. 본문의 명확한 감정을 우선하고, 선택 감정은 의미가 정확히 맞는 14개 ID에 한해 보조 정보로 사용한다. 우울을 단순한 슬픔으로, 평온을 걱정 해소로 바꾸는 식의 임의 대응은 하지 않는다.
- 인용, 다른 사람의 감정, 부정문, 불명확한 글에서 선택 감정만으로 단정하지 않는다.
- 기존 답장은 자동으로 덮어쓰지 않는다. 고양이 편지와 마음편지의 이전 답장에 **새 문안으로 답장 다시 받기** 버튼을 제공한다.
- 새 문안으로 갱신하는 데는 무료 답장 횟수를 차감하지 않는다. 받은 답장이 없는 편지는 기존 하루 제한을 유지한다.
- 갱신은 문안 엔진 버전별 한 번이다. 중복 요청은 같은 저장 결과를 돌려준다.
- 갱신 중에는 기존 답장을 표시하고, 실패하면 다시 시도할 수 있다. 편지 본문·날짜·정원 성장 기록은 삭제하지 않는다.
- 갱신 후 다시 열어도 예전 캐시가 새 답장을 덮어쓰지 않는다. 이전 답장에 대한 평가는 새 답장의 평가로 이어받지 않는다.

이 기능은 기기 안에서 문안을 고르는 방식이다. 서버 AI가 문맥 전체를 이해하는 기능으로 바뀐 것은 아니다.

## 젠스파크 적용 요청

이번 패치는 답장 연결과 갱신에 관한 수정입니다. 첨부 패치의 적용 안내 및 변경 파일 목록을 먼저 확인한 후 현재 프로젝트와 병합해 주세요. 최신 프로젝트에 별도 수정이 있다면 같은 파일을 무조건 덮어쓰지 말고 차이를 비교해 주세요.

로그인 연동과 달려라 몽이 분리 상태는 유지해 주세요. Android 서명키, Firebase 설정, 패키지명, 고양이 영상, 기존 편지 저장소를 삭제하거나 초기화하지 마세요.

수정 파일 반영 후 `flutter pub get`, `flutter analyze`, `flutter test`를 실행하고, 현재 서버의 배포 설정을 유지해 새 APK를 빌드해 주세요. 휴대폰에는 기존 앱을 삭제하지 않고 동일 서명키·패키지명의 새 APK로 업데이트해야 합니다. 웹 미리보기나 소스 파일만 바꿔서는 이미 설치된 휴대폰 앱이 변경되지 않습니다.

실기기 확인은 기존 편지 열기 → 예전 답장 그대로 표시 → 새 문안으로 답장 다시 받기 → 닫았다 다시 열기 순서로 진행해 주세요. 무료 이용 횟수가 추가 차감되지 않는지, 편지 본문과 정원 기록이 유지되는지도 확인해 주세요.

## 검증 결과

- Flutter 3.35.4 / Dart 3.9.2.

- 화면 통합 검증: 명시적 갱신, 중복 버튼 비활성화, 무료 횟수 유지, 이전 평가 초기화, 닫고 다시 열기, 실패 시 기존 답장 유지와 재시도, 다른 편지로 전환, 기록 화면의 고양이 답장 갱신.
- 최종 정적 분석: **error 0 / warning 9 / info 207**. 경고와 info가 남아 있으므로 분석 경고가 전혀 없다는 뜻은 아니다.

- 원본 72개 답장 문구 및 로그인·게임 분리 관련 원본 파일은 유지했다.
- 실제 Android APK 빌드·서명·휴대폰 설치 검증은 이번 작업에 포함하지 않았다.
- 새 답장도 로컬 문안 선택의 범위 안에서 동작한다. 사람의 맥락 이해나 무한한 새 문장 생성을 보장하지 않는다.
