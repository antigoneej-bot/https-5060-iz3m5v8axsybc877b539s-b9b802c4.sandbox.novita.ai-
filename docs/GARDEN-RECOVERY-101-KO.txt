수정 내용과 이유
1. garden_world_screen / garden_cultivation_tools
   100번의 겹치는 패널 구성을 정리하고 기존 아이콘+글자 도구를 기본 표시.
   도구 접기/펼치기를 명시. 접어도 캔버스 크기·카메라 배율은 유지. 접힌 자리의 높이는 보존됨.
   가꾸는/쉬어가는 정원 선택을 바로 표시. 쉬어가는 정원에는 편집·물주기를 노출하지 않음.
2. garden_world_view
   첫 진입은 동반묘를 화면 안에 배치. 명시적인 식물 위치 찾기는 저장 좌표를 우선.
   배경 효과 OFF와 고양이 자동 동작 OFF를 분리. 동작 줄이기·백그라운드·비활성 탭은 기존처럼 존중.
   현지 시각 18시~06시 밤, 분 단위 및 앱 복귀 시 갱신. 수동 낮밤 선택 유지.
3. garden_daily_care_screen / companion_together_dialog / pastel_garden_shell / home_screen
   힐링 상단의 함께 돌보기와 정원 마음돌봄을 연결. 선택한 6종 동반묘·저장 이름 사용.
   물 마시기·씻기·운동·산책을 고양이가 제안. 취소는 저장/보상 없음. 완료 확인은 기존 하루 보상 로직 사용.
   전용 물 마시기/씻기 신규 스프라이트는 없음. 기존 눈 깜박임·반응·놀이·걷기 에셋을 재사용.
4. cat_flow_tab_screen / meditation_flow_screen / mind_planting_screen / calm_letter_receipt
   실제 저장된 편지의 감정 고양이 ID를 심기에 전달. 동반묘 6종과 감정 고양이 37종을 혼동하지 않음.
   편지 완료 후 심기/돌봄 영수증 경유 심기 모두 검사. 씨앗은 심기 확인 전 소모하지 않음.
5. draft_service
   닫힌 Hive 초안 핸들을 다음 편집기가 재사용하던 문제 수정. 암호화 초안은 보존 후 재열기.
6. 영어 카탈로그
   새 제안/버튼의 자연스러운 영어 추가. 사용자가 직접 지은 이름은 변경하지 않음.
