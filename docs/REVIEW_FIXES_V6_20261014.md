# v6 재검토 결함 수정 · 2026-10-14

작업 기준은 v5 누적 패치와 일치하는 소스이며, 원본과 v5 사본을 먼저 보존했다. 이번 수정은 기록 안정성, 공개 상태의 정확성, 명상 완료 복구, 알림 동의, 이동·복원 흐름을 대상으로 한다.

## 1. 회고 저장

주간/월간 통계와 돌봄 화면이 같은 회고를 별도 컨트롤러로 열어 부모 화면 종료 때 옛 내용을 저장하던 문제가 있었다. 저장 키별 편집 상태와 쓰기 큐를 공유하도록 변경했다. 수정하지 않은 내용을 다시 쓰지 않으며, 저장 중 편집·삭제·화면 종료 순서와 실패 후 재시도를 처리한다. 암호화는 유지한다.

## 2. 공개 정원 상태

로컬 공개 플래그를 서버 상태로 오인하지 않는다. 인증된 UID의 공개 문서를 조회하는 API를 추가했다. 계정 변경, 응답 손실, 조회 실패는 미확인으로 표시하며 미확인 상태에서도 공개 중단이 가능하다. 닉네임 캐시만 UID별로 저장한다. 이전 계정/오래된 요청 응답은 무시한다.

새 조회 API는 백엔드 배포 후 동작한다. 이 작업에서는 서버에 배포하지 않았다. 구버전 서버에서도 기존 공개 중단 API는 사용 가능하며 조회 실패를 비공개로 표시하지 않는다. 비공개 편지 본문을 공개 정원에 추가하지 않았다.

## 3. 구버전 기록 이전

대상 박스가 비어 있지 않으면 모든 이전을 성공 처리하던 조건을 제거했다. 없는 키만 병합하며 기존 값은 유지한다. 쓰기·flush와 전체 확인 후 완료 표시를 저장한다. 실패는 다음 시도에서 이어간다.

이미 v1 이전 완료 표시가 있는 사용자의 누락 기록은 삭제한 기록과 구분할 수 없다. 자동 재복사는 하지 않으며 '이전 기록 확인'에서 종류별 건수와 삭제 기록 포함 가능성을 안내한 후 명시적으로 복구한다. guest 원본은 보존한다. 일반 백업에 아직 복구하지 않은 guest 원본을 추가하지는 않았다.

## 4. 명상

암호화된 기기 내 완료 대기열을 먼저 저장하고 과정 진행과 일일 보상을 반영한 뒤 대기열을 지운다. 재시작 후 복구하며 기존 멱등성으로 중복 진행·지급을 막는다. 실제 완료일을 보존한다.

첫 대기열 기록 자체가 실패하면 앱 강제 종료 후 복구를 보장할 수 없다. 이 경우 완료 저장으로 표시하지 않고, 앱을 닫기 전 다시 저장하도록 안내한다. 기기에는 저장했지만 과정/정원 반영이 남은 상태도 별도로 표시한다.

후기를 재진입하면 저장된 세션의 감정을 읽는다. 중복 선택 시 UI에 클릭한 값이 아닌 실제 저장 결과를 표시한다. 저장 대기 기록을 먼저 처리하고, 명상 완료 처리와 정원 쓰기 큐를 같은 순서로 잠근 상태에서 백업해 과정/보상 일부만 담기는 것을 방지한다.

## 5. 알림

동의 거절을 모든 리마인더와 답장 알림에 적용한다. 재방문/활동 알림 기본값은 꺼짐이다. 예약/취소/설정 변경은 하나의 직렬 큐에서 처리해 늦게 끝난 예약이 거절 뒤 되살아나지 않게 했다. 취소 한 건이 실패해도 나머지 채널을 정리하고 실패를 알린다. 앱 복귀 때 꺼진 채널의 잔여 예약도 취소하고, 재방문 기준 시각과 활동 알림을 갱신한다.

## 6. 정원·구독 확인·소리

정원에서 감정 고양이 선택으로 이동할 때 홈 탭을 바꾸고 정원 및 중첩 경로를 닫는다. 교체되어 폐기된 고요 모드의 context를 재사용하지 않는다. 공개 응원/전송은 내 정원을 먼저 표시한 뒤 진행하고 실패 시 재연결을 제공한다.

앱 전체의 첫 화면을 구독 서버 확인에 묶지 않는다. 처음에는 저장된 돌봄 상태를 부수효과 없이 표시하며, 보상 계산은 최초 구독 확인 시도가 끝난 뒤 기존 규칙대로 처리한다. 확인 후 Provider의 구독 상태만 갱신한다. 기존 지급량과 온도·게임 규칙을 바꾸지 않는다.

이전 효과음의 비동기 준비/재생이 종료·일시정지 뒤 늦게 완료되어 다시 소리가 나는 경로를 막는다.

## 7. 백업 복원

웹 파일은 바이트로, 네이티브 파일은 경로로 읽으며 같은 크기 제한을 적용한다. 복원 후 플랫폼 종료 호출 대신 앱의 이전 화면을 제거하고 저장소·캐시·Provider를 다시 구성한다. 재초기화 실패 시 최상위 화면에서 다시 시도할 수 있다. 재초기화 실패 중 자동 백업은 멈춘다.

## 검증 범위

`verification/v6-*`에 실제 실행 기록을 포함한다. 서버의 순수/모의 API 테스트, 순수 Dart 계약 검사, 실제 서비스 소스에 모의 저장소/플랫폼을 연결한 실행 검증, 문법·참조 검사, 패치 적용/충돌/재적용/보호파일 검증을 수행했다. 서로 다른 검증은 같은 제품 조건을 중복 확인할 수 있으므로 실행 개수를 기능 완성도 점수로 해석하지 않는다.

전체 Flutter 분석/테스트, 릴리스 빌드, 앱 화면/실기기/실제 Firebase/결제 확인은 이 환경에서 수행하지 않았다. Flutter SDK가 없다. 새 Flutter 회귀 테스트를 포함했으며 `python3 tool/verify_refinement.py --web`로 해당 환경에서 실행할 수 있다.

Node API VM 검사는 `node --experimental-vm-modules testing/api-regression.mjs`로 실행한다. 초기 실행은 VM 플래그 누락으로 실패했고, 올바른 플래그로 재실행해 통과했다. 상대 참조 검사에서 생성 파일의 주석 예시가 처음 누락 경로로 잡혔으나 실제 코드가 아니며, 실제 import/export/part 지시문 기준으로 수정하여 확인했다.

## 적용 환경에서 필요한 확인

1. 통계 → 같은 기간 돌봄 → 회고 수정 → 뒤로가기 → 앱 재실행 후 내용 유지.
2. 두 계정/두 기기에서 공개 상태 확인, 공개 중 응답 유실 및 공개 중단 재시도.
3. 알림을 거절한 뒤 재실행, 설정에서 한 종류만 켜기, 앱 복귀 시 미접속 알림 시각 갱신.
4. 명상 완료 → 앱 재시작 후 과정/보상 유지 및 중복 미지급, 후기 재진입의 값 일치.
5. 홈/고요 모드/게임에서 정원 진입 후 감정 고양이 탭으로 복귀.
6. Android/iOS/web 백업 가져오기와 복원한 정원 열기, 저장 중단 후 재시도.
7. 360/390px 실제 화면의 잘림과 버튼 접근, 고양이 걸음·그림자·빛 효과의 자연스러움.
