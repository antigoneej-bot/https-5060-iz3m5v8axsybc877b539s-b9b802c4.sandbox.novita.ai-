R92-01 사용 통계 OFF
- 새 앱 이벤트를 즉시 차단하고 OFF를 먼저 저장한다. SDK 중지 실패에도 저장된 OFF 유지.
- 초기화/ON/OFF/재시도를 직렬화하여 늦은 ON이 새로운 OFF 표시를 되돌리지 않게 한다.
- SDK 실패 시 적용 대기 안내/재시도. 앱 복귀와 재시작에서 OFF를 다시 적용한다.
- 실제 물리 저장 실패는 성공으로 처리하지 않으며 현재 프로세스에서는 이벤트 차단을 유지한다.
- 이미 SDK로 전달된 이벤트를 소급하여 취소하거나 전송된 자료를 자동 삭제한다고 주장하지 않는다.

R92-02 알림 OFF
- 아침/저녁/방문/목표/고양이 소식 모두 기존 설정 키에 OFF를 먼저 저장한다.
- OS 예약 취소 확인과 사용자의 OFF 선택은 별도 상태로 관리한다.
- 실패한 취소는 안내/재시도하며 재실행/복귀에서도 저장된 OFF를 기준으로 취소한다.
- 고양이 알림은 한 슬롯 취소 실패가 나머지 슬롯 취소 시도를 막지 않는다.
- 알림이 OFF인 돌보기·이름 변경은 네이티브 알림 초기화/취소를 기다리지 않는다.
  취소 재시도는 앱 시작·복귀·명시적 재시도에서 처리하여 돌보기 조작을 막지 않는다.
- 기존 시각/돌봄/성장/하루 발송 예산 기록을 유지하고 OFF로 보상/재화를 만들지 않는다.
- 실패한 시간 변경은 기존 시각을 보존한다. 새로 명시한 ON은 기존 권한 확인을 거친다.
- OS 취소가 실패한 동안 기존 알림이 도착할 수 있음을 안내한다. 시스템 알림 설정에서도 끌 수 있다.
- 앱이 종료된 동안 취소 재시도가 실행된다고 보장하지 않는다.
