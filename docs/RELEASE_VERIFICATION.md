## 실제로 확인한 핵심 동작

- 일반 편지와 마음 편지에서 고른 정확한 문장만 개인 식물 기억에 연결. 중복 저장 방지, 원본 삭제 후 열린 편집창의 재저장 차단.
- 나무의 기억에서 원문과 해당 달 기록집으로 이동. 오래 저장된 UTC 기록집의 날짜 호환성 유지.
- 간직한 말의 종류별 조회와 실제로 도움이 됐다고 남긴 돌봄 재선택. 열람만으로 실천 완료를 만들지 않음.
- 암호화된 실제 Hive 저장소에 쓰기 실패를 주입하여 삭제 직후의 늦은 실패, 연결 기록 복구, 동시에 대기한 새 기록 보존, 백업 일관성 검사.
- 첫 무료 기록집 이력의 삭제·백업·복원 유지. 정책 메타데이터를 사용자 기록 개수와 혼동하지 않음.
- 공동 나무 관계 종료 후 본인 메모 삭제, 이웃 재연결에 따른 예전 권한 부활 방지, 응답 유실 뒤 나가기·거절 재시도.
- 새 활동 확인과 동시에 새 활동이 도착해도 새 기록을 읽음으로 덮어쓰지 않음. 계정 전환 시 이전 내용 제거.
- 예약 성공 뒤 불필요한 조회 없이 확정 상태 표시, 정원 축소 방지, 기존 신청 취소, 삭제 중간 실패 뒤 운영자 재시도.
- 로그인·구독·백업·정원 성장 관련 기존 회귀 테스트도 전체 실행에 포함.

전체 정적 분석의 경고 6건은 기존 정원/돌보기/통계 미사용 선언과 개발용 도구의 테스트 API 사용입니다. 오류·경고가 모두 0이라고 표시하지 않습니다.

초기 웹 빌드는 생성된 커널 캐시 읽기 오류로 실패했습니다. 생성 캐시만 정리한 뒤 다른 Flutter 작업과 겹치지 않게 다시 빌드하여 성공했습니다. 실제 배포물에 적용한 옵션을 바꾸거나 아이콘 최적화를 끄지 않았습니다. Wasm 사전 검사에는 기존 의존성 호환성 경고가 남지만 최종 JavaScript 빌드는 성공했습니다.

## 이번 결과에 포함되지 않는 검증

- 운영 gardenApi 배포 및 실제 Firebase 권한 검증
- 기존 서명키를 이용한 Android APK/AAB 생성, Play 업로드·실제 설치
- 두 휴대전화 간 공동 나무·응원·예약·실제 구독 갱신
- iOS 및 Apple 결제, 실제 OS 공유 시트
- 클래스 참가비 결제·자동 할인, 일정 푸시 알림

새 서버 기능은 기존 gardenApi 환경에 배포하고 앱도 업데이트해야 합니다. 로그인 서버·구독 알림 서버의 재설정은 이 변경에 필요하지 않습니다. 기록 복구는 실행 중 발생한 저장 오류를 다루며 강제 종료·물리 디스크 고장에 대한 완전한 복구 보장은 아닙니다.
