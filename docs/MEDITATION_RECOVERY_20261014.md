# 명상 완료·후기 저장 보완

- 실제 완료일, 가이드, 진행 중인 과정/순서를 암호화 로컬 완료 대기열에 먼저 저장합니다. 그 뒤 과정 진행과 기존 하루 한 번 정원 보상을 적용하고 대기열을 지웁니다.
- 과정 또는 정원 저장이 실패하면 대기열을 보존해 앱 재시작 후 재처리합니다. 적용 후 대기열 삭제에 실패해도 같은 단계와 같은 날짜 보상은 중복 지급하지 않습니다.
- 최초 대기열 저장 자체가 실패한 경우에는 앱 종료 후 복구를 보장할 수 없습니다. 화면에 이를 구분해 표시하고 앱을 닫기 전 재시도를 안내합니다.
- 명상 목록 입구와 완료 후 화면에 저장 대기/실패와 재시도 버튼을 표시합니다.
- 이미 답한 세션을 다시 열면 실제 저장된 후기를 표시합니다. 중복 저장 요청도 기존 저장 값을 반환합니다. 최근 90개 표시 범위 밖의 세션도 직접 확인할 수 있습니다.
- 완료 대기열은 다른 기기에 이전할 보상 권한이 아니므로 백업 대상에서 제외합니다. 백업/복원 전 저장을 마치고, 백업 스냅샷 동안 완료 처리와 정원 트랜잭션을 순서대로 잠급니다.
- 명상 길이, 게임 시간, 보상 금액은 변경하지 않았습니다.

## 검증

실행: `python3 tool/verify_meditation_recovery.py --dart /path/to/dart`

원본 서비스 코드의 외부 플랫폼 의존성만 대체한 검증입니다. Dart 분석 오류 없음, 장애·재시작·중복 처리·백업 동시성·후기 일치 21건을 실행해 통과했습니다. Flutter UI나 실제 오디오/영상 실행을 대체하지 않습니다.

추가한 Flutter 회귀 검증: `test/meditation_completion_recovery_test.dart`. 기존 명상 테스트에도 암호화 저장소 초기화를 추가했습니다. 현재 환경에서는 Flutter SDK가 없어 Flutter 테스트와 실제 기기 실행은 미실행입니다.
