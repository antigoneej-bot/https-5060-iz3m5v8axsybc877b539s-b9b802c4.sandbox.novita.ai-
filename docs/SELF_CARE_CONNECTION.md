# 마음 돌아보기와 선택적 도움 연결

2026-10-13 구현. 이 문서는 이번 기능의 범위와 실제 검증 한계를 함께 설명합니다.

## 이용 흐름

홈 → 돌아보기 & 기록 → 돌아보고 돌보기, 또는 기록 탭의 같은 이름 카드에서 시작합니다.
편지를 저장한 뒤에도 선택한 감정을 이어받아 들어갈 수 있습니다.

1. 지금 느끼는 편안함 1~10과 감정 이름을 선택합니다. 둘 다 건너뛸 수 있고 기본 점수는 없습니다.
2. 상황·필요·나에게 할 말 중 질문 하나를 골라 돌아봅니다. 답을 쓰지 않아도 됩니다.
3. 쉬기, 작은 일 정하기, 사람에게 연락하기, 다정한 말, 간직할 순간 중 원하는 돌봄을 선택하고 저장합니다. 기록만 남겨도 됩니다.
4. 직접 해본 다음 해당 기록을 펼쳐 도움 여부를 남깁니다. 조금 도움 / 변화 없음 / 불편 / 모르겠음. 실천 후 편안함은 선택입니다.
5. 주간·월간으로 기록을 다시 보고, 도움이 됐던 돌봄을 다시 선택하거나 다음 기간의 작은 실천을 씁니다.

모든 핵심 자기보고·돌봄 후기·도움 찾기는 구독 여부와 무관하게 이용할 수 있습니다. 기존 유료 감정 분석의 권한 체계는 변경하지 않았습니다.

## 점수 의미와 통계

- 1은 매우 힘듦, 10은 매우 편안함입니다. 진단·우울도·위험도 점수가 아닙니다.
- 누락은 null입니다. 0점이나 실패로 처리하지 않습니다.
- 하루 여러 기록은 일평균으로, 기간 평균은 점수가 있는 날들의 일평균 평균으로 계산합니다. 원래 각 기록은 그대로 열람합니다.
- 기간은 월요일~일요일 또는 달력 월이며 현재 기간은 오늘까지만 계산합니다.
- 실천 후 점수는 기준 점수와 섞어 평균 내지 않습니다. 점수가 내려가도 ‘도움이 됐다’고 기록할 수 있습니다.
- 돌봄 후기 집계는 ‘돌봄을 선택한 날짜가 그 기간에 있는 기록’을 기준으로 합니다. 나중에 쓴 후기도 이 기록에 연결됩니다.
- 선택 횟수, 후기 횟수, 아직 후기 없는 횟수, 네 가지 답변을 모두 구분합니다. 활동 효과나 개선의 인과관계를 주장하지 않습니다.
- 기존 출석·편지·돌봄 보상 온도는 **돌봄 온기**로 이름을 바꿉니다. 값·보상 계산·저장 키를 보존하며 새 자기보고 점수로 변환하지 않습니다.
- 활동 온도를 긍정/부정 감정이나 회복 상태로 해석하던 UI와 설명을 제거했습니다. 기존 서비스 API는 호환용으로 남기되 심리 해석을 출력하지 않습니다.

## 개인정보와 백업

- `self_care_local_user__enc` Hive AES 암호화 저장소를 이용합니다. 기존 앱의 기기당 한 정원 구조를 따릅니다.
- 원래 편지 본문을 자동 복제하지 않습니다. 편지에서 이동하면 고른 고양이 ID만 전달합니다.
- 기존 백업 목록에 `self_care`를 추가하고 복원 시 점수 범위·필드·후기 일관성·키를 검사합니다.
- 기존 백업에 이 종류가 없어도 복원이 가능합니다. 새 기록을 포함한 백업은 업데이트된 앱에서 복원해야 합니다.
- 기기 로그아웃은 기록 삭제가 아닙니다. 각 돌봄 기록을 삭제할 수 있으며 이전 별도 백업에는 남을 수 있습니다.
- 기록은 공개 정원·Analytics·기관에 자동 전송하지 않습니다. 기존 암호화 서버 백업은 사용자가 켠 설정을 따릅니다.
- 주간·월간 직접 회고는 기존 암호화 draft 키를 재사용하여 이전 글을 보존합니다.

## 사람과 연결

- 정신건강복지센터: 국가정신건강정보포털 공식 기관 안내.
- 정신건강사회복지사: 별도 무자격 ‘정신복지사’ 서비스가 아니라, 기관의 전문요원에게 상담·생활 지원 가능 여부를 문의하도록 안내.
- 심리상담센터·명상센터: 외부 지도에서 기관 종류만 검색. 위치 권한이나 일기 데이터를 전달하지 않음.
- 외부 검색 결과는 마음냥 제휴·자격 검증·예약 확정을 뜻하지 않으며 신청은 해당 기관에서 진행.
- 실제 센터와의 제휴 예약, 기관용 내담자 화면, 전문 인력 매칭, 통계 전송은 이번에 활성화하지 않았습니다. 실제 제휴·운영 주체·동의 범위가 정해진 후 별도 연동이 필요합니다.
- 대한민국 긴급 도움은 109 / 112 / 119를 표시합니다. 전화 앱에서 사용자가 진행하며 해외 이용자를 위한 별도 디렉토리도 제공합니다.
