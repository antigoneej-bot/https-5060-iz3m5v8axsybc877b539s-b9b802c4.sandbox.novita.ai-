## 분리한 것

게임에서만 들어가던 웰니스 기능은 **나의 정원 → 기록·활동 → 정원에서 마음 돌보기**로 옮겼습니다. 고요 모드·호흡·마음 체크인·작은 실천·주간 편지·혼자 읽는 응원을 이용할 수 있습니다. 혼자 읽는 응원은 이웃의 실제 메시지와 구별해 표시합니다.

## 게임 없이 정원 가꾸기

- 기록 또는 명상을 완료하면 기존 공통 보상인 하루 한 번 씨앗 1개·빛의 정수 20개를 받습니다. 같은 날 중복 완료로 보상이 늘어나지 않습니다.
- 기본 장식은 정수 60개로 얻습니다. 과거에 해제하거나 획득했던 장식은 그대로 사용합니다.
- 구독 장식은 기존 권한 확인을 유지합니다. 이미 받은 장식의 소유도 유지합니다.
- 나무는 심은 후 하루 한 번 물을 주며 성장합니다. 게임 단계에 의존하지 않습니다.
- 과거 달리기로 얻은 성장분은 보존합니다. 이야기는 기록·명상으로도 열리도록 조정했습니다.

## 별도 게임 소스

별도 ZIP은 독립 개발용 Flutter 프로젝트입니다. 기존 달리기 엔진을 재사용하지만 마음냥의 Firebase·계정·결제·정원 저장소는 연결하지 않습니다. 새로운 게임의 저장 영역과 개발용 앱 ID를 사용합니다.

함께 제공한 `mongi-original-reference.zip`은 분리 전 게임 코드·원래 결과/상점/시즌 화면·관련 자산을 그대로 보관한 참고 자료입니다. 이 참고 ZIP 자체는 독립 실행 프로젝트가 아닙니다. 별도 앱 출시 시 필요한 디자인·상품·로그인·배포 설정과 실제 기기 검증은 별도 작업입니다.

## 적용

전체 소스를 적용할 때 Android 서명키, 실제 Firebase 설정, 로컬 비밀 설정은 현재 프로젝트 것을 보존하세요. 이 작업에서 그 설정을 변경하지 않았습니다.

작은 패치는 **직전 로그인 수정본** 기준입니다. `apply_patch.py`를 먼저 `--check`로 실행하세요. 다른 수정이 있으면 강제 덮어쓰기하지 않고 중단합니다. `--apply`는 변경·제거 대상 원본을 백업한 뒤 적용합니다. 단순 파일 복사로는 삭제 대상 게임 코드가 남을 수 있으므로 삭제 목록도 적용해야 합니다.

적용 후 `flutter pub get`, 분석·테스트, 새로운 APK/AAB 빌드가 필요합니다. 웹 미리보기를 갱신하는 것만으로 이미 설치된 폰 앱은 바뀌지 않습니다. 기존 앱은 삭제하지 않고 같은 서명키로 업데이트하여 기기 기록을 유지하세요.

로그인의 실서비스 키·서버 배포는 기존 `SOCIAL_LOGIN_SETUP_KO.md` 안내를 따릅니다. 이 분리 작업은 해당 외부 설정이나 실결제를 완료한 것으로 간주하지 않습니다.
