# 마음냥 정원 1.0.54 (57)

## 1. 경계를 지키는 색칠
- 기본은 ‘영역 채우기’입니다. 색을 고르고 하트·얼굴·꽃잎 등의 안쪽을 누르면 선택한 영역만 채웁니다.
- ‘붓으로 칠하기’ 또는 붓 굵기를 선택하면 붓을 사용합니다. 처음 누른 영역 안에서만 그려지며 다른 곳으로 손가락이 넘어가도 해당 영역 밖에 색이 묻지 않습니다. 다른 영역은 손가락을 떼고 새로 눌러 칠합니다.
- 지우개도 선택 영역 안에서만 작동합니다. 영역 채우기 모드의 지우개는 해당 영역 전체를 지웁니다.
- 윤곽선 자체를 누르면 칠하지 않습니다. 영역 안쪽을 눌러주세요. 도안의 원래 선을 기준으로 경계를 판별합니다.
- v56 이전에 이미 경계 밖에 그린 선은 지우지 않고 보존합니다. 새 붓질부터 경계를 적용합니다. 저장·되돌리기·다시하기·작품함·공유와 기존 세 도안은 유지합니다.

## 2. 색칠 전체화면
- 위쪽 전체화면 아이콘으로 그림 영역을 휴대폰 화면 전체에 펼칩니다.
- 회전 아이콘으로 가로·세로 전환, ‘확대·이동’으로 화면 이동과 확대, ‘그림 전체보기’로 도안 전체를 맞춰 봅니다.
- 전체화면은 처음에는 화면을 채워 크게 보이므로 일부가 화면 밖에 있을 수 있습니다. 이동하거나 그림 전체보기로 전부 확인할 수 있습니다. 그림을 찌그러뜨리지는 않습니다.
- 전체화면에서 팔레트 아이콘으로 도구를 접거나 다시 펼칩니다. 뒤로가기 또는 전체화면 닫기로 돌아갑니다. 화면을 나가면 직접 설정했던 방향 제한을 해제합니다.

## 3. 가로 정원 도구
- 풍경은 가로 화면 전체를 계속 채웁니다.
- 위쪽에는 정원 구역 이동·보기 설정, 아래쪽에는 돌보기·꾸미기·추억 도구가 표시됩니다.
- 도구를 펼치면 물주기, 배치, 씨앗, 장식, 연결된 열매 정원·창고·기억의 나무·응원 꽃 기능을 사용할 수 있습니다. 도구가 길면 도구 안에서 스크롤합니다.
- 고양이 보기·확대·축소, 세로 복귀·뒤로가기는 유지됩니다.

## 4. 테스트 온보딩
- 이 AAB에는 TEST_SHOW_ONBOARDING=true를 넣었습니다. 기존 사용자도 앱의 새 시작 세션에서 웰컴 온보딩이 다시 나옵니다. 단순히 다른 앱에 갔다 돌아올 때 반복 표시하지 않습니다.
- 이름 입력에는 기존 동반묘 이름을 불러옵니다. 기존 편지·정원·구독·온보딩 완료 기록을 삭제하지 않습니다.
- 정식 출시 빌드에서는 TEST_SHOW_ONBOARDING을 빼거나 false로 빌드하면 기존 최초 온보딩 동작으로 돌아갑니다. 테스트 구독 개방도 계속 유지했습니다.

## 5. 메뉴 간소화
- 홈·정원·마음돌보기·기록과 모든 기능의 메뉴 타일은 설명을 빼고 제목 중심으로 표시합니다.
- ‘모든 기능 둘러보기’의 안내와 실제 사용법·전체 기능 화면 설명은 유지합니다.
