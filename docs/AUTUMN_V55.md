# 마음냥 정원 1.0.52 (55)

## 이번 변경

- 홈의 파스텔 디자인 위에 고양이 얼굴 물방울, 작은 반짝임, 천천히 내려오는 옅은 낙엽을 더했습니다. 장식은 터치를 가로막지 않습니다.
- 큰 화면 카드와 메뉴 박스가 약 2~4픽셀 정도로 부드럽게 떠다닙니다. 앱이 백그라운드로 가거나 다른 화면에 가려질 때 정지합니다. 기기의 움직임 줄이기와 앱의 정원 움직임 설정을 존중합니다.
- 첫 번째 홈의 ‘기록과 모든 기능’을 빼고 ‘명상 · 힐링’을 넣었습니다.
- 네 번째 화면은 ‘기록과 모든 기능’으로 바꾸고 모든 기능·편지 기록을 앞에 배치했습니다. 이웃 정원·받은 선물·카드 교환도 이 화면에서 이어서 이용합니다.
- 가로 정원은 작은 3:1 비율 틀을 없애고 화면 전체를 채웁니다. 상단 제목줄과 하단 도구줄이 정원을 줄이지 않도록 버튼을 정원 위에 겹쳐 놓았습니다.
- 원래 정원 비율을 유지하면서 화면을 채우므로 양옆의 나머지 공간은 손가락으로 끌어서 봅니다. 확대·축소와 고양이 보기 버튼을 제공합니다.
- 가로 보기에서는 아직 열리지 않은 공간도 큰 안내판 대신 작은 잠금 안내로 표시해 풍경을 가리지 않습니다. 성장에 따른 잠금 조건은 유지합니다.
- 가로 화면 왼쪽 위에서 세로로 돌아가거나 정원을 나갈 수 있습니다. 나가면 화면 방향 제한을 해제합니다. 운영체제의 상태 아이콘·내비게이션 표시 방식은 기기에 따릅니다.
- 관련 사용법도 변경했습니다.

## 배포

패키지명은 기존 com.mysticcat.journal이고 버전 코드는 55입니다. 기존 업로드 서명을 유지합니다. 구독 기능 테스트 개방도 유지합니다. 이번 변경에는 서버 재배포가 필요하지 않습니다.

제공 AAB는 Play Console에 올리는 파일이며 휴대폰에 직접 설치하는 APK가 아닙니다. 이 작업에서 Play 배포와 실제 휴대폰 설치 시험은 수행하지 않았습니다. 변경 내용은 새 버전을 배포하고 휴대폰에서 업데이트한 뒤 확인할 수 있습니다.

자동 검증 결과는 함께 제공한 Verification.json에 있습니다. 실기기에서 가로 회전, 세로 복귀, 기존 기록 유지, 배경 효과와 정원 움직임 설정을 확인해 주세요.
