기준: 1.0.94+97 / 01aa875c33030913e00a7e062dfce5854428c76f
97번 원본 및 APK/AAB/ZIP은 그대로 두고 fix/mind-followup-98 별도 브랜치에서 작업했습니다.

변경
1. 감정 카드의 화면 낭독기 실행 동작을 연결했습니다. 일반 터치와 같은 감정 선택을 수행합니다.
2. 이미 심은 식물에는 '이 식물에 마음 남기기'로 감정·선택적 한마디만 추가합니다. 씨앗/정수/좌표/성장/물주기를 변경하지 않습니다. 여섯 종류를 모두 심으면 이미 심은 식물을 먼저 보여줍니다.
   기존 암호화 식물 추억 저장소와 직렬 저장/실패 복구를 사용합니다. 같은 초안 ID의 재시도/연속 터치는 한 번만 저장합니다. 계정이 바뀌면 저장하지 않고, 식물당 기존 60개 제한에서는 이전 기록을 지우지 않고 안내합니다.
3. '추억 보기'는 새로 작성하던 마음을 유지한 채 기존 추억 창을 엽니다. 위치 보기는 저장 동작이 아니며, 저장을 마치면 정원에서 해당 식물 위치를 보여줍니다.
4. 기존 기억의 나무로 가는 안내 버튼은 '기억의 나무 보기'로 구별합니다. 씨앗이 없으면 기존 마음 기록/명상으로 이동했다 돌아올 수 있습니다. 새 보상이나 보상 통합을 만들지 않습니다.
5. 정원 설정의 배경 효과/고양이 움직임/오류 안내를 영어에 연결했습니다. 사용자 이름·개인 기록은 원문입니다.
6. 작은 화면/큰 글자에서 마음 선택의 질문과 고양이 카드 높이를 조절하고 '가로 보기' 라벨을 짧게 했습니다. 접근성에는 전체화면 동작 이름을 유지합니다. 실제 정원의 그림·좌표·카메라·성장 표현은 유지합니다.
7. 동작하지 않던 전체 초기화 카드, 확정되지 않은 보상 통합 예고 문장, 전체 기능 상단의 큰 인사 카드를 제거했습니다. 전체 기능 36개와 검색/분류는 유지합니다.

보존
기존 기록, 백업 구조, 37종 감정 고양이, 6종 동반 고양이/이름/교감, 실제 정원, 이웃, 로그인, 구독 상품/가격, 서명키, 잠금 파일과 빌드 스크립트 LF 유지.
색칠의 기존 작품/보존용 소스, 예약 변경 소식, 고양이 코드 비교는 삭제하지 않았습니다.
서버 소스/운영 설정 변경이나 배포, 스토어 업로드, USB 재시도는 하지 않습니다.
