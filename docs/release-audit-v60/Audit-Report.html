PRIV-02상 · 공개 안내 누락공개 방침 URL과 외부 삭제 경로가 확인되지 않음. 검증된 URL·문의처를 빌드 설정으로 주입하고 앱에서 접근하도록 추가. 국외 처리와 보관 범위의 미확정 부분 표시.공개 페이지는 배포하지 않음. 포함된 초안을 그대로 게시하면 안 됨.
SEC-02중 · 백업/로그Android 추출 제외 규칙의 path를 명시하고 구형 백업 제외 도메인을 보강. cleartext 통신 명시 차단. 시작 실패의 예외·스택은 디버그에서만 출력.암호화와 TLS가 루팅 기기·악성 키보드·스크린샷까지 보호하지는 않음. OS 실제 전송 동작 미검증.
BILL-03중 · 테스트/실결제 혼동서버 entitlement에 Google 응답의 testPurchase 존재 여부를 isTestPurchase로 남김.테스트 구매도 테스트 권한 검증에 사용되며 실매출 성공 증거로 쓰면 안 됨. 오래된 entitlement는 다음 검증에 필드가 추가됨.
UGC-01상 · 미완료닉네임·공동 나무 메모 등 UGC가 있고 신고·차단 코드는 존재하지만 업로드 전 버전 있는 이용약관 동의 및 지속적 운영자 신고 처리 체계는 확인되지 않음.코드/운영 추가 보완 필요. 단순히 신고 버튼이 있다는 이유로 적합 판정하지 않음. 이번 버전에서 임의의 연령 제한이나 법적 약관을 확정하지 않음.

3. 개인정보·저장·접근 제어 분석

  • 편지·감정·초안·개인 기억·기록집은 Hive 암호화 저장. 키는 FlutterSecureStorage에 보관. 이름·일부 설정·그림 색칠·카운터 등은 SharedPreferences 등 앱 전용 저장소도 사용하므로 “모든 데이터가 별도 암호화”라고 표현하지 않음.
  • 로컬 사용자는 local_user이며 Firebase 계정과 기기 데이터 저장 주체가 자동으로 일치하는 구조가 아님. 한 기기 한 정원, 로그아웃 시 로컬 기록이 남는 정책. 계정 변경 때 클라우드 소유자 검사와 응답 소유자 검사가 있음. 공용 기기에서는 앱 잠금과 기기 기록 삭제를 따로 안내해야 함.
  • Firebase Authentication과 Google / 카카오·네이버·Facebook 연결 코드가 존재. 익명 가입 또는 이메일 가입을 실제 앱 주 흐름으로 사용한다고 기재하지 않음. 제공사 활성화·클라이언트 ID·리디렉션·서명 지문은 콘솔 확인 필요.
  • 서버는 Firebase ID 토큰 검증(취소 확인 포함), App Check 토큰과 Android app ID 대조, 요청 크기 제한, 계정별 속도 제한 및 삭제 잠금을 사용. Firestore·Storage 규칙 파일은 모든 직접 클라이언트 읽기/쓰기를 거부하고 Admin SDK API로 처리. 실제 배포 규칙·IAM이 동일하다는 보장은 없음.
  • 공개 정원은 허용된 나무·배치·장식 필드만 받아 편지 본문·감정 통계·개인 날짜를 거부. 이웃 및 공동 나무는 관계·초대 수락·차단 상태를 검사. 자동화 테스트는 메모리 DB 대역이며 실제 Firebase 침투 테스트가 아님.
  • 백업은 PBKDF2-HMAC-SHA256 600,000회 + AES-256-GCM, 암호 12자 이상. 서버에는 암호화 envelope만 전송. 서버 최근 10개 보관 코드, 구독 종료 후 복원 허용. 비밀번호 분실 시 새 기기 복원 불가. 앱 삭제/재설치로 자동 복원된다고 보장하지 않음.
  • 복원은 허용한 개인 기록만 병합하고 기존 레코드 우선·복원 저널로 중단 후 재개. 구매 권한·로그인·OS 권한을 백업에서 덮어쓰지 않음. 저장 형식 변경이나 데이터 일괄 삭제 없음.
  • 서버 계정 삭제는 최근 재인증 후 백업·공개 정원·이웃·공동 나무·예약·알림·카드·방문 정보를 정리하고 Auth 사용자를 삭제. 원문 구매 토큰과 uid를 삭제하고 재사용 방지 해시 흔적 유지. 소셜 세션 TTL, 이미 보낸 푸시 작업 및 Cloud 로그의 보유/삭제 정책은 운영 설정 확인 필요.
  • Analytics 기본 비활성, 사용자가 공유를 켜면 기능 이벤트와 제한된 필드 전송. AdMob 설정이 유효해야 광고 요청 가능하며 UMP 및 비맞춤 광고 사용. FCM은 선택한 소식 알림용 토큰 처리. 진단/기기/IP 처리 범위는 SDK 및 실제 설정과 함께 신고해야 함.
  • 앱 서비스 코드에서 http:// 주소 및 포함된 개인키 리터럴은 이번 제한적 정적 검색에서 발견하지 못함. Firebase 공개 API 식별자 자체를 비밀키로 오인해 삭제하지 않음. 클라우드 비밀 저장소·키 제한·서비스 계정 권한은 미검증.

4. 복구·마이그레이션 계획

  • v59 원본 ZIP을 별도 백업하고 Git 기준 커밋 후 audit/release-security-v60 브랜치에서 수정. assets 296개가 원본과 바이트 단위 동일. 캐릭터·정원·음악·애니메이션·내비게이션 코드는 이번 변경 대상에서 제외.
  • 데이터 스키마 변경 없음. Hive 암호화 알고리즘·키 이름·박스명 유지. 기존 평문→암호화 이관은 원본을 성공 확인 뒤에만 삭제하는 기존 순서를 유지하며 실패 파일 절단만 방지.
  • 손상/키 불일치 시 앱 데이터 초기화나 재설치를 먼저 하지 말 것. 원본 파일·키 접근 가능 상태를 보존하고 사용자가 갖고 있는 정상 암호화 백업으로 복원을 검토. 내보낸 백업 암호 확보 후 복원 테스트. 파일 자동 절단/키 강제 교체를 복구 방법으로 쓰지 않음.
  • 롤백은 소스 기준 커밋으로 재빌드하되 Android versionCode는 설치된 버전보다 높게 설정하고 기존 서명 유지. 이전 AAB를 바로 설치해 다운그레이드하거나 앱을 삭제하지 않음. 서버도 배포 전 실제 현재 소스를 확보·비교한 후 필요한 변경만 병합.

6. 정책·콘솔 점검

  • 현재 확인한 공식 정책에서 2026-08-31 이후 신규 앱/업데이트는 API 36 이상 요구. 이 프로젝트 Flutter 환경의 최종 targetSdk는 빌드 manifest에서 다시 확인. Billing 8 지원 기한은 2027-08-31로 안내되어 있어 12월 출시 시 지원 대상이나, 로컬 포크의 실기기 호환성 검증은 별도.
  • 37마리 귀여운 고양이 이미지가 실제 타깃 연령을 결정하지 않음. 운영자가 대상 연령을 확정하고 스토어 표현·광고·UGC·연령 안내를 일치시켜야 함. 현재 보였던 17세 표시를 콘텐츠 등급 설문이 정확하다는 증거로 쓰지 않음.
  • UGC 신고/차단 테스트와 별개로 금지 콘텐츠 약관, 업로드 전 동의, 신고 담당자·처리 기한·삭제/제재·이의제기 절차가 필요. 공동 메모/닉네임/고양이 이름 등 실제 텍스트 기능을 설문에 반영. 연령 확인 방식은 대상 연령 확정 후 구현 검토.
