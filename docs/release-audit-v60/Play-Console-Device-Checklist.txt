서버 적용 순서
1. gcloud functions describe gardenApi --gen2 --region=asia-northeast3 --project=mycatapp-99bc8
   실제 소스 위치·런타임·환경·서비스 계정 확인. 비밀 값은 공유하지 않음.
2. 현재 배포 소스를 백업하고 backend-changes.patch와 비교. 이번 소스가 서버 최신과 다르면 강제 덮어쓰지 않고 병합.
3. 테스트 환경에서 node --test, 실제 두 계정·Play 테스트 구매·App Check·삭제 시나리오 실행.
4. gardenApi, playNotifications에 변경 적용. 기존 IAM/Secret/환경변수를 보존. firestore/storage 규칙도 실제 비교.
5. 운영 전 테스트 플래그 해제, 버전/설정 기록 및 롤백 절차 확보.
