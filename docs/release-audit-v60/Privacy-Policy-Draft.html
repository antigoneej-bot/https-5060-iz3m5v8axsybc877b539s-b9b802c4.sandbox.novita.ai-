2. 보유·삭제·복원

  • 기기 기록은 사용자가 삭제하거나 앱 데이터를 제거할 때까지 보관합니다. 앱 제거 시 복원을 보장하지 않습니다. 내보낸 암호화 파일과 암호 또는 선택한 서버 백업이 있어야 복원할 수 있습니다.
  • 서버는 최근 10개 암호화 백업을 보관합니다. 구독 종료 후에도 기존 백업 복원을 허용합니다. 기록 개별 삭제가 과거 백업·이미 공유한 파일을 자동 삭제하는 것은 아닙니다.
  • 기록 보관과 백업의 서버 계정 삭제는 서버 데이터 정리와 Auth 삭제를 요청합니다. 로그아웃은 삭제가 아닙니다. 기기 기록 및 외부 공유 파일 삭제, Play 구독 해지는 별도입니다.
  • 계정 삭제 후 중복 구매 사용 방지용 해시 표식이 남을 수 있습니다. 관련 법적 근거·보유 기간 [운영자 확정]. 신고 기록, 접속/진단 로그, 소셜 세션 TTL, 푸시 작업, 제공사 백업의 구체적 보유 기간 [운영자 확인]. 기간을 임의로 정해 구현된 것처럼 쓰지 않습니다.
  • 외부 계정·데이터 삭제 요청: [실제 작동하는 HTTPS URL]. 본인 확인 방법 [확정], 처리 기한 [확정], 보존 예외 및 결과 안내 [확정]. 외부 요청은 앱 재설치를 요구하지 않아야 합니다.

4. 동의·철회·보호 조치

  • 사용 통계는 기본 꺼짐이며 기록 보관과 백업에서 변경합니다. 광고 개인정보 선택은 관련 지역 UMP 화면과 앱의 광고 개인정보 선택 경로에서 관리합니다. 알림은 앱 설정 및 OS 권한에서 끌 수 있습니다.
  • 공개 범위와 목록 노출·선물 받기는 냥이 마을 설정에서 변경합니다. 기존 공동 메모/공유 파일은 해당 기능에서 직접 삭제해야 합니다. 소셜 제공사 연결 해제와 앱 계정 삭제가 같은 행위인지 오인하지 않도록 안내합니다.
  • HTTPS, 주요 기록의 기기 암호화, 비밀번호 기반 백업 암호화, 사용자별 서버 검증 및 접근 통제를 사용합니다. 기기 보안 저장소의 키나 백업 암호를 잃으면 복원할 수 없습니다.
