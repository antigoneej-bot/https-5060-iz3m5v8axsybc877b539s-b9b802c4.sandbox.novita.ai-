# 마음냥 정원 답장·마음편지·구매 복원 추가 보완

버전: 1.0.12+15 / 로컬 답장 엔진 버전: 3
기준 소스: 직전 제공본 1.0.11+14

## 답장 선택

- ‘영화나’ 등의 단어 일부를 ‘화나’로 읽던 분류를 수정했습니다.
- 다른 사람에게 실망한 글을 자기비난으로, 아들 등 타인의 감정을 작성자 감정으로 단정하는 경로를 보완했습니다.
- ‘질문하지 마’와 같은 듣기 요청은 뒤에 의문문이 있어도 우선합니다.
- 명시적인 현재 자해·자살 표현에는 선택한 고양이나 일반 감정 문안보다 도움 안내를 먼저 표시합니다. 본인의 이야기와 타인의 이야기를 구분하고 부정·과거·허구·인용 표현의 오인식을 줄였습니다.
- 이 기능은 한국어 표현 규칙에 따른 보조 안내입니다. 진단·위험도 평가·응급 감시가 아니며 모든 표현이나 문맥을 인식하지는 못합니다. 기록을 외부에 보내거나 자동으로 연락하지 않습니다.
- 도움 안내는 기존 앱의 도움받기 화면으로 연결합니다. 편지 작성 중, 저장 확인, 기록 상세와 마음편지에서 이용할 수 있고 답장 도착 시각이나 유료 횟수를 기다리지 않습니다. 인식된 위험 표현에 과거의 일반 답장이 함께 나와 모순되지 않도록 표시를 분리하되 저장한 원문과 답장은 보존합니다.
- 기존 72개 감정 답장 원문을 유지합니다. 새 엔진은 문안 선택과 연결을 보완한 것이며 서버 생성형 AI로 바뀐 것은 아닙니다.

지원 문구 작성 참고: 미국 NIMH의 판단 없이 듣기·안전 확보·주변 사람 및 전문 지원 연결 원칙. 국내 전화번호를 이 자료에서 가져오지 않았고 기존 도움 화면으로 연결합니다.

## 저장과 삭제

- 사용자 화면의 대기 시간과 실제 저장 작업의 종료를 분리했습니다. 화면 대기가 끝나도 진행 중인 쓰기·복구가 끝나기 전에는 후속 읽기나 쓰기가 끼어들지 않습니다.
- 대기 중 시간 초과되어 시작하지 못한 요청은 나중에 몰래 실행하지 않습니다. 이미 시작한 비취소식 저장은 끝까지 처리하므로 시간 초과 뒤 재시도하면 저장 결과부터 확인합니다.
- 최근 답장 순서를 문자열 키 순서 대신 저장 순번과 날짜로 정합니다. 고양이 편지와 마음편지를 함께 고려합니다. 날짜 정보가 없는 구형 데이터는 재현 가능한 키 순서를 보조로 사용합니다.
- 원문 존재 여부와 내용 일치를 확인하며 원문 삭제와 답장 삭제를 같은 작업 순서로 처리합니다. 삭제한 편지를 쥐고 있던 이전 화면이 답장을 되살리는 경로를 차단합니다.
- 기존 답장을 읽는 전용 경로를 마련했습니다. 읽기만으로 새 답장이나 무료 횟수 사용이 발생하지 않습니다.
- 엔진 버전 3에 대해 기존 답장을 명시적으로 다시 받는 기능을 유지합니다. 이 갱신에는 무료 횟수를 추가 차감하지 않으며 실패하면 기존 답장을 보존합니다.

## 마음편지 이용 흐름

- 목록을 열거나 스크롤할 때는 저장된 답장만 읽습니다. 답장이 없으면 사용자가 ‘답장 열기’를 눌러 생성할 편지를 선택합니다.
- 새 글을 쓰지 않아도 ‘지난 마음편지’에서 종류별 기록으로 들어갈 수 있습니다.
- 원문을 펼쳤다는 이유로 답장을 읽음 처리하지 않습니다. 답장이 실제 화면에 표시되었을 때 읽음 처리하며 화면 밖 카드와 구분합니다.
- 도착 시각 타이머와 앱 복귀 시 갱신을 추가했습니다. 홈의 마음편지 배너도 저장소 변경을 반영합니다.

## 구독 복원

- 장식·감정 공유 프레임·구독 화면에서 로그인 확인 후 복원합니다.
- 복원 완료, 활성 구매 없음, 확인 불가, 로그인 필요를 구분해 안내합니다. 통신 실패를 복원 완료라고 표시하지 않습니다.
- 요청별 결과 객체를 사용하고 중복 탭과 동시 복원을 정리했습니다. 확인 불가만으로 기존 구독 권한을 제거하지 않습니다.
- 기존 bool 복원 API도 유지합니다. 상품 ID, 결제 서버 설정, 독립 아이템 구매 구현은 변경하지 않았습니다.

## 범위와 남은 확인

- 로그인 구현·몽이 게임 분리 상태·정원 그래픽·영상 자산을 유지합니다. 서명키, Firebase 프로젝트 설정, 패키지명을 변경하지 않습니다.
- 실제 Google Play 상품·검증 서버를 사용하는 구독 구매 및 복원, 소셜 로그인 운영 설정, 서로 다른 휴대폰의 공개 정원·선물 통신은 실제 환경에서 별도 확인해야 합니다.
- 독립 아이템 결제는 아직 별도 구현 및 상품 설정·서버 검증이 필요합니다. 이번 변경을 독립 아이템 구매 완성으로 해석하면 안 됩니다.
- 설치된 휴대폰 앱에는 같은 서명키로 새 APK/AAB를 빌드해 업데이트해야 반영됩니다. 소스나 웹 미리보기만 바꾸어서는 설치된 앱이 바뀌지 않습니다.
