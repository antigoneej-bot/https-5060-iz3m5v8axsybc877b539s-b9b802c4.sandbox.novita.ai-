마음냥 정원 95 — 실사용 검증안 (아직 실행하지 않음)

목적
설명 없이 '내 고양이 → 감정 기록 → 실제 정원 → 지난 기록'을 이해하는지 확인합니다.
첫 1분 테스트는 5~10명 정도의 작은 내부 테스트부터 시작할 수 있습니다.
아래 인원·기간은 제안이며 실제 모집/실행 결과가 아닙니다.

준비
Play 내부 테스트에서 업데이트합니다. 기록이 있는 앱을 삭제하지 않습니다.
서명 오류가 나오면 설치를 멈추고 오류 문구만 전달합니다.
개인 기록이 있는 기기에서 삭제·복원·계정 삭제를 테스트하지 않습니다.
공유할 캡처에는 이메일·개인 기록 본문·초대 코드를 가립니다.

첫 사용 — 개발자가 경로를 먼저 설명하지 말고 관찰
1. 앱을 열었을 때 가장 먼저 무엇을 하고 싶은지 말해 주세요.
2. 지금 마음을 고르고 짧은 테스트 기록을 남겨 주세요.
3. 저장이 끝났는지 어떤 표시로 알 수 있었나요?
4. 정원에 들어가 이미 심어진 식물을 찾아 주세요.
5. 오늘 물을 줬다면 홈에 돌아와 표시를 눌러 같은 식물을 찾아 주세요.
6. 오늘 기록과 지난주 감정 흐름을 각각 다시 찾아 주세요.

업데이트 보존 확인
내 고양이의 외형·이름, 기존 편지, 식물 위치·성장·오늘 물주기 상태, 보유 재화가
업데이트 전후 같은지 확인합니다. 일부러 물을 중복 지급하거나 보상을 초기화하지 않습니다.
기존 전시 작품이 있는 사람은 정원 액자가 유지되는지만 확인합니다.
색칠 메뉴와 '색칠 완성 추가 카드' 안내가 나타나지 않아야 합니다.

작은 화면/큰 글자
삼성 Buddy3를 포함한 작은 폰에서 글자를 크게 설정하고 마음 기록·정원·홈 요약 버튼을
눌러 봅니다. 길면 스크롤되어야 하며 버튼이 겹치거나 글자를 강제로 작게 만들면 안 됩니다.
한글/영어를 바꿔도 사용자가 지은 이름과 직접 작성한 글은 그대로여야 합니다.

7일 사용 후 질문
가장 자주 돌아온 이유는 고양이/기록/정원/이웃/그 외 중 무엇이었나요?
다시 찾기 어려웠던 기능과 불필요한 안내가 있었나요?
물주기 표시와 실제 식물 상태가 어긋난 적이 있나요?
주간·월간 만화책이나 정원 기록집을 스스로 찾아봤나요?
기능을 더 추가하기 전에, 어떤 한 가지를 먼저 고치면 좋겠나요?

기록 양식
앱 버전 / 기종 / 언어 / 글자 크기 / 시도한 작업 / 성공 여부 / 막힌 위치 / 오류 문구
첫 기록 완료 시간, 도움을 요청한 횟수, 다음날 다시 연 이유를 자발적으로 기록합니다.
편지 본문·비밀번호·결제 영수증 원문·인증 토큰은 수집하지 않습니다.
실제 관찰 결과 없이 D1/D7 유지율이나 유료 전환율이 개선됐다고 결론내리지 않습니다.

이번에 제외한 항목
두 별도 테스트 계정의 이웃 공유/차단/철회, 실결제, 서버 배포, iOS 검증은 별도입니다.
기존 사용자에게 확인받은 동작을 95번의 새 실행 결과로 재사용하지 않습니다.
