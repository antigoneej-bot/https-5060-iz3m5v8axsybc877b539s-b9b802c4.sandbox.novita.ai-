# 마음냥 정원 — 생활과 기억

## 적용한 기능

- 몽이는 기존 24초 환경 애니메이션 시간축에 맞춰 꽃으로 다가가고, 나비를 바라보고, 벤치에 앉아 눈을 감고 쉰다. 저장된 꽃과 벤치 위치를 사용한다. 모션 줄이기와 앱 비활성 상태에서는 지속 애니메이션을 멈춘다.
- 기억의 나무는 기존 정원 성장 기록(recordDays)의 서로 다른 작성 날짜 수로 자란다. 감정의 종류나 긍정 여부는 성장 조건이 아니다. 같은 날 여러 편지를 써도 하루이며, 삭제한 편지는 현재 목록에서 제외하지만 이미 적립된 성장은 유지한다. 나무를 열면 현재 보관된 편지만 날짜별로 다시 볼 수 있다. 삭제한 본문을 따로 보관하지 않는다.
- 응원함에서 실제 수신한 응원을 꽃으로 남길 수 있다. 서버에서 받은 응원만 계정별로 보관하며 같은 응원은 한 번만 심는다. 꽃은 장식이고 기존 선물 수령/재화 지급과는 별개다. 꽃 보관함은 암호화된 로컬 저장소 및 기존 백업에 포함된다.
- 벤치 또는 '잠깐 쉬기'를 누르면 조작 메뉴를 숨기고 몽이가 쉰다. '쉬기 마치기'로 언제든 돌아온다. 기존 소리 설정을 존중하며 휴식에서 시작한 자연음은 종료/백그라운드 전환 시 정리한다.

## 공개 범위

공개 정원에는 기억의 나무 성장 단계(0~4)와 응원 꽃밭 유무만 저장한다. 편지 내용, 감정, 기록 날짜, 정확한 기록 일수, 받은 응원 내용 및 수신 개수는 새 공개 필드에 포함하지 않는다. 다른 사람은 외형만 보고 개인 보관함을 열 수 없다. 공개 모습은 기존 정원 공개/갱신 동작에서 최신 스냅샷으로 저장된다. 자동 실시간 동기화는 추가하지 않았다.

## 배포 순서

1. 기존 프로젝트 절차에 따라 `backend`의 변경된 공개 정원 검증 및 저장/조회 함수를 먼저 배포한다. 새 선택 필드 `memoryTreeStage`, `hasCheerFlowers`를 허용해야 한다. 이전 스냅샷은 기본값 0/false로 읽으므로 호환된다.
2. 이후 업데이트된 Flutter 앱을 빌드/배포한다. 구 서버는 새 공개 필드를 거절하므로 앱보다 서버를 먼저 반영해야 한다.
3. 실제 기기에서 기존 계정 두 개로 공개/방문/응원 수신/꽃 심기/재실행을 확인하고, 소리 켜기·끄기 및 휴식 중 백그라운드 전환을 확인한다.

이번 작업에서는 운영 서버 배포, 실제 계정 간 전송, 네이티브 설치 및 오디오 재생 검증은 수행하지 않았다. 기존 이미지 기반 2.5D 정원을 확장했으며 3D 메시 엔진으로 교체한 작업은 아니다. 함께 기르는 우정의 꽃은 이번 범위에 포함하지 않았다.

## 검증

- Flutter 기존 정원/성장/백업 회귀 묶음 27개 통과.
- 최종 생활·정원 UI·눈 깜빡임 테스트 14개 통과: 날짜 중복/삭제, 저장 재시작/중복, 계정 구분, 개인 기록 비공개, 휴식 진입/종료 등.
- 백엔드 테스트 41개 통과 및 Node 구문 검사 통과.
- 변경 기능 중심 정적 분석에 오류/경고 없음. 기존 cloud_service.dart의 중괄호 스타일 안내는 남아 있다.
- `expanded-garden-overview.png`, `garden-rest.png`는 Flutter 위젯 렌더링 결과다. 캡처용 테스트 Scaffold의 상단 제목은 남지만 실제 휴식 화면의 AppBar는 숨긴다.

## 정원 선물·동작 개선 (2026-10-05)

몽이 이동은 별도로 제작한 네 프레임 걷기 이미지로 바뀌었다. 이동 방향에 맞춰 좌우가 바뀌며, 이동 거리로 시간을 계산한다. 멈춤·꽃향기 맡기·벤치로 올라가는 짧은 도약·휴식이 이어진다. 실제 3D 리깅이 아닌 이미지 기반 2.5D 동작이다. 소나무는 둥근 수형의 3단계 전용 이미지로 교체했다.

응원 보내기 화면에서 데이지·튤립·수국·안개꽃·라벤더를 고르고, 선택적으로 하트·별·포옹·나비를 함께 보낸다. 기존 동일 상대 하루 한 번 제한을 그대로 사용한다. 받은 사람은 꽃 보관함에서 심거나 꽃 종류를 바꿀 수 있다. 기존 기록에는 데이지가 기본값으로 적용된다. 정원 공개 시 선택된 꽃 종류만 중복을 제거해 최대 5종 공개하며, 편지와 받은 메시지는 공개하지 않는다.

하루 응원은 서버가 수신 기록을 생성한 시각부터 24시간 유효하다. 클라이언트가 요청한 만료 시각은 사용하지 않는다. 서버는 조회 시 만료된 응원을 제외하고, 앱은 저장된 만료 시각으로 화면에서 제거한다. 창을 열어 두었을 때도 만료 타이머가 동작하며 재개 시 다시 계산한다. 응원을 다시 읽거나 꽃을 심어도 만료는 연장되지 않는다. 꽃은 계속 남는다. 최대 6개 이모티콘을 정원에 표시하며 방문자에게 보이는 서버 장식 목록은 최대 12개로 제한한다. 앱에서 사라지는 것이 수신 기록의 영구 삭제를 뜻하지는 않는다.

서버부터 배포해야 한다. `backend/garden-gifts.js`와 `index.js`, `policy.js`가 함께 필요하다. 공개 꽃 종류와 서버가 생성한 하루 응원 필드를 처리한다. 기기의 실제 전송/수신, 서로 다른 계정, 오프라인 후 재접속은 운영 배포 후 확인해야 한다. 운영 서버에는 이번 작업에서 배포하지 않았다.

검증: 정원·저장·성장·백업 회귀 테스트 29개, 최종 생활 및 UI 테스트 15개, 백엔드 43개 통과. Flutter 실제 위젯 정원 렌더링 캡처를 갱신했다. 체험판에서도 글자, 이미지, 꽃 선택, 하루 응원과 24시간 뒤 모습, 휴식 종료, 낮/밤, 모바일 너비를 확인했다. 기존 코드의 스타일 안내는 남아 있으나 검사 범위에 컴파일 오류와 경고는 없었다.
