101번 휴대폰 최종 확인 순서 (현재 미검증)

새 101번 AAB/APK가 만들어져 기존 서명으로 업데이트된 후에만 진행.
현재 설치된 100번에서는 이번 수정이 보이지 않음. 앱 삭제·데이터 초기화 금지.

1. 업데이트 전후 보존
- 앱 버전, 선택 고양이/이름, 최근 기록, 기존 나무/성장/씨앗 수를 비교.
2. 정원 첫 화면
- 고양이가 화면 안에 보임. 씨앗 심기/물주기/내 식물/전체보기 바로 보임.
- 도구 접기/펼치기 후 카메라 위치·크기가 갑자기 바뀌지 않음.
- 내 식물에서 기존 소나무 위치 보기: 해당 저장 위치를 비추고 강조함.
3. 움직임/시간
- 배경 효과 OFF, 고양이 움직임 ON에서 눈 깜박임 유지.
- 고양이 움직임 OFF와 동작 줄이기에서는 자동 동작 멈춤.
- 자동 낮밤 모드로 저녁 18시 이후 재진입: 밤. 수동 낮 선택은 그대로 낮.
4. 함께 돌보기
- 힐링→함께 돌보기 또는 정원→마음돌봄. 저장 이름과 선택 고양이 일치.
- 물 마시기/씻기/운동/산책에서 고양이가 제안. 나중에는 기록/보상 변화 없음.
- 함께 했어 확인 후 기존 일일 보상. 같은 날 다른 활동을 해도 일일 씨앗/정수 중복 지급 없음.
5. 마음 나누기
- 별도 테스트 편지 저장→오늘의 감정을 심어볼까?→식물 선택.
- 저장한 감정이 이어지고 재선택 요구 없음. 기존 기록은 보존.
- 위치 선택 취소: 씨앗/좌표 유지. 확인: 심은 식물 위치와 첫 물 주기 표시.
- 재실행 후 위치/성장 유지, 같은 날 물주기 중복 없음.
6. 기존 기능
- 쉬어가는 정원에서 편집/물주기 없음. 전체화면/지도/돌아가기 정상.
- 다섯 탭 넘김/뒤로가기/구독/로그인 정상.

오류를 만나면 버전·화면·재현 순서만 기록. 개인 편지 내용·이메일·비밀값은 공유하지 않음.
