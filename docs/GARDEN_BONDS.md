# 마음이 닿는 정원 — 꽃 소식과 몽이 반응

## 사용 흐름

새로 보낸 응원 꽃을 이웃이 처음 심으면, 보낸 사람의 **내가 건넨 꽃 소식**에 한 번 소식이 남는다. 정원 → 응원 꽃 또는 받은 응원함에서 열 수 있다. 앱 내부 소식함이며 휴대전화 푸시 알림은 이번 변경에 포함하지 않는다. 기존 응원에는 보낸 사람 정보가 없어 소식을 소급 생성하지 않는다.

소식에는 꽃 종류와 심은 시각만 들어간다. 이웃의 이름, 계정, 편지, 감정은 보이지 않는다. 받은 사람이 꽃 종류를 바꿀 경우 처음 심은 꽃의 종류로 소식이 기록되고, 이후 바꿔도 새 소식이 반복되지 않는다. 구독자 간 실제로 발생한 동작만 처리한다. 소식함이 비어 있으면 예시나 가짜 이웃 소식을 만들지 않는다.

꽃은 로컬에 먼저 저장한다. 오프라인 또는 전송 실패 시 `bloomPending`을 유지하고 다음 정원/응원함 방문에서 다시 시도한다. 서버는 응원을 받은 계정의 인증 정보와 해당 수신 기록으로 발신자를 확인한다. 클라이언트가 수신자/발신자를 임의 지정하지 못한다. 처음 심기 확인과 소식 쓰기는 같은 트랜잭션이며 다시 요청해도 한 건이다. 삭제 중이거나 삭제된 발신자 계정에는 새 데이터를 만들지 않는다. 이전 로컬 기록의 pending 기본값은 false이다.

## 몽이의 반응

- 하트: 앞발을 내밀어 톡 건드리는 자세.
- 별: 고개를 들어 올려다보는 자세.
- 포옹: 눈을 감고 앞발을 가슴에 모으는 자세.
- 나비: 고개를 돌려 호기심 있게 바라보는 자세.

정원을 열었을 때 유효한 응원이 있거나 새 응원이 들어오면 한 번 반응한다. 약 3.2초 뒤 원래 활동으로 돌아간다. 정원에 떠 있는 이모티콘을 누르면 다시 볼 수 있다. 반응 중에는 걷기 경로의 시간을 멈춰 종료 후 다른 위치로 뛰지 않게 했다. 휴식 모드에서는 반응을 중단한다. 앱 비활성 시 반응 애니메이션을 멈추며 모션 줄이기에서는 자세만 보여준다. 만료된 이모티콘은 반응을 새로 시작하지 않으며, 진행 중인 표시도 만료 시 사라진다.

네 개의 별도 자세 이미지와 작은 회전/떠오름 효과를 쓰는 2.5D 표현이다. 관절을 가진 실시간 3D 캐릭터나 네 프레임의 연속 동작 영상은 아니다.

## 검증 및 배포

- 백엔드 테스트 46개 통과: 중복 확인, 다른 수신자의 기록 접근, 알 수 없는 꽃/잘못된 ID, 구 데이터 및 삭제된 발신자 처리 포함.
- 생활·정원 UI·백업 묶음 23개 통과. 최종 생활 및 정원 UI 16개 통과.
- 검사한 변경 파일에 정적 분석 오류/경고 없음. 중괄호 스타일 안내는 남아 있음.
- 체험 화면의 선물 → 이웃 심기 → 단일 소식, 몽이 반응의 시작/종료, 만료 및 모바일 너비를 브라우저로 확인함.

`backend/garden-blooms.js`와 변경된 `backend/index.js`를 먼저 배포한 뒤 앱을 업데이트해야 한다. 실제 계정 간 전송, 운영 서버 배포, 네이티브 기기 설치/푸시 검증은 수행하지 않았다. 개발자가 두 실제 계정으로 처음 심기, 반복 요청, 오프라인 복구, 소식함 조회를 확인해야 한다.

## 추가 자산

`assets/living_garden/cat_reactions.webp`: 기존 몽이 이미지를 기준으로 내장 이미지 생성 도구로 제작한 투명 2×2 자세 시트. 원본을 보존하고 프로젝트용 WebP로 변환함.

제작 프롬프트: 동일한 주황색 아기 고양이의 털 무늬·호박색 눈·흰 발·따뜻한 3D 동화풍 질감을 유지한다. 투명 배경의 동일 크기 2×2 셀, 같은 시점/기준선/크기로 앉은 자세를 그린다. 왼쪽 위는 오른쪽 앞발로 보이지 않는 하트를 향해 손 내밀기, 오른쪽 위는 고개와 눈을 위로 들어 별 바라보기, 왼쪽 아래는 눈을 감고 앞발을 가슴에 모으기, 오른쪽 아래는 고개를 옆으로 돌려 나비 바라보기. 각 셀 안에 전신을 담고 충분한 여백을 두며 이모티콘·배경·글자·격자선은 그리지 않는다.

## 낮 정원의 투명한 빛 (추가)

낮에만 나타나는 투명한 빛 조각을 추가했다. 24초 환경 주기 안에서 1초·9초·17초에 각각 약 4.8초 동안 느리게 스친다. 부드러운 타원형 빛 번짐, 가는 반사선, 작은 중심 반짝임이 함께 나타났다 사라진다. 매 주기 끝에는 빛이 사라져 반복 경계가 튀지 않는다. 기존 공통 애니메이션 시간을 사용하므로 모션 끄기·모션 줄이기·앱 비활성 동작을 따른다. 새 타이머나 서버 변경은 없다. 정적 분석 및 체험 화면의 낮/밤·모션 전환과 모바일 표시를 확인했다. 실제 기기 성능 검증은 남아 있다.


## 사선 햇살 조정
낮에는 넓고 투명한 평행 햇살 네 줄기가 오른쪽 위에서 왼쪽 아래로 펼쳐집니다. 10초 주기로 6초 동안 부드럽게 밝아졌다 사라지고 4초 쉬며, 기존 상시 광선과 짧은 빛 조각은 이 효과로 대체했습니다. 별도 10초 시계를 사용해 24초 주변 애니메이션 경계에서도 주기가 끊기지 않습니다. 일시정지, 동작 줄이기, 백그라운드 중지에 함께 반응합니다.
