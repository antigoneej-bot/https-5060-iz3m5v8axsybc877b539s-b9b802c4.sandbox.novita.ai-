# 넓은 정원 — 산책과 배치

홈의 ‘정원 가꾸기’ 또는 ‘넓은 정원 산책 · 아이템 배치’를 눌러 엽니다.

## 사용 방법

1. 좌우로 밀어 산책하고 두 손가락 또는 확대·축소 버튼으로 크기를 조절합니다. 위쪽 꽃밭·몽이의 집·나무 뜰 버튼으로 바로 이동할 수 있습니다.
2. ‘씨앗 심기’에서 보유 씨앗을 사용합니다. 기존 규칙대로 종류별 첫 씨앗은 식물을 만들고, 같은 씨앗을 다시 심으면 그 식물이 성장합니다. 여러 독립 개체를 무제한 복제하는 기능은 아닙니다.
3. ‘장식’에서 기존 보유·해금 조건을 충족한 장식을 놓습니다. 새 화면은 실제 배치된 장식만 보여줍니다.
4. ‘배치 모드’에서 식물이나 장식을 고른 후 원하는 잔디를 누릅니다. 이동할 때마다 저장하며 ‘되돌리기’로 마지막 이동을 취소할 수 있습니다. 배치 중에도 화면 이동과 확대가 가능합니다.
5. 산책 모드에서 식물을 누르면 기존 이름·추억 기록창이 열립니다. 이 기록과 배치는 자동 공개되지 않습니다.

## 공간

전체 월드는 2400×800의 가상 좌표이며 중앙·왼쪽·오른쪽 3개 공간으로 구성됩니다. 중앙은 처음부터 열려 있습니다. 저장된 씨앗 성장 횟수 총합 3회에 왼쪽 꽃밭, 8회에 오른쪽 나무 뜰이 자동으로 열립니다. 게임 보상으로 씨앗을 갖고 있기만 한 경우에는 횟수가 늘지 않습니다. 해금은 별도로 저장되어 쉬거나 기록 수가 줄어도 닫히지 않습니다. 이 기준은 첫 구현의 조정 가능한 설정입니다.

좌표는 전체 정원을 기준으로 정규화해서 화면 크기나 확대 배율에 영향을 받지 않습니다. 꽃·나무 6종과 현재 장식 카탈로그 13종을 지원합니다. 이동은 잔디 범위·열린 공간·다른 아이템과의 거리·현재 정원에 있는 아이템인지 확인한 뒤 저장합니다. 장식을 잠시 해제해도 이전 위치는 남습니다.

## 저장과 백업

`garden_layout_local_user` 암호화 저장소의 `layout` 행에 좌표와 해금 공간을 저장합니다. 여러 쓰기를 순서대로 처리하고 디스크 저장 후 화면 상태를 갱신합니다. 로드 실패 시 기존 내용을 초기화하지 않습니다. 기존 암호화 백업의 `garden_layout` 항목으로 내보내고, 복원 전에 구조·좌표·아이템 ID를 검증합니다. 기존 백업 복원 정책대로 현재 기기에 배치 기록이 있으면 현재 기록을 우선합니다.

## 이미지와 구현 범위

승인된 시안의 분위기를 유지한 넓은 낮·밤 배경을 built-in ImageGen으로 생성하고 WebP로 변환했습니다. 생성 지시: 하나로 연결된 3:1 파노라마, 중앙 오두막·뒤쪽 버들나무와 시냇물, 양쪽 정원, 앞쪽은 식물을 배치할 수 있는 넓은 잔디, UI·문자·캐릭터 제외. 밤에는 같은 구도에 별빛·달빛·창문 조명만 변경했습니다.

이전과 같은 2.5D 렌더 레이어 방식이며 자유 회전 3D 월드는 아닙니다. 넓은 배경의 나무와 꽃은 기본 풍경입니다. 이동 가능한 식물은 현재 벡터 성장 표현을 공유하고, 벤치는 별도 그림, 나머지 장식은 종류별 아이콘입니다. 모든 아이템의 독립 3D 모델 제작, 새로운 씨앗·장식 종류, 선물 발신자 연결은 이번 변경에 포함하지 않았습니다. 홈의 기존 작은 정원은 몽이의 쉼터이며 자유 배치는 넓은 정원 화면에서 확인합니다.

## 검증

Flutter 3.35.4 / Dart 3.9.2. 관련 테스트 총 39개(새 레이아웃 7개, 새 화면 4개, 기존 정원·성장·화면 21개, 백업 안전성 7개)가 최종 통과했습니다. 작은 화면·큰 글씨 오류 및 저장 알림의 버튼 가림을 발견해 수정 후 해당 테스트를 다시 통과했습니다. 변경된 정원 코드 6개 파일 정적 검사에는 문제가 없었습니다.

`expanded-garden.png`와 `expanded-garden-overview.png`는 실제 Flutter 위젯 캡처입니다. 캡처는 모든 공간을 연 상태의 예시 데이터를 사용합니다. 실기기 APK/AAB 설치, 공개 정원 서버 배포, 결제 검증은 이번 작업 범위가 아닙니다.
