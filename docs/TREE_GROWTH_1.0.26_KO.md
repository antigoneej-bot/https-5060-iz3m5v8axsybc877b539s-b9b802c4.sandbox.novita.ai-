# 마음냥 정원 · 물·거름·햇볕과 나무 성장

이 수정은 아직 빌드·출시하지 않은 1.0.26+29 소스에 추가했습니다. 빛의 정수 표시, 구독 해지 안내와 상태 갱신, 연간 상품 선택 수정도 함께 포함합니다. 앞서 제공한 같은 버전의 ZIP보다 이 파일이 들어 있는 ZIP이 최신입니다.

## 사용하는 방법

나의 넓은 정원에서 심은 식물을 누르면 추억 창 위쪽에 성장률과 **물 주기 / 거름 주기 / 햇볕 쬐기**가 나옵니다. 작은 식물이 누르기 어려우면 하단 도구를 펼쳐 씨앗을 심고 가꾸는 목록에서 해당 식물의 **돌보기**를 누릅니다. 물주기 모드의 기존 물뿌리개도 그대로 사용할 수 있습니다.

- 물은 식물마다 하루 한 번, 기존과 같은 양만큼 성장시킵니다.
- 거름과 햇볕도 각각 하루 한 번씩 성장을 조금 더 도와줍니다. 물만으로도 완전히 키울 수 있습니다.
- 물만 주면 9번의 돌봄 날짜, 세 가지를 모두 해 주면 6번의 돌봄 날짜에 완전히 자랍니다. 연속 방문은 필요하지 않습니다.
- 나무를 돌보는 데 씨앗이나 빛의 정수를 쓰지 않습니다. 시간이 지났다는 이유만으로 자동 성장하거나, 쉬었다고 시들거나 작아지지 않습니다.
- 다 자란 뒤에도 돌보기와 이름·기념일·추억 기록을 계속할 수 있습니다. 크기는 일정한 상한을 유지합니다.

## 화면 변화

소나무·벚꽃나무·단풍나무는 작은 새싹에서 시작해 돌볼 때마다 조금씩 커집니다. 같은 깊이에서 다 자란 나무는 고양이보다 확실히 크게 보입니다. 꽃 종류에는 별도의 작은 크기 범위를 적용했습니다.

크기가 바뀌어도 저장된 뿌리 좌표를 유지하며, 위쪽으로 0.7초에 걸쳐 부드럽게 자랍니다. 성장 단계의 그림 전환도 짧게 겹쳐 보여 줍니다. 움직임 끄기·접근성의 애니메이션 줄이기·쉬기 모드에서는 즉시 반영합니다. 나무 크기는 낮과 밤에 같습니다.

## 저장과 호환

- 기존 성장 수치·심은 날짜·물 준 날짜·이름·추억은 유지합니다. 이미 다 자란 나무를 새싹으로 되돌리지 않습니다.
- 물 3점, 거름 1점, 햇볕 1점을 내부 성장 단위로 사용합니다. 3점마다 기존 성장 수치가 1 올라가며, 남은 1~2점도 보관해 크기와 성장률에 반영합니다. UI는 이 내부 단위를 요구하지 않습니다.
- 로컬 정원 스냅샷 버전은 3으로 올라갔고, 기존 1·2 버전도 읽습니다. 돌봄별 날짜와 남은 성장량을 같은 저장 작업에 기록합니다.
- 저장 실패·중복 클릭·동시 요청으로 성장이 중복되지 않게 했습니다. 날짜를 과거로 돌려 다른 종류의 돌봄을 추가하는 것도 막습니다.
- 백업에 새 돌봄 날짜와 남은 성장량이 포함됩니다. 구버전 앱은 새 백업 형식을 읽을 수 없으므로 복원할 앱도 업데이트해야 합니다.
- 공개 정원은 기존 서버의 정수 성장 수치를 그대로 사용합니다. 따라서 이웃에게 보이는 모습은 다음 정수 성장에 도달했을 때 갱신되며, 개인 정원에서 먼저 보이는 작은 중간 성장은 아직 공개 데이터에 포함하지 않습니다. 새 서버 배포는 필요하지 않습니다.

## 검증과 남은 확인

- 성장 속도, 중복 방지, 날짜 역행, 이전 데이터 이전, 잘못된 백업 거절을 검증했습니다.
- 동시 돌봄과 앱 재로딩 후 저장 유지, 저장 실패 후 재시도를 검증했습니다.
- 360px·글자 1.5배에서 세 돌봄 버튼을 실제 탭해 저장을 확인했습니다.
- 390px 정원에서 성장 애니메이션 도중에도 뿌리가 같은 위치에 남는지, 움직임을 끄면 즉시 반영되는지 검증했습니다.
- 기존 백업 검증에 거름·햇볕 날짜와 남은 성장량을 추가했습니다.
- `test/plant_care_growth_widget_test.dart`는 `GARDEN_GROWTH_CAPTURE=1`로 실행하면 실제 Flutter 정원 위젯을 `/tmp/mindnyang-grown-tree.png`로 렌더링합니다. 실기기 사진은 아닙니다.

서명된 AAB 생성과 Play 업로드, 휴대전화 업데이트 후 돌봄·재실행·이웃 정원 비교는 별도입니다. 기존 서명키가 있는 환경에서 함께 제공한 `docs/BILLING_1.0.26_KO.md`의 빌드 절차를 따릅니다. 설치된 앱에는 아직 이 변경이 반영되지 않았습니다.
