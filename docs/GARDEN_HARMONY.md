2026-10-05 시각 수정. 기존 성장/편지/응원/선물 저장 형식은 변경하지 않음.

- 꽃·나무 18단계와 응원꽃 5종을 배경의 따뜻한 빛과 재질에 맞춰 재생성. 소나무의 분재 아틀라스 우회 렌더링을 없애 일반 나무와 같은 성장 아틀라스를 사용.
- 벤치를 덜 붉고 부드러운 목재, 옅은 세이지 쿠션으로 수정. 나무·꽃·벤치의 표시 크기를 구분하고 잔디 위치에 따라 크기를 소폭 조절.
- 아틀라스를 각 셀로 분리하고 투명 여백과 밑동 기준선을 맞춰 다른 단계 조각이 들어오는 문제 방지. 원본 자산은 새 생성 결과를 사용하며 배경은 그대로 보존.

- 평상시 아이템 이름표는 숨기고 선택/배치 시 표시. 접근성 설명과 탭 동작 유지.
- 식물 흔들림 각도 .055 → .025 rad로 완화. 10초 사선 햇살 유지.

검증: 수정 Dart 파일 구문 포맷 검사 통과. 브라우저 체험 낮/밤, 배치, 동작 중지, 360px 화면 확인(스크립트 오류 0, 가로 넘침 없음). Flutter 의존성 설치는 자동 승인 검토에서 클라우드 메타데이터 주소 접근을 감지하여 차단됨. 설치를 중단했으며 Flutter 컴파일·위젯 테스트·실기기 검증 완료를 주장하지 않음. 체험 미리보기는 앱과 같은 자산을 이용한 브라우저 시뮬레이션이며 실제 계정 기록과 연결되지 않음.

## 이미지 제작 기록
내장 image_gen 사용. 배경 world_day.webp는 스타일 참조, 기존 plants.webp / botanicals.webp / bench.webp는 편집 대상. 실제 투명 알파 유지. ImageMagick은 자산 분할·크기 정렬·WebP 변환에만 사용.

1. plants: style-transfer, 6×3 동일 정사각 셀. 열은 소나무/벚꽃/단풍/코스모스/장미/종꽃, 행은 새싹/어린 식물/성체. 배경과 같은 약간 내려다본 시점, 오른쪽 위 따뜻한 빛, 자연스러운 무광 잎과 작은 꽃, 과한 광택과 분재 형태 제거. 밑동 주변 희박한 잔디, 화분·돌 테두리·불투명 배경 없음.
2. bench: style-transfer, 3:2 투명 벤치. 완만한 등받이와 작은 하트, 세이지 쿠션, 작은 크림 베개, 왼쪽 장미 유지. 매트한 밝은 참나무와 덜 두꺼운 부재, 정원과 같은 카메라/광원. 다리 끝에 얇은 잔디, 배경·받침대 없음.
3. botanicals: style-transfer, 4×2 동일 정사각 셀. 위는 소나무 세 단계/데이지, 아래는 연분홍 튤립/옅은 수국/안개꽃/라벤더. 자연스러운 가는 잎, 따뜻한 오른쪽 위 햇빛, 투명 배경, 셀별 간격.

## 밤 정원 조명 통일

2026-10-05 후속: GardenNightLight를 추가하여 몽이의 앉기/걷기/눈깜빡임/응원 반응 및 꽃·나무·벤치에 같은 오른쪽 위 달빛 그라데이션을 적용. 원본 자산의 투명도를 유지하며 밤에만 렌더링 색을 조정. 작은 정원 화면의 몽이에도 적용. 아래쪽은 차분한 푸른 그림자, 위쪽은 밝은 은빛으로 처리하되 고양이의 털색을 남김.

접촉 그림자는 밤에 더 넓고 옅게 변경(.30 → .18). 달빛의 넓은 반사광을 추가하고 반딧불이는 파노라마 기준 28 → 20마리, 노란 금빛으로 낮은 강도로 변경. 별도의 타이머 없이 기존 일시정지/동작 줄이기/백그라운드 중지 정책을 사용. 기존 창문 불빛과 낮의 10초 햇살은 유지.

검증: 수정 Dart 4개 파일 구문 포맷 통과, 밤 시작 미리보기/낮 전환/배치 모드/움직임 중지/360px 폭 확인. 브라우저 오류 0, 가로 넘침 없음. Flutter 의존성 설치는 이전 자동 승인 검토 차단 이후 재시도하지 않았으며 실제 Flutter 실행 검증은 여전히 미완료.

## 벤치에서 쉬는 몽이의 달빛
밤 + 벤치 보유 + 몽이 resting 상태일 때에만 GardenBenchMoonlight가 얼굴·등 위쪽 조명을 한 단계 밝히고, 부드러운 사선 광채와 좌석 반사광을 표시. 자동 산책 중 벤치 휴식 및 잠깐 쉬기 모두 적용. 낮/벤치 없음/걷는 상태에는 일반 조명으로 복귀. Flutter는 1.2초 easeInOut 전환, 동작 중지/동작 줄이기 시 즉시 정적 표시. 새 외부 통신이나 데이터 변경 없음.
검증: Dart 구문 포맷 통과. 밤 미리보기에서 잠깐 쉬기→쉬기 마치기→낮 전환·배치·움직임 중지 및 모바일 폭 확인(오류 0, 가로 넘침 없음). 미리보기는 같은 색과 광채의 시뮬레이션이며 Flutter 실행 검증은 앞서 기록한 환경 제한으로 미완료.
