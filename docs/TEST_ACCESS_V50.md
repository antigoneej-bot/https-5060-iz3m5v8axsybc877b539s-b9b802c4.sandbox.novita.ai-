# 마음냥 정원 v50 — 구독 기능 테스트 개방

버전: 1.0.47+50. 배포 파일: `Mindnyang-1.0.47-50-TestOpen.aab`.

## 이번 변경

- 기존 구독 기능을 테스트용으로 개방한 앱을 빌드합니다. `UNLOCK_ALL_PREMIUM=true`이며 인증·App Check는 그대로 유지합니다.
- 앱 상단에 **테스트 모드 · 구독 기능 개방 중**을 표시합니다.
- 구독 화면에서는 실제 결제 대신 무료·구독 기능 안내를 보여줍니다. 테스트 개방은 실제 유료 구독 구매나 결제 이력을 만들지 않습니다.
- 기본 고양이는 무료, 호스트 고양이 6종 선택·성장·가족과 열매 나무 5종은 구독 항목으로 표시합니다. 현재 테스트에서는 계속 사용할 수 있습니다.
- 서버 구독 제한이 있는 자동 백업과 공유 나무도 `PREMIUM_TEST_ACCESS=true`일 때 인증된 테스트 계정이 이용할 수 있도록 준비했습니다. 결제 검증과 실제 구독 상태 응답은 바꾸지 않습니다.

## 적용

1. `Mindnyang-TestAccess-Server-v50.py`를 Google Cloud Shell에 업로드합니다.
2. `python3 Mindnyang-TestAccess-Server-v50.py`로 현재 서버와 기준 소스 일치 여부를 검사하고 변경 파일을 준비합니다.
3. `python3 Mindnyang-TestAccess-Server-v50.py --deploy`로 테스트 서버 코드를 적용하고 `PREMIUM_TEST_ACCESS=true`를 설정합니다. 검증된 v47·v48·v49 기준 서버를 지원하며 다른 변경이 있으면 멈춥니다. 이전 나무·고양이 방문 서버 변경도 포함합니다.
4. Play Console 내부/비공개 테스트 트랙에 `Mindnyang-1.0.47-50-TestOpen.aab`를 올려 출시합니다.
5. 업데이트 후 상단 테스트 표시와 고양이 선택·성장·열매 정원, 서버 기능을 확인합니다.

이 작업에서는 실제 서버 배포·Play Console 업로드·실제 기기 검사를 수행하지 않았습니다. 서버 기능은 서버 적용까지 완료해야 테스트 개방됩니다.

## 출시 전 남은 작업

이 버전은 사용자가 요청한 **기능 구분 표시 + 테스트 개방** 버전입니다. 새로 정한 무료/구독 경계를 모두 강제하는 정식 출시 버전이 아닙니다.

- 앱을 `UNLOCK_ALL_PREMIUM=false`로 다시 빌드하고 서버 `PREMIUM_TEST_ACCESS`도 `false`로 변경해야 합니다. 테스트 해제만으로 기존에 무료였던 고양이·열매 나무의 새 구독 제한까지 자동 적용되지는 않습니다.
- 고양이 6종·성장·가족과 열매 나무에 실제 구독 권한 검사, 무료 기본 고양이 복귀, 만료 시 기록 보관·재구독 복구를 연결해야 합니다. 실제 계정 만료와 복구 시나리오 검증도 필요합니다.
- v49의 별도 정원 코인 구조는 아직 남아 있습니다. **빛의 정수 단일 재화로 통합하는 작업은 별도 구현이 필요하며, 표시 이름만 바꿔 통합했다고 하지 않았습니다.**
- 7·20·30일 출석부, 연속 출석, 하루 목표·누적 성과와 무료/구독 차등 보상은 기획 상태입니다. 이번 버전에서 구현 완료로 표시하지 않습니다.
- 출시 전 무료 계정/유효 구독/만료 구독별 검사 및 테스트 표시·결제 화면 복원을 확인합니다.

서버 테스트 종료 시 `gardenApi`의 환경변수 `PREMIUM_TEST_ACCESS`를 `false`로 변경하고 검증된 서버 소스로 재배포합니다. 앱도 테스트 해제를 반영해 새 버전으로 출시해야 합니다.

전체 소스에서 테스트 빌드를 다시 만들 때는 Flutter/Android SDK와 기존 서명을 준비한 뒤 `bash tools/build_test_access_v50.sh`를 실행합니다. 이 스크립트는 테스트 개방을 명시하며 정식 출시용 빌드가 아닙니다.
