마음냥 정원 1.0.97+100 — 이번 작업의 변경과 검증
작성: 2026-11-07 / Flutter 3.35.4 / Windows

변경 범위
사용자가 확인한 네 장은 정원 한 카테고리의 흐름이다. 기존 다섯 탭을 유지했다.
정원 탭에서는 저장된 실제 정원이 바로 나타나고, 마음돌봄/보상/꾸미기를 정원 내부에서 연다.
99번 원본과 전달 파일은 보존하고 feature/garden-reference-100에서 수정했다.

주요 수정 파일과 이유
- lib/mongi/screens/garden_world_screen.dart: 실제 캔버스 위 작은 패널/도구, 마음돌봄 진입, 짧은 선택 식물 정보.
- lib/mongi/screens/garden_daily_care_screen.dart: 선택 동반 고양이와 기존 활동 연결, 저장된 일일 보상 영수증.
- lib/mongi/widgets/garden_essence_chip.dart: 실제 보유 정수 표시.
- lib/mongi/widgets/garden_cultivation_tools.dart: 네 핵심 조작을 그림/글자로 표시, 큰 글자 대응.
- lib/mongi/widgets/garden_decoration_sheet.dart: 실제 정원 미리보기, 그림 목록, 선택 후 명시적 확인.
- lib/mongi/widgets/garden_world_view.dart: 저장 좌표는 그대로 두고 식물을 가린 카드 위로 카메라 조정, 장식 미리보기.
- lib/screens/cat_flow_tab_screen.dart, meditation_flow_screen.dart: 정원에서 기록을 마치면 정원 보상 화면으로 복귀. 기본 홈 흐름 유지.
- lib/l10n/mind_followup_english_catalog.dart: 추가 문구의 영어 표시. 사용자가 정한 이름 유지.
- test/garden_reference_flow_test.dart: 장식 선택/확정/실패/중복, 보상 읽기 전용, 크기별 회귀.
- test/garden_world_offline_test.dart: 새 경로와 크기별 조작, 실제 로컬 편지 저장 후 보상, 새싹이 카드 위에 보이는지 검사.
- test/mind_followup98_ui_test.dart: 새 전체보기 글자와 기존 가로 전체화면 접근성 의미를 함께 확인.
- pubspec.yaml 및 인계 문서: 1.0.97+100과 노트북 인계.

보존
- 홈·이웃·힐링·기록 제품 코드는 기존 99 디자인 유지.
- 실제 정원 배경/낮밤/나비/빛, 고양이 선택/이름/성장/동작 유지.
- 기존 기록/씨앗/식물 종류/성장/물주기/위치/확장/장식 저장 모델은 변경하지 않음.
- 일일 보상 기존 정수 20/씨앗 1, 장식 가격 60과 구독 혜택을 변경하지 않음.
- 방문/화면 열기/장식 미리 선택만으로 추가 지급/차감하지 않음.
- 기록/재화/배치 기존 저장 트랜잭션과 실패 복구 로직 재사용.
- 서버/API/IAM/비밀값/로그인/상품 ID/서명키 변경 없음.

이번 실행 증거
- pub get --offline --enforce-lockfile 통과. 잠금 파일 변경 없음.
- 전체 Flutter 테스트: 1,192개 통과 (full.log, full-status.json, exit 0).
  UTC 2026-11-07 08:30:46 시작, 08:40:55 종료. 제품 코드 최종본 기준.
- 관련 저장 흐름 단독 검증: save-flow2 1개 통과. 실제 테스트용 편지 저장 → 보상 → 정원 복귀.
- 위치 가시성 단독 검증: plant-visible 1개 통과. 저장된 뿌리 좌표를 화면에 변환해 카드 위 위치를 검사.
- 장식/보상 신규 9개 및 나머지 기존 회귀는 위 전체 실행에 포함.
- 화면 크기 320×640 / 390×844 / 844×390 각각 글자 1배·2배.
- 캔버스 크기와 도구 접기 전후 카메라 행렬 불변, 실제 저장 데이터 불변을 확인.
- 심기 취소/저장 실패/재시도/중복 터치/첫 물주기/저장 위치 찾기를 테스트용 로컬 저장소로 확인.
- 최종 캡처 회귀 8개 통과: final-captures3.log/status, exit 0. 캡처 모드 수정 후 재실행.
- 최종 정적 분석 오류 0, 경고 0, 정보 663. --no-fatal-infos 사용, 권고 사항을 모두 해결한 것은 아님.
- 원본 로그/상태 JSON과 AAB 검증은 함께 전달하는 검증결과.txt 및 validation 폴더 참조.

검증 중 발견하여 수정한 사항
- 고양이 컨테이너 가로 폭이 없어 이미지가 사라짐: 무한 가용 폭 지정, 실제 캡처와 너비 검사 추가.
- 심은 새싹이 선택 카드 뒤에 가림: 카드 축약/카메라 조정, 저장 좌표 변경 없음.
- 성공/실패 스낵바가 다음 장식 확인 버튼을 막음: 선택창 내부 상태 안내로 표시.
- 정원 편지 완료가 홈으로 이동: 정원 호출자에게 완료를 돌려주는 선택 콜백 추가.
- 새 메뉴/버튼과 맞지 않는 기존 테스트의 진입/표시 이름 수정. 데이터·동작·접근성 검사는 유지.
- 캡처 모드의 그림자 전역 설정 잔류: 테스트 바인딩의 정식 그림자 옵션 사용, 불변 검사 유지.
  이 수정과 리뷰용 이모지 폰트 로딩은 캡처 환경에서만 적용. 앱 코드는 전체 테스트 후 변경하지 않음.
- 초기 실패 로그도 별도로 보존. 단독 성공만으로 전체 테스트 성공으로 대체하지 않음.

실제 확인과 미검증 구분
- 캡처는 이번 소스의 Flutter 위젯 실행 결과, 합성 기록/정원 데이터 사용.
- 실제 삼성 Buddy3/다른 휴대폰/Android 에뮬레이터 실행 캡처가 아니다.
- 앱 업데이트 설치 후 기존 사용자 기록 보존, 실제 Play 결제/구독/이웃 두 계정/알림/오디오/배터리/성능은 이번 미검증.
- iOS 실행/서명도 미검증.
- 보상 화면은 오늘 저장된 기존 일일 지급 내역을 표시한다. 이전에 보상을 받은 날에는 추가 지급되지 않는다.
- 시안 숫자는 예시였으므로 실제 잔액을 표시한다. 시안 그림을 앱 배경이나 고양이로 교체하지 않았다.
- 오래된 장식 중 이모지 기반 항목은 기존 렌더링 유지. Windows 캡처에서 조약돌 오솔길의 바위 이모지가 빈 글리프로 보임.
  기존 에셋 기반의 주요 네 장식은 정상 표시. 바위 이모지의 실제 Android 표시는 이번 미검증이며 확인 필요.
- APK 미제작, USB/브라우저 재시도 없음. 스토어 업로드/서버 배포 없음.

내부 테스트 확인 순서 (앱 삭제 금지)
1. 100번 내부 테스트 업데이트 후 홈/이웃/힐링/기록 탭이 유지되는지 확인.
2. 내 정원 → 마음돌봄 → 기록 → 보상 확인 → 정원에서 심어보기.
3. 심기 위치 취소, 정상 심기, 첫 물주기, 내 식물에서 기존 나무 위치 찾기.
4. 꾸미기에서 아이템 선택만 하면 정수가 그대로인지, 확인 후 한 번만 적용되는지 확인.
5. 앱 재실행 후 고양이/이름/기록/식물/좌표/장식이 유지되는지 확인.
6. 가로 전체화면/전체 지도/돌아가기 및 작은 화면·글자 확대에서 도구 접근 확인.
문제가 있으면 버전·화면·재현 순서를 기록하고 개인 기록 삭제/재설치로 해결하지 않는다.
