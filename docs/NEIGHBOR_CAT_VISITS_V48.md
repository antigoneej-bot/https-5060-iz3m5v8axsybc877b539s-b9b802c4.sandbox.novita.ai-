# 마음냥 정원 v48 — 고양이와 이웃 방문

버전: 1.0.45+48. 경로: 이웃 정원 → 고양이 초대와 방문.

수락한 이웃을 초대할 때 우리 가족 고양이 한 마리를 선택합니다. 상대는 받은 초대에서 함께 갈 고양이를 골라 방문합니다. 선택은 내 정원의 대표 고양이, 성장일수, 재화에 영향을 주지 않습니다. 서로 같은 품종도 함께 나타납니다. 인사하기, 함께 산책, 함께 쉬기, 사진 저장과 기존 응원·선물을 제공합니다.

초대는 7일간 유효하며 같은 이웃에게 새 초대는 하루에 한 번 보낼 수 있습니다. 받은 초대는 거절하고 보낸 초대는 취소할 수 있습니다. 방문은 수락 후 최대 30분입니다. 방문 중 30초마다 접근 권한을 재검사하고 차단·이웃 해제·정원 비공개·계정 삭제 시 종료합니다. 주인이 접속하지 않아도 방문 기록이 남습니다. 이 화면은 초대 당시 고양이 모습을 쓰며 실시간 동시 조종이나 푸시 알림 기능은 아닙니다.

공유 정보는 고양이 이름·품종·성장 모습과 이웃 별명입니다. 감정·일기·개인 마음돌봄 내용은 전송하지 않습니다. 서버는 본인 인증과 양쪽 이웃 관계를 검증합니다. 방문 데이터는 기존 클라이언트 접근 금지 영역에 저장합니다. 계정 삭제 시 상대편의 관련 기록도 지웁니다.

## 배포 순서

1. Google Cloud Shell에 `Mindnyang-Neighbor-Cats-Server-v48.py`를 업로드합니다. 프로젝트 `mycatapp-99bc8`의 기존 `gardenApi`를 관리할 수 있는 계정이어야 합니다.
2. `python3 Mindnyang-Neighbor-Cats-Server-v48.py`로 현재 배포 소스와 기준 버전을 대조하고 변경 파일을 준비합니다. 기존 소스가 다르면 배포하지 않고 중단합니다. 임시 폴더의 변경 파일을 검토합니다.
3. `python3 Mindnyang-Neighbor-Cats-Server-v48.py --deploy`로 적용합니다. 기존 소스와 롤백 명령은 Cloud Shell 홈에 보관합니다. `gardenApi`만 업데이트하며 소셜 인증 함수는 변경하지 않습니다.
4. Play Console의 같은 테스트 트랙에 `Mindnyang-1.0.45-48-Play.aab`를 업로드하고 출시합니다.
5. 서로 이웃을 수락한 두 테스트 계정으로 초대 → 수락 → 방문 → 방문 기록을 확인합니다. 실제 기기의 움직임, 사진 저장 권한과 갤러리 저장도 확인합니다.

현재 이 작업에서는 실제 서버 배포와 Play Console 업로드를 수행하지 않았습니다. 서버 업데이트 없이 앱만 설치하면 새 초대 기능을 사용할 수 없습니다. 기존 서버 코드를 덮어쓰기 전에 설치기가 기준 소스와 일치 여부를 확인합니다. 불일치 시 기존 소스를 병합 검토해야 합니다.
