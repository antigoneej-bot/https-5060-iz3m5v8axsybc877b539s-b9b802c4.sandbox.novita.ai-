마음냥 정원 / 승인 시안 기반 4페이지 UI / 내부 테스트 1.0.65 (68)

구성
1. 홈: 오늘의 기분 선택, 마음 기록 시작, 저장된 내 정원 미리보기, 지난 기록 연결.
2. 정원: 정원 꾸미기, 기억의 나무, 열매 정원, 이웃 둘러보기/즐겨찾기, 받은 응원·선물.
3. 마음돌보기: 선택한 고양이, 밥/물/목욕/청소, 호흡·명상, 색칠, 돌봄 기록.
4. 모든 기능: 지난 편지/감정 통계/캘린더, 기록집/추억 카드, 계정·백업·잠금/소리·알림/구독.
전체 기능 화면과 기존 알림 목적지는 남겨 두었습니다.

시안 구현
- 승인한 4페이지의 수채화 분위기를 배경 4개와 투명 그림 시트 2개로 분리했습니다.
- 이미지 생성은 built-in image_gen을 사용했습니다. assets/storybook_ui_v1/에 최종 원본을 보관합니다.
- 앱 화면 전체를 이미지로 붙이지 않았습니다. 제목/버튼/검색/탭/상태 표시는 실제 Flutter 위젯입니다.
- sitting/sleeping 그림은 선택한 6종 고양이에 따라 바뀝니다. 선택/이름/성장/돌봄 저장 형식은 바꾸지 않았습니다.
- StorySprite는 공유 이미지 캐시와 atlas sourceRect를 사용하고, 이미지 리스너/참조를 해제합니다. 그림은 탭을 가로채지 않습니다.
- 배경은 1200px로 디코딩해 캐시합니다. 앱에 네트워크 이미지 요청이나 생성형 AI 호출을 추가하지 않았습니다.
- 일반 글자 크기는 승인 시안의 배치를 따릅니다. 큰 글자에서는 제목과 그림을 분리하고, 좁은 화면 하단 메뉴를 2x2로 펼쳐 읽기 쉽게 표시합니다. 가로 화면은 그림 높이를 줄이고 스크롤과 고정 메뉴를 유지합니다.

기능과 데이터
- 홈의 5개 기분은 기존 37가지 감정 탐색의 초기 필터일 뿐입니다. 기록을 자동 저장하거나 감정을 임의로 지정하지 않습니다. 필터는 해제할 수 있습니다.
- 밥/물/목욕/청소는 기존 CatCareProvider 및 CatCareService 처리를 재사용합니다. 로딩/저장 중과 완료한 항목은 비활성화합니다. 계정이 바뀐 뒤 늦은 호출을 이어가지 않도록 요청 전후 소유자를 확인합니다.
- 이웃 둘러보기/즐겨찾기는 기존 GardenDiscoveryScreen, GardenVillageService, CloudService의 약관/Auth/App Check/계정 고정 경로를 사용합니다.
- 실제 정원 편집은 기존 GardenWorldScreen에서 합니다. 홈의 작은 미리보기는 실제 저장된 정원입니다. 큰 배경 그림은 시안의 장식 일러스트입니다.
- 개인 기록, 구독 가격/혜택, 프리미엄 테스트 모드, 서버 비밀값/IAM/규칙/인덱스를 변경하지 않았습니다.
- UI 변경 자체에는 서버 재배포가 필요 없지만, 2026-11-01 통합 수정본의 무작위 정원 탐색 보완은 backend 재배포가 필요합니다. 새 AAB를 Play 내부 테스트에 올리고 앱을 삭제하지 않은 채 업데이트하면 됩니다.

검증/결과
- 페이지별 버튼 연결, 검색, 큰 글자/가로 화면, 6종 외형과 감정 필터를 검사합니다.
- 최종 전체 회귀 결과/화면 캡처/서명/버전/해시는 별도 출력 보고서와 JSON에 기록합니다.
- 실제 휴대폰의 터치/성능/App Check를 포함한 검증은 별도 테스트 계정에서 확인해야 합니다. 이 문서는 실기기 검증 완료를 뜻하지 않습니다.
- 이전 67 소스와 AAB는 보존하며, 이번 작업에서 Play 업로드/정식 출시/프리미엄 테스트 해제는 수행하지 않습니다.
