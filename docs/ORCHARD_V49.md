# 마음냥 정원 v49 — 열매 정원과 수확 창고

앱 버전 1.0.46+49. 고양이 정원 위의 나무 버튼 또는 도구 → **열매 정원 · 창고**에서 들어갑니다.

## 사용 흐름

- 로그인하면 무료 사과나무 한 그루가 계정에 생깁니다. 나무와 창고는 서버에 보관되므로 인터넷 연결이 필요합니다.
- 나무 돌보기에서 좌우로 넘겨 나무를 고릅니다. 묘목, 어린 나무, 꽃, 자라는 열매, 익은 열매 순으로 보입니다.
- 기본 성장 기간은 7일입니다. 물주기 한 번에 성장이 12시간 앞당겨지고 수확량이 4개 늘어납니다. 한국 시간 하루 한 번, 한 수확 주기에 최대 5번 돌볼 수 있습니다.
- 돌보지 않아도 10개가 달리고, 5번 돌보면 30개가 달립니다. 자리를 비워도 나무가 시들거나 열매가 사라지지 않습니다.
- 수확하기를 누르면 창고에 들어갑니다. 수확 후 큰 나무는 그대로 남아 다음 열매를 준비합니다.
- 수확 창고에서 수량을 정해 판매하거나 서로 수락한 이웃에게 선물합니다. 이웃의 선물 받기 설정과 양쪽 차단 여부를 확인합니다. 받은 선물은 창고에 즉시 들어오며 최근 30개 선물 내역이 표시됩니다.
- 간식과 사료는 고양이에게 한 개씩 줄 수 있습니다. 먹는 반응을 보여주며 기존 성장 기록과 재화를 변경하지 않습니다.
- 판매로 모은 정원 코인은 묘목 상점에서 사용합니다. 기존 빛의 정수와 별개이며 현금 구매는 없습니다. 한 종류당 한 그루, 최대 다섯 그루입니다.

| 나무 | 묘목 가격 | 열매 1개 판매 |
|---|---:|---:|
| 사과나무 | 첫 그루 무료 | 5코인 |
| 감나무 | 50코인 | 6코인 |
| 참치 츄르나무 | 70코인 | 7코인 |
| 닭고기 츄르나무 | 90코인 | 8코인 |
| 고양이 사료나무 | 110코인 | 9코인 |

## 데이터와 검증

서버 시간으로 성장과 하루 물주기를 계산합니다. 수확·판매·구매·먹이주기·선물은 서버 트랜잭션으로 처리하며, 요청별 영수증으로 재시도 시 중복 처리하지 않습니다. 앱은 보내기 전에 요청을 계정별로 저장하고, 네트워크가 끊기면 같은 요청 ID로 결과를 확인합니다. 계정이 바뀐 응답은 다른 계정 화면에 적용하지 않습니다. 수량·나무 종류·재고·코인·이웃 관계·선물 수신 설정은 서버에서 다시 검사합니다.

`users/{uid}/orchard/state`, `users/{uid}/orchardRequests`에 저장하며 기존 클라이언트 직접 접근 금지 규칙을 사용합니다. 로그인 계정 삭제 시 기존 users 하위 재귀 삭제에 포함됩니다. 감정 기록이나 편지 내용은 선물에 포함하지 않습니다.

## 실제 서비스 적용

이 결과물은 앱과 서버 소스를 만든 상태입니다. 실제 서버 배포, Google Play 업로드, 실제 기기 검사는 수행하지 않았습니다. 앱 파일만 올리면 새 기능이 동작하지 않으므로 서버도 업데이트해야 합니다.

1. Google Cloud Shell에 `Mindnyang-Orchard-Server-v49.py`를 업로드합니다.
2. `python3 Mindnyang-Orchard-Server-v49.py`로 기존 서버 소스와 일치 여부를 확인하고 변경 파일을 준비합니다.
3. 준비된 파일을 확인한 뒤 `python3 Mindnyang-Orchard-Server-v49.py --deploy`를 실행합니다. 프로젝트는 `mycatapp-99bc8`, 함수는 `gardenApi`, 리전은 `asia-northeast3`입니다.
4. 설치기는 검증된 v47 또는 v48 서버 기준 코드만 업데이트하며, 다른 변경이 있으면 멈춥니다. 고양이 초대 기능도 함께 포함하므로 v48 업데이트 도구를 따로 실행할 필요가 없습니다. 원본 소스와 롤백 명령은 Cloud Shell 홈에 보관합니다.
5. 같은 앱의 Play Console 테스트 트랙에 `Mindnyang-1.0.46-49-Play.aab`를 올리고 출시합니다.
6. 두 이웃 계정으로 묘목·물주기·창고·선물 수신을 확인합니다. 실제 기기에서 재접속, 화면 회전, 네트워크 단절 후 재시도와 계정 전환을 확인합니다. 성장 시간과 중복 처리의 자동 검사는 테스트용 서버 시계로 검증했습니다.

명령 참고: https://docs.cloud.google.com/sdk/gcloud/reference/functions/deploy
