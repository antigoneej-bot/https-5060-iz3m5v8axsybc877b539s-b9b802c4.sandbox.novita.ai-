# 사용자가 지은 노란 고양이 이름

기존 companion_name 저장값과 CatCareProvider를 그대로 사용합니다. 값이 없거나 공백이면 '고양이'로 표시합니다. 별도 이름 저장소나 서버 필드를 만들지 않았습니다.

적용: 처음 이름짓기 → 저장 및 provider 즉시 갱신, 작은 정원 쓰다듬기/접근성, 넓은 정원 집 탭/산책·휴식·응원 반응 안내, 주간 편지 제목/본문/서명. 넓은 정원 상단 연필 버튼에서 이름 변경 가능(최대 16글자, 비우면 기본 호칭). 저장 실패 시 이전 이름 유지. 기존 백업의 companion_name 포함 규칙 유지.

companionCopy는 앱이 제공하는 문구에만 적용합니다. 구름이/구름을/구름과, 보리가/보리를/보리와처럼 받침에 따라 조사를 선택합니다. 사용자 편지 원문이나 과거 작성 기록에는 문자열 치환을 적용하지 않습니다. 감정 고양이 도감의 개별 이름 및 달리기 게임 브랜드 이름은 정원의 반려 고양이 이름과 별개로 유지합니다. 공개 정원에는 반려 이름을 새로 전송하지 않으며, 이웃 화면에 현재 사용자의 반려 이름을 잘못 표시하지 않도록 기본 호칭을 사용합니다.

검증: Dart 이름/공백/조사/영문 치환 6사례 통과(tool/check_companion_name.dart). 변경 Dart 파일 구문 포맷 검사 통과. 브라우저 미리보기 이름 변경, 공백 기본값, 360px 폭 검사 통과(오류 0, 가로 넘침 없음). 미리보기 이름은 체험 내에서만 유지됩니다. Flutter 컴파일·실기기 실행 검증은 기존 의존성 설치 자동 검토 차단으로 미완료이며 재시도하지 않았습니다.
