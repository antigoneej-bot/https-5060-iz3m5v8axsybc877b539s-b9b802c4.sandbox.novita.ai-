# 마음냥 산책 · 힐링 메뉴 통합 (1.0.58+61)

## 이용 경로
명상·힐링 → 마음냥 산책. 모든 기능에서 ‘마음냥 산책’ 검색도 가능합니다.
홈의 기존 카테고리와 정원·기록 화면은 유지합니다.

## 이번 변경
- 승인된 웹 체험판의 꽃길, 원본 고양이, 감정별 대사, 보물 수집, 숨은 풀숲, 간식 먹이기, 엽서를 앱에 포함했습니다.
- 외부 체험판 URL/로그인을 사용하지 않고 앱 내부 파일을 엽니다.
- 기존 동반 고양이 이름/종류를 반영합니다. 구독 접근은 기존 SubscriptionService를 따르며 무료 기본 고양이 구분을 유지합니다.
- 오늘의 편지에서 감정 ID만 가져와 미리 선택합니다. 편지 본문·계정 자격증명은 산책 화면에 전달하지 않습니다. 산책 중 감정 선택은 원래 기록을 수정하지 않습니다.
- 사용자가 입력하는 별도 호칭은 해당 화면에서만 유지합니다.
- 기존 앱 SoundService의 배경음악·효과음·설정을 재사용합니다. 새로 만든 합성 음악/새소리/물소리는 포함하지 않았습니다. 산책을 떠나도 앱의 원래 배경음악 재생 상태를 유지합니다.
- 산책 보상은 아직 체험용입니다. 해당 산책에서 주운 간식만 먹일 수 있고 재시작하면 초기화됩니다. 앱 창고·빛의 정수 잔액·결제·서버 보상은 변경하지 않습니다.
- 엽서는 사용자가 버튼을 눌렀을 때 네이티브 공유창으로 전달합니다. 외부 URL 탐색과 네트워크 요청은 허용하지 않습니다.
- 새 WebView 엔진을 포함하지 않으며, 잠금 파일에 이미 있던 webview_flutter 4.13.1을 직접 의존성으로 명시했습니다.

## 용량과 보호
기존 이미지/음악 등 296개 파일은 바이트 단위로 동일합니다. 웹 체험판에서 사용한 기존 파일 47개는 재사용합니다. 추가 산책 자료는 약 2.3MB입니다. 실제 Android 용량은 동봉 검증 결과의 APK/AAB 바이트 수를 참고하세요.
원본 v60 ZIP을 보관하고 baseline에서 feature/healing-cat-walk 브랜치로 작업했습니다. 소스 ZIP에는 서명키, key.properties, 빌드 캐시, Git 저장소를 넣지 않습니다.

## 실기기 확인 필요
1. 명상·힐링에서 산책 진입, 뒤로가기, 재진입.
2. 기본 고양이/선택한 구독 고양이와 이름, 오늘 기록한 감정 연결.
3. 화면 잠금·홈 이동 후 산책이 멈추고 복귀하면 사용자가 이어서 시작하는지.
4. 기존 앱 음악이 중복 재생되지 않는지, 꺼둔 음악이 자동으로 켜지지 않는지.
5. 가로 전체보기의 조작 버튼·회전 복원, 저사양 폰의 움직임.
6. 감정 수집은 멈추지 않고 특별 보물에서만 짧게 멈추는지.
7. 보상 중복 수령 방지, 가진 간식만 먹이기, 엽서 공유/저장.
8. Android System WebView의 로컬 이미지·캔버스 공유 호환성 및 iOS WKWebView 동작.

Android 실기기와 iOS에서 실행 검증하지 않았습니다. Play Console 업로드 및 서버 배포를 수행하지 않았습니다. 빌드 환경은 기존 v60과 동일한 audit이며 정식 출시 승인본이 아닙니다. v60 보고서의 개인정보 공개 URL·운영자 정보·실제 결제 등 출시 차단 항목은 이번 작업으로 해결되지 않습니다.
