# 마음냥 정원 1.0.31 (버전 코드 34) — 다섯 가지 보완

## 적용 순서

1. `Mindnyang-Quality34-Server-Setup.py`를 Cloud Shell에 업로드하고 실행합니다.
   `python3 "$HOME/Mindnyang-Quality34-Server-Setup.py"`
2. `QUALITY34_SERVER_READY`를 확인한 뒤 `Mindnyang-1.0.31-34-Play-Internal.aab`를 Play Console 내부 테스트 새 출시로 업로드합니다.
3. 테스터는 기존 앱을 삭제하지 않고 Play에서 업데이트합니다. 마이 → 이웃·예약 소식에서 필요한 알림을 켭니다.
4. 서버 배포는 이 문서 작성 환경에서 실행하지 않았습니다. 배포 도구의 로컬 검증과 실제 계정에서의 배포 완료는 다릅니다.

## 1. 기록 변경에 따른 자동 백업

자동 백업을 명시적으로 켠 로그인 계정에 한해 앱 사용 중 1분마다 변경 여부를 확인합니다. 변경이 있으면 성공한 백업 사이 최소 2분 간격으로 재시도합니다. 복원 중에는 중단하며 앱을 닫았을 때의 백그라운드 실행은 보장하지 않습니다. 수동 '지금 백업'은 기존 메뉴에 있습니다.

스냅샷 생성 시각이나 저장 순서만 달라진 경우 업로드하지 않습니다. 업로드 중 새 글을 쓰면 그 변경은 다음 백업 대상으로 남습니다. 오류가 나면 마지막 성공 시각을 갱신하지 않습니다. 마이의 백업 카드에는 최근 확인한 변경 대기 상태가 표시됩니다. 로그인 자체가 다른 기기의 기록을 자동 합치는 기능은 아닙니다.

서버에는 최대 10개를 보관합니다. 최근 5개와 이전 날짜의 복구 지점을 우선 보존하여 잦은 업로드로 전날 백업까지 모두 밀려나는 일을 줄였습니다. 복구 암호와 기존 암호화 형식은 유지합니다.

## 2. 월간 → 연간 구독 전환

활성 월간 구독자는 구독 화면에서 연간으로 변경할 수 있습니다. 기존 월간 구매 영수증의 소유자를 서버에서 확인하고 Google Play의 구독 교체 요청을 사용합니다. 연간 가격을 지금 결제하고 남은 월간 가치를 새 이용 기간에 반영하는 `CHARGE_FULL_PRICE` 방식입니다. 최종 금액·갱신일은 Play 결제창에서 확인한 뒤 사용자가 승인합니다. 새 상품을 별도 중복 구매하는 방식이 아닙니다.

새 영수증과 이전 영수증의 연결을 서버 트랜잭션으로 기록합니다. 이전 월간 토큰의 지연된 알림이 다시 권한을 살리지 못하게 했습니다. 다른 계정의 구매를 가져오거나, 서버가 월간으로만 확인했는데 연간 전환 성공으로 표시하지 않습니다. 해지·복원은 기존 Play 연결과 계정별 검증을 유지합니다.

실제 테스트 결제·전환·취소·만료·복원은 Play 내부 테스트에서 확인해야 합니다. 이미 구독 중인 계정은 실제 과금 계정 대신 라이선스 테스터로 확인하세요.

## 3. 응원·선물 및 예약 변경 서버 알림

Android Firebase Cloud Messaging을 추가했습니다. 마이에서 응원·선물과 예약 변경·취소를 각각 선택합니다. 시작할 때 임의로 알림 권한을 요청하지 않으며 기기 등록 토큰을 서버에 연결하는 작업은 명시적 선택 후 수행합니다. 기기 OS에서 알림을 차단하면 표시되지 않을 수 있습니다.

서버의 응원·선물 저장과 알림 대기 기록을 같은 트랜잭션으로 처리합니다. 모임의 장소·안내·일정 취소 등 변경은 기존 신청자에게 알리고, 모집 마감과 좌석 수 변경은 취소로 오인하지 않습니다. 운영자가 공지를 삭제하면 신청 정리와 취소 알림 기록을 함께 저장합니다. 앱의 '예약 변경 소식'에서 최근 30일의 안내를 볼 수 있습니다.

전달 확인, 일시 오류 재시도, 중복 트리거 억제, 잘못된 기기 토큰 정리, 계정 변경·로그아웃 시 연결 해제를 포함합니다. FCM은 네트워크/OS에 따라 늦거나 누락될 수 있으며 전송과 확인 저장 사이 장애가 생기면 중복 수신 가능성이 남습니다. 개인정보가 담긴 편지·감정·메모 본문은 알림에 넣지 않습니다. 동의가 꺼져 있어도 앱 내 예약 내역과 변경 소식은 확인할 수 있습니다.

배포 도구는 `gardenPush` 수신 함수를 먼저 준비하고 `playNotifications`, `gardenApi`를 순서대로 수정합니다. 실행 중인 서버 원본·환경 변수·비밀키 참조·접속 권한을 보관하고 필요한 코드 구간만 대조하여 적용합니다. `socialAuth`는 변경하지 않습니다. 알림 전용 FCM/Eventarc 역할과 새 수신 서버의 호출 권한을 연결하며 Editor/Owner 권한을 부여하지 않습니다. 비밀키 원문은 읽거나 출력하지 않습니다. Cloud Shell에 원본과 진행 기록이 남으며 중단 시 출력된 `--resume` 명령으로 조회를 이어갑니다.

## 4. 앱 용량

과도한 비트레이트를 사용하던 고양이 영상 16개를 다시 압축했습니다. 해상도·프레임 수·재생 길이를 대조했고 오디오 트랙은 복사했습니다. 원본 대비 영상 합계 99,219,695바이트를 줄였습니다. 프레임 비교 SSIM은 모두 0.96을 넘으며 대표 장면도 직접 비교했습니다. 손실 압축이므로 원본 픽셀과 완전히 같다는 의미는 아닙니다. 음악·명상 오디오와 라이선스 문서는 변경하지 않았습니다.

최종 AAB 크기·서명·해시·패키지명은 함께 제공한 Verification.json에 기록합니다. AAB 파일 크기는 기기에 실제로 다운로드되는 APK 크기나 설치 후 용량과 다릅니다. 저사양 실기기 프레임률·배터리 사용량은 별도 확인이 필요합니다.

## 5. 다 자란 나무의 추억

다 자란 나무를 누르면 추억 관리 상단에 누적 추억 수, 함께한 날짜, 다음 30/100/365일 이정표, 최근 추억 세 개와 월별 기록집 연결이 나타납니다. '오늘의 추억 더하기'와 '모든 추억 보기'로 연결합니다. 기존 나무 성장, 물·거름·햇볕, 글 수정·삭제는 유지합니다. 개인 추억을 공개 정원에 자동 게시하지 않습니다.

## 검증 및 남은 확인

앱 전체 기존·신규 자동 테스트 626개 통과 후 마지막 문구/널 표기 정리와 미래 날짜 이동 방어를 추가했으며, 관련 39개와 작은 화면/글자 확대 3개를 다시 통과했습니다. 서버 테스트 178개, 배포 도구 로컬 검증 4개를 통과했습니다. 정적 분석 오류는 없습니다. 기존 경고 5개가 남아 있습니다.

실기기 확인: (1) 백업을 켠 뒤 글 작성·수정 및 다른 기기 복원, (2) Play 월간→연간 전환·취소·복원, (3) 두 계정 응원·선물 알림과 로그아웃 후 오발송 여부, (4) 운영자 모임 변경·취소 알림과 신청 내역, (5) 다 자란 나무의 추억/기록집 연결. 실제 전송이나 유료 결제를 개발 환경에서 대신 실행하지 않았습니다.
