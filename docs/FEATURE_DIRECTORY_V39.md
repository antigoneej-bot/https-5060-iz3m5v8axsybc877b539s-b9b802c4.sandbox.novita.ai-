# 마음냥 정원 1.0.36+39 변경 안내

기준 소스: 1.0.35+38. 홈과 마이에 ‘전체 기능’을 추가했습니다.
검색어와 10개 카테고리로 기능을 찾고 32개 바로가기로 이동할 수 있습니다.
로그인·구독·기록 조건은 기존 대상 화면에서 그대로 처리합니다.

## 회색 박스 원인과 수정

기존 고양이 도감을 펼치면 GridView에서 다음 예외가 재현됐습니다.
`type 'bool' is not a subtype of type 'double?' in type cast`

ExpansionTile의 PageStorageKey에 저장한 펼침 여부(bool)를 내부의 키 없는
GridView가 스크롤 위치(double)로 읽으면서 발생했습니다.
내부 GridView를 자연 높이의 Wrap으로 교체해 별도의 스크롤 상태를 없앴습니다.
좁은 화면·큰 글자는 2열, 넓은 화면은 3열로 표시하며 이미지 오류에는 고양이 아이콘을 표시합니다.
실제 사용자 휴대전화에서의 확인은 아직 하지 않았습니다.

## 확인 방법

1. 홈 또는 마이에서 ‘전체 기능’을 누릅니다.
2. ‘즐겨찾기’, ‘음악’, ‘백업’, ‘도감’을 검색하고 항목을 열어봅니다.
3. 나의 정원 → 기록·활동 → 함께한 고양이 도감을 펼치고 닫았다가 다시 엽니다.
4. 휴대전화 글자를 크게 설정해도 도감이 보이는지 확인합니다.

## 적용 범위

이 파일은 수정된 Flutter 전체 소스입니다. 설치용 APK나 Play 제출용 AAB는 포함하지 않습니다.
휴대전화에는 기존 배포 설정과 기존 서명키를 사용해 새로 빌드한 앱을 업데이트해야 합니다.
기존 앱 삭제는 필요하지 않습니다. 서버 변경은 없습니다.

이번 작업의 테스트 결과는 `verification/feature-directory-v39.json`에 기록했습니다.
이전 버전 문서의 빌드·테스트 결과는 이번 버전의 결과가 아닙니다.
