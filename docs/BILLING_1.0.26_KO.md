# 마음냥 정원 1.0.26+29 수정 및 확인

## 반영한 세 가지

1. **빛의 정수**: 나의 넓은 정원 상단에 실제 보유 개수를 표시합니다. 적립·사용 시 바로 갱신되며, 누르면 정원 꾸미기로 이동합니다. 별도 잔액을 새로 만들지 않았습니다.
2. **멤버십 해지**: Android에서 연결 가능 여부 조회만으로 해지 화면을 막던 처리를 제거했습니다. 해당 구독 관리 화면을 직접 열고, 실패하면 전체 구독 목록으로 연결합니다. 둘 다 실패하면 수동 경로를 안내합니다. Play에서 돌아오면 서버 상태를 다시 조회하고, 수동 재확인 버튼도 제공합니다. 해지 예약 시 이용 종료 날짜·시간을 표시합니다. 관리 화면을 열었다는 이유만으로 해지됐다고 표시하거나 이용 권한을 없애지 않습니다.
3. **연간 결제**: 앱의 고정 가격(연 29,000원) 및 정확히 15일인 체험만 허용하던 조건을 없앴습니다. Play에서 반환한 가격·체험·할인 단계와 자동 갱신 여부를 검증하고 그대로 표시합니다. 연간 P1Y/P12M을 지원합니다. 잘못된 주기·일회성/선불 상품·무료 갱신 상품은 거절합니다. 월간만 조회된 상태에서도 연간 구매를 시도하면 연간 상품을 다시 조회합니다. 선택한 상품과 offer token으로 결제하고 영수증의 계정·상품을 검증하는 기존 보호 장치를 유지했습니다.

Google Play 가격 자체는 변경하지 않았습니다. 월간 이용 중에는 기존 중복 구독 방지 정책을 유지합니다. 즉시 연간 전환은 이번 버전에 구현하지 않았으며, 자동 갱신 해지 후 기존 이용 기간이 끝나야 연간을 새로 선택할 수 있다는 안내를 넣었습니다.

## 배포 범위

이번 세 가지 수정에는 서버 재배포가 필요하지 않습니다. 정상 동작 중인 서버의 키·권한·환경 변수는 그대로 둡니다.

전체 소스에는 이미 서버에서 성공을 확인한 Facebook Return Fix v2의 성공 반환 URL 보완을 함께 보존했습니다. 이는 서버의 최신 로그인 수정을 이후 전체 소스 배포에서 잃지 않기 위한 것입니다. 향후 서버 전체 배포는 Cloud Shell에 보관한 기존 배포 설정도 함께 보존해야 합니다.

패키지명, Firebase 설정, 로그인 클라이언트 코드, Android 빌드/서명 설정, 에셋, pubspec.lock은 원본 그대로입니다. 서명키와 key.properties는 원본 ZIP에도 없으며, 새 키를 만들지 않았습니다.

## 앱 업데이트

1. 변경 파일 ZIP은 flutter_app 폴더 아래의 같은 경로에 병합합니다. 기존 프로젝트 전체를 삭제하거나 서명키를 덮어쓰지 않습니다. 기준 소스는 1.0.25+28입니다. 기준 이후 별도 수정이 있으면 파일 차이를 검토해 병합합니다.
2. 원래 서명키가 있는 빌드 환경에서 프로젝트 루트로 이동하여 `bash tool/build_mindnyang_play_bundle.sh`를 실행합니다. 기존 Play Integrity 및 서버 주소 설정을 유지하는 빌드 명령입니다.
3. 생성한 1.0.26+29 AAB를 같은 Play 앱의 내부 테스트에 올립니다. 이미 29 이상의 버전 코드를 사용했다면 실제 최신 코드보다 높여 빌드합니다.
4. 휴대전화에서는 Play 업데이트를 사용합니다. 이번 수정 때문에 앱을 삭제하거나 App Check 디버그 토큰을 등록할 필요는 없습니다.

현재 제공물은 수정 소스이며, 이 작업에서 서명된 AAB를 생성하거나 Play에 업로드하지 않았습니다.

## 실제 기기에서 마무리할 확인

- 정원: 상단 빛의 정수 확인 → 적립/사용 → 보유 개수 갱신.
- 해지: 구독 관리 열기 → Play에서 해지 완료 → 앱 복귀 → 해지 예약 및 이용 종료 시각 확인. 아직 유료 기간이 남아 있으면 혜택 유지가 정상입니다.
- 연간: 활성 월간 구독이 없는 테스트 계정에서 연간 선택 → Play 결제 창의 상품·금액·체험 조건 확인 → 라이선스 테스터 결제 → 앱 연간 상태 및 재실행 후 유지 확인.

연간 상품의 실제 활성화·국가·신규 가입 가능 여부는 현재 Play Console에서 직접 조회하지 못했습니다. 필요하면 Cloud Shell에 동봉된 `Mindnyang-Billing-Check.py`를 올려 `python3 "$HOME/Mindnyang-Billing-Check.py"`로 읽기 전용 확인을 할 수 있습니다. 해당 도구는 설정을 변경하지 않으며, 실제 가격과 기간을 표시합니다. 비밀키·토큰은 출력하지 않습니다.
