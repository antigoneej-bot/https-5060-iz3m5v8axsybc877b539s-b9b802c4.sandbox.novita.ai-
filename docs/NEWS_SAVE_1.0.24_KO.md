# 마음냥 정원 1.0.24+27 — 정원소식 저장 개선

## 변경 내용

- 제목과 내용만 쓰고 하단의 `저장하기`를 누르면 정원소식에 공개한다. 예약 없는 모임 안내도 허용한다.
- 예약 일정과 추가 정보는 선택 항목으로 접어서 표시한다. 달력과 숫자 시간 입력은 유지한다.
- 저장 버튼과 입력 오류 안내를 하단에 고정한다. 작은 화면에서 키보드가 떠 있어도 버튼을 사용할 수 있다.
- 제목/내용 누락 시 해당 입력 칸으로 이동한다. 잘못된 선택 링크는 무엇을 고쳐야 하는지 알려준다. `https://`가 생략된 도메인 주소는 자동 보완한다.
- 작성 중인 내용, 일정, 선택 정보를 기존 암호화 저장소에 계정·소식별로 임시저장하고 다시 열면 복원한다. 임시저장은 공개 게시와 구분해서 표시한다.
- 성공 응답의 소식 ID를 확인한 뒤에만 공개 저장 완료를 표시한다. 저장 중 중복 클릭과 뒤로가기를 막는다.
- 서버가 작업 시작 전에 `account-busy`로 거절했을 때만 제한적으로 재시도한다. 권한 오류나 결과를 알 수 없는 통신 실패는 자동 재전송하지 않는다.
- 기존 예약 일정의 날짜·인원 보호, 운영자 권한, App Check, 로그인과 결제 설정은 유지한다.

- 빌드 및 소스 ZIP에 섞여 있던 임시 영상 조각을 제외했다. 실제 영상 파일은 그대로 보존한다.

## 적용

서버 변경 없음. 기존 Play 앱의 내부 테스트에 AAB 1.0.24(27)를 올리고 앱을 업데이트한다. 재설치하거나 기기별 App Check 토큰을 추가할 필요는 없다.

## 기기 확인

정원소식에서 제목과 내용만 입력 → 저장하기 → 목록에 소식 표시를 확인한다. 모임은 예약 받기에서 달력·시간·인원을 추가한 후 저장한다. 테스트 게시물은 확인 후 운영자 메뉴에서 삭제할 수 있다.

실제 운영 서버에 게시하는 테스트는 이 작업 환경에서 수행하지 않았다. 자동화 테스트의 인증된 서버 응답은 테스트 대역이며, 배포된 앱과 계정의 실제 게시 확인을 대신하지 않는다.
