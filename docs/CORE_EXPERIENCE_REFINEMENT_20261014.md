# 마음냥 핵심 경험 보완 — 2026-10-14

사용자 요청: 90점대를 위한 제안 중 5번(명상·게임 개선)을 제외하고 1~4번 진행.

## 1. 홈의 세 가지 행동
상단은 마음 남기기 / 내 정원 / 지난 마음 돌아보기입니다. 움직이는 큰 정원이나 여러 독립 카드를 상단에 함께 배치하지 않습니다. 도착한 답장은 접힌 편지함에서 볼 수 있고 기존 고양이 도감·추가 기능은 더 보기에서 유지합니다. 돌아보기에서는 지난 편지로도 이동할 수 있습니다.

## 2. 정원에 남긴 시간
정원 상단 달력 버튼 → '정원에 남긴 기억'. 기존에 심은 식물의 이름·메모를 모아 다시 읽고 고칩니다. 실제 심은 날짜와 별도로 '기억할 날짜'를 선택할 수 있습니다. 날짜를 선택하지 않아도 기록할 수 있습니다. 30일·100일·주년을 표시합니다. 심은 날은 1일째, 100일은 시작일+99일이며 윤년 2월 29일의 평년 주년은 2월 28일입니다. 기존 날짜 없는 기록에 오늘 날짜를 임의로 채우지 않습니다.

기록은 기존 암호화 저장·백업에 포함됩니다. 기존 식물 종류별 저장 구조를 유지합니다. 이름·메모·기념일 삭제는 식물 성장에 영향을 주지 않습니다. 저장 전 뒤로가기에는 작성 내용 확인을 추가했습니다. 기념일은 앱 안에서 표시하며 새 푸시 알림은 추가하지 않았습니다.

고양이는 정원이 다른 화면에 가려지면 이동/주변 움직임을 멈추도록 바꿨습니다. 이전 산책 이미지·그림자·걸음 처리는 유지했습니다. 실제 걸음의 자연스러움을 새로 실기기 검증했다는 뜻이 아닙니다.

## 3. 통계에서 다음 돌봄까지
주간/월간 화면에서 후기를 기다리는 돌봄을 먼저 찾을 수 있습니다. 지난달 선택한 돌봄도 최근 후속 목록에서 이어볼 수 있고, 최근 세 개 외의 기록은 펼쳐 볼 수 있습니다. 최근 후기에 도움이 됐다고 남긴 활동은 다시 선택할 수 있습니다. 같은 활동의 최신 후기가 불편함이면 과거의 도움이 됐던 후기만을 근거로 다시 권하지 않습니다. 재선택은 돌봄 선택 단계로 바로 열리며 감정 점수는 복사/추정하지 않습니다. 실행했다고 자동 처리하거나 기분이 좋아졌다고 가정하지 않습니다.

## 4. 비공개 기록과 공개 정원
공개/갱신 전에 현재 공개 닉네임·식물 종류·장식과 공개 범위를 확인합니다. 편지·감정 점수·돌봄 후기·식물 개인 이름·메모·날짜는 공개 대상이 아닙니다. 서버의 허용 필드 목록을 유지하고 새 날짜/개인 기록이 섞인 요청이 거부되는 검사를 추가했습니다. 응원 선택창과 이웃 정원에서도 마음 기록은 보이지 않는다고 안내하고, 보내기 중에는 같은 상대에게 중복 요청하지 않도록 막았습니다.

## 변경하지 않은 영역
명상·호흡과 달려라 몽이의 플레이/결과/부활 코드는 이번 작업에서 변경하지 않았습니다. 이전 누적 패치에 있던 몽이 수정은 그대로 포함합니다. 결제·권한·서명키·Firebase 설정·패키지명·의존성·기존 영상/음성 파일도 유지합니다.
