# 달려라 몽이 보완 — 2026-10-13

## 변경
- 결과 화면에 들어오면 먼저 기본 점수·빛의 정수·도감·성장 보상을 저장합니다. 실패 시 같은 세션 ID로 재시도합니다.
- 선택 화면 여러 단계를 결과 한 화면으로 합쳤습니다. 정원 이동/마음 돌아보기는 위쪽, 씨앗 선택은 접힘 영역입니다.
- 씨앗 심기와 다음 단계 상승은 별도 선택·별도 중복 방지 저장입니다. 기존 재화·점수·씨앗 정책은 유지하며 기본 보상을 다시 주지 않습니다.
- 이미 심은 씨앗은 보관함으로 들어가고 물주기로 성장하는 기존 정책을 유지합니다.
- 게임 설정의 감정/기본 강도 3을 감정 일기에 자동 저장하지 않습니다. 선택형 '지금 마음 돌아보기'는 기존 SelfCareEntryScreen에서 새로 직접 선택합니다. 1~5 강도를 1~10 마음 편안함으로 환산하지 않습니다.
- 이전에 저장된 일기·통계는 임의 삭제하거나 과거 기록의 의미를 재분류하지 않았습니다.
- 게임 도감/꽃 수/성장 점수는 게임 활동입니다. 새로 직접 기록하는 마음 상태와 구분합니다.
- 일반 플레이는 20/25/30개 목표, 60/75/90초 제한입니다. 기존 무한도전과 시간 제한 없는 연습은 유지합니다.
- 상단에 일시정지를 추가했습니다. 엔진 재개 요청이 들어와도 사용자가 쉬는 동안에는 멈춤을 유지하며 소리 재개도 막습니다.
- 중첩 내비게이터의 시스템 뒤로가기를 maybePop으로 전달해 저장·종료 확인을 건너뛰지 않도록 했습니다.
- 부활 처리에 중복 클릭 방지·실패 안내·상태 복구·동일 요청 ID로 재시도를 추가했습니다. 저장이 완료된 뒤 응답이 실패해도 재시도에서 재차 차감하지 않도록 거래 영수증을 사용합니다.

## 확인한 것과 한계
- Dart 3.9.2로 실제 시간/목표 정책 계약 검사 실행 및 해당 두 파일 분석: 통과.
- 앱 lib 전체와 관련 테스트 Dart 구문 파싱: 통과. 전체 Flutter 타입 분석이 아닙니다.
- 로컬 import/asset/XML 구조 검사: 통과.
- Flutter SDK가 없어 Flutter analyze/test, 웹/APK 빌드, 실제 UI/소리/터치는 실행하지 못했습니다.
- 이전 backend 검증 로그는 과거 작업의 결과이며 이번에는 backend를 수정/재실행하지 않았습니다.
- ZIP preview 폴더는 앞선 정원 시안입니다. 이번 게임의 실행 미리보기가 아닙니다.

## 실제 폰 확인
- 360/390px: 결과 보상, 정원 이동, 마음 돌아보기, 접힘 씨앗 목록이 가리지 않는지.
- 완료 결과 자동 저장 → 뒤로가기 → 정원 보관함/재화 확인. 반복 탭해도 보상이 한 번인지.
- 마음 돌아보기를 누르지 않은 플레이가 감정 일기에 생기지 않는지. 직접 기록한 값은 주간/월간 자기돌봄 통계에서 확인.
- 일시정지 → 홈 버튼 → 앱 복귀 → 계속하기 전 시간/캐릭터/소리가 멈춰 있는지.
- 일시정지에서 그만하기: 진행 중인 판을 버린다는 안내와 소리 종료 확인.
- 부활 오류 후 다시 시도/닫기, 재화 부족, 무료/구독 권한 확인.
- 1/2/10단계 제한시간 및 목표 달성 가능성 확인. 실제 평균 플레이 시간은 아직 측정하지 않았습니다.
