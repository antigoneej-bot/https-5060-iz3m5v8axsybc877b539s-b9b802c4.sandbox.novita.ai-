# 살아 있는 마음냥 정원 — 실제 앱 소스 반영

2026-10-04. 최신 검토본을 기준으로 홈 정원과 넓은 정원에 적용했습니다.

- 소나무, 벚꽃, 단풍, 용서, 사랑, 평안: 투명 배경의 입체 식물 이미지 18개를 하나의 atlas로 묶었습니다. 심기 1–2회는 어린 식물, 3–5회는 성장, 6–9회는 성숙, 10회 이상은 성숙한 식물과 부드러운 빛으로 표시합니다. 아직 심지 않은 식물은 표시하지 않습니다.
- 씨앗 선택 화면도 새 식물 이미지를 사용합니다.
- 구름 이동, 햇살과 빛줄기, 반짝임, 가을 낙엽, 개울의 물결을 추가했습니다. 밤에는 별빛과 반딧불 색감으로 전환됩니다.
- 넓은 정원의 몽이는 호흡하며 살랑거리고, 식물은 뿌리를 기준으로 흔들립니다. 배치 좌표에는 영향을 주지 않습니다.
- 넓은 정원에 일시정지 버튼을 추가했습니다. 기존 전체 움직임 설정, 운영체제 동작 줄이기, TickerMode와 앱 백그라운드 상태를 따릅니다.
- 기존 씨앗 횟수, 보상, 배치·잠금 해제, 백업 구조는 변경하지 않았습니다.

## 구성

`lib/mongi/widgets/garden_ambient.dart`: 공통 환경 효과와 바람 움직임.
`lib/mongi/widgets/living_garden_scene.dart`: 홈 연결 및 공통 식물 atlas 표시.
`lib/mongi/widgets/garden_world_view.dart`: 넓은 정원 연결, 동작 제어.
`lib/mongi/screens/garden_world_screen.dart`: 설정 전달 및 씨앗 선택 이미지.
`assets/living_garden/plants.webp`: 6열 × 3행 투명 식물 atlas, 약 1.6 MB.

렌더링된 3D 이미지와 Flutter의 레이어·애니메이션을 결합한 2.5D 방식입니다. 자유 회전하는 3D 메시나 골격 애니메이션은 아닙니다.

## 확인

Flutter 3.35.4 / Dart 3.9.2에서 변경된 Dart 파일 정적 분석 통과.
기존 관련 테스트 37개 통과, 새 동작 일시정지/재생/생명주기 및 전체 설정 테스트 2개 통과.
홈·넓은 정원의 Flutter 캡처 테스트 2개 통과, 모바일 및 넓은 화면 캡처를 직접 확인했습니다.
`docs/living-garden-day.png`, `living-garden-night.png`, `expanded-garden.png`, `expanded-garden-overview.png`에 실제 위젯 캡처가 있습니다.

Android/iOS 실기기 설치·프레임 성능 측정과 출시 빌드는 이번 환경에서 수행하지 않았습니다.

실행: 프로젝트 루트에서 `flutter pub get`, `flutter run`.
테스트: `flutter test test/garden_world_view_test.dart test/living_garden_scene_test.dart`.

## 물주기와 벤치 크기 조정

넓은 정원에서 `물 주기`를 누른 뒤 꽃이나 나무를 누르면 2.2초간 물방울과 물결이 나타나고 식물이 살짝 반응합니다. 동작 줄이기/움직임 끄기 상태에서는 안내 문구로 반응합니다. 물주기는 무료 시각적 돌봄 동작이며 씨앗이나 성장 횟수, 저장 기록을 변경하지 않습니다. 배치 모드와 물주기 모드는 동시에 켜지지 않습니다. 읽기 전용 정원에는 돌봄 버튼이 표시되지 않습니다.

나무 벤치 그림은 88에서 158로 약 1.8배 확대했으며, 선택 영역도 함께 확대했습니다. 기존 배치 좌표는 유지합니다.
추가 확인: 물주기 대상/종료, 움직임 줄이기 상태, 확대 벤치 선택 영역 테스트 통과. 정원 위젯 테스트 및 캡처 8개 통과, 변경 파일 정적 분석 통과. 브라우저 체험에서도 물주기·배치·되돌리기와 360px 화면 표시를 확인했습니다.

## 낮의 나비 · 밤의 반딧불이 · 벤치 · 눈 깜빡임

- 낮에는 꽃 주변을 오가며 날개를 움직이는 나비, 밤에는 느린 곡선으로 날면서 빛이 밝아졌다 약해지는 반딧불이를 표시합니다. 홈과 넓은 정원 모두 공통 환경 효과를 사용합니다.
- 벤치는 장미 장식, 둥근 목재 등받이와 초록 쿠션이 있는 투명 이미지로 교체했습니다. 확대된 선택 영역과 기존 위치는 유지됩니다.
- 몽이는 약 3~6초 간격으로 짧게 눈을 깜빡이며 가끔 두 번 깜빡입니다. 원래 몸 이미지는 유지하고 눈 주변에만 닫힌 표정을 합성합니다. 기존 24초 환경 시계를 공유하며 별도 무한 타이머를 추가하지 않습니다.
- 움직임 설정과 동작 줄이기, 화면 비활성 상태를 따릅니다.
- 새 자산: `bench.webp`, `cat_blink.webp`. 이미지와 코드 모두 전체 소스에 포함했습니다.
- 이번 변경 확인: 정원/홈 위젯·캡처 13개와 눈 깜빡임 테스트 1개 통과, 변경 소스 정적 분석 통과. 실제 Flutter 캡처에서 벤치 및 눈 감은 표정 확인. 브라우저 체험의 낮/밤·움직임·물주기·배치·모바일 표시도 확인했습니다. 실기기 설치·프레임 측정은 아직 수행하지 않았습니다.

## 연노랑 나비 디자인

낮의 나비를 크림빛 연노랑 한 색상으로 통일했습니다. 위·아래 날개의 곡선, 옅은 날개맥, 작은 하이라이트와 더듬이를 추가하고 날개를 접을 때도 형태가 보이도록 날갯짓 폭을 조정했습니다. 변경 파일 정적 분석 및 홈/확장 정원 캡처 확인, 브라우저 동작 확인을 마쳤습니다.
