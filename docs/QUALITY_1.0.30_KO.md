# 마음냥 정원 1.0.30+33 — 이용 흐름과 상태 안내 개선

기준 소스: 1.0.29+32. 이번 변경은 Android 앱 업데이트로 적용합니다. 이번 변경을 위한 서버 재배포는 필요하지 않습니다.

## 반영 내용

### 마이에서 로그인·구독·백업 상태 확인

- 로그인 방법, 월간/연간 구독, 이용 기간과 자동 갱신 상태를 한 카드에 표시합니다. 서버가 갱신 여부를 알려주지 않은 경우에는 갱신을 확정해서 표시하지 않습니다.
- 해지 예약 상태에서는 남은 이용 기간과 자동 갱신이 꺼졌음을 안내합니다. 기간 종료 후에는 기존 기록을 보관한다는 문구를 표시합니다.
- 상태 확인이 누락되거나 오래됐으면 확인 필요로 안내합니다. 통신 실패를 무료 계정으로 오인해 표시하지 않습니다.
- 구독 관리·구매 복원과 기록 백업·복원으로 바로 이동합니다. 기존 결제 처리와 권한 판정은 유지합니다.
- 자동 백업 켜짐 여부와 이 기기에서 확인한 마지막 서버 백업 시각을 표시합니다. 마지막 백업 이후의 기록까지 모두 저장됐다고 표현하지 않습니다.
- 계정 변경 시 이전 계정의 지연된 응답을 표시하지 않습니다. 로그인만으로 기록이 다른 기기에 자동 이전된다고 안내하지 않습니다.

### 홈과 지난 마음 보기

- 주요 선택을 마음 남기기·정원 가꾸기·지난 마음 보기로 정리했습니다. 조용히 쉬기는 보조 버튼으로 유지합니다.
- 정원 미리보기와 다른 활동은 펼쳐서 볼 수 있게 정리했습니다. 기존 기능과 기록은 삭제하지 않았습니다.
- 지난 마음 보기에서 편지, 도움이 됐던 돌봄, 마음의 흐름, 정원 기록집으로 이동합니다.
- 휴대전화에서는 버튼을 세로로 배치해 글자 확대에도 대응합니다.

### 기록에서 다시 돌봄으로

- 돌봄 기록에 최근 30일 동안 직접 완료하고 도움이 됐다고 표시한 행동을 다시 꺼내는 카드를 추가했습니다.
- 같은 행동·상황에서 더 최근에 도움이 안 됐거나 잘 모르겠다고 남겼으면, 이전의 긍정적 후기만으로 그 행동을 다시 권하지 않습니다.
- 해본 일에 후기가 없으면 느낌을 남기는 동선을 제공합니다. 다른 돌봄을 고르거나 정원에서 쉬는 선택도 제공합니다.
- 계획 추가나 화면 열기를 행동 완료로 계산하지 않습니다. 기록 수를 치료 효과나 심리 진단으로 표현하지 않습니다.
- 새 기록이 없는 이용자에게는 빈 추천 카드를 먼저 보여주지 않습니다.

### 구독 혜택 설명

- 시간과 함께 가꾸는 정원, 한 달의 기록집, 함께 남기는 나무의 기억을 중심으로 설명을 정리했습니다. 나머지 혜택은 펼쳐 볼 수 있습니다.
- 상품 ID, 가격 설정, 결제 승인 로직과 기존 혜택 권한은 변경하지 않았습니다. 오프라인 클래스 비용을 구독에 포함한다고 안내하지 않습니다.
- 실제 광고 ID를 넣지 않은 빌드로 광고는 비활성입니다.

## 검증

- Flutter 전체 테스트 616개 통과. 이후 편지 안내 문구와 조건문 괄호 정리 후 관련 테스트 및 서버 연결 설정을 켠 구독 테스트 64개가 통과했습니다.
- 360px/390px 폭과 글자 2배 확대에서 홈 주요 버튼 배치를 위젯 렌더링으로 확인했습니다. 실제 Android 기기 전체 화면 검증을 대신하지 않습니다.
- 계정 변경 중 지연 응답, 새로고침 실패, 오래된 구독 정보, 월간/연간·해지 예약·만료, 실제 돌봄 후기 조건을 자동 검사했습니다.
- 최종 정적 분석 및 AAB 버전·패키지·서명·원본 일치 결과는 함께 제공하는 Verification.json에 기록합니다.

## 설치 후 확인할 항목

1. Play Console 내부 테스트에 버전 코드 33의 AAB를 올린 뒤 테스터 기기에서 업데이트합니다. 기존 앱을 삭제할 필요는 없습니다.
2. 마이에서 현재 로그인과 실제 Play 구독 상태가 맞는지 확인합니다. 새로고침 및 구독 관리·구매 복원 버튼을 확인합니다.
3. 백업 설정과 표시된 마지막 시각이 맞는지 확인합니다. 실제 복원은 별도 테스트 기기와 테스트 기록으로 검증합니다.
4. 홈 세 가지 버튼과 지난 마음 보기를 눌러 실제 기록·돌봄·정원으로 이동하는지 확인합니다.
5. 돌봄을 완료하고 느낌을 남긴 뒤 다시 꺼내기 카드가 맞는지 확인합니다. 도움이 되지 않았다고 후기를 바꾼 경우도 확인합니다.
6. 두 기기 간 응원·선물, 실제 월간/연간 구매·취소·갱신, 알림 권한과 수신은 실기기 검증이 필요합니다.

## 범위와 보존

- 이미지·영상·음원, 고양이 애니메이션, 나무 성장 규칙, 서버 코드, 로그인 구현, Firebase Android 설정과 서명키는 이번 작업에서 변경하지 않았습니다.
- AAB 용량 최적화나 정원 애니메이션 전체 재제작을 완료한 버전은 아닙니다. 용량·속도·발열은 실제 기기 측정 후 별도로 개선해야 합니다.
- 자동 검사 통과를 시장성이나 종합 90점 달성으로 환산하지 않습니다. 첫 사용 성공률, 반복 방문, 구매·복원 성공과 사용자의 돌봄 경험을 실제 테스트에서 확인해야 합니다.
- 전체 소스 ZIP에는 서명키, key.properties, 개인 비밀값, 빌드 캐시를 넣지 않습니다. 기존 프로젝트의 해당 파일을 그대로 보존하세요.
- 이번 수정 ZIP은 버전 32 소스에 병합하는 용도입니다. 이후 별도 수정이 있다면 PATCH_MANIFEST.json의 변경 전 해시와 대조하세요.
