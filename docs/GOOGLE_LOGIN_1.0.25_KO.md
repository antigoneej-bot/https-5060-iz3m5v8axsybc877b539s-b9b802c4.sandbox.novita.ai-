# 마음냥 정원 1.0.25 (28) — Google 로그인 연결

## 반영 내용

- 사용자가 Firebase에서 새로 받은 `google-services.json`을 Android 앱에 반영했습니다.
- 프로젝트 `mycatapp-99bc8`, 패키지 `com.mysticcat.journal`, Firebase Android 앱 ID와 기존 API 키가 이전 버전과 동일함을 확인했습니다.
- Android OAuth 클라이언트와 웹 OAuth 클라이언트가 포함되어 있습니다. Gradle의 Google Services 플러그인이 `default_web_client_id` 리소스를 생성하고 기존 Google 로그인 코드가 이 값을 사용합니다.
- 버전을 `1.0.25+28`로 올렸습니다. 이전 1.0.24의 간편 공지 저장, 캘린더·숫자 시간 예약 기능은 유지합니다.
- 카카오 로그인·결제·정원 서버 코드 및 운영 설정은 변경하지 않았습니다. 이번 변경을 위한 Cloud Shell 서버 재배포는 필요하지 않습니다.
- 출시 빌드는 Play Integrity를 사용하며 App Check 디버그 제공자와 전체 프리미엄 잠금 해제를 끕니다.

## 업데이트와 실제 확인

1. 기존 Play Console 앱의 내부 테스트 트랙에 새 AAB(버전 코드 28)를 업로드합니다.
2. 휴대전화에서 같은 내부 테스트 링크를 통해 **업데이트**합니다. 기존 앱 삭제는 필요하지 않습니다.
3. 마이 → 간편 로그인 → 구글로 계속하기에서 계정을 선택합니다.
4. 계정 화면이 로그인 완료 상태가 되는지, 앱을 종료하고 다시 열어도 유지되는지 확인합니다.
5. 냥이 마을 등 계정이 필요한 기능이 정상적으로 열리는지 확인합니다.

기존 카카오 구매 계정을 유지하려면 카카오로 로그인하세요. 별도로 로그인한 Google 계정과 카카오 계정은 자동으로 합쳐지지 않습니다. Google 첫 로그인은 기존 구독 계정과 구분해 테스트해야 합니다.

## 검증 범위

첨부된 설정 파일에 등록된 SHA-1은 확인할 수 있지만 실제 Play 배포 인증서와의 일치, Firebase 제공자 활성화 상태, 계정 선택 및 로그인 성공은 실제 기기 확인이 필요합니다. 빌드 성공만으로 로그인 성공을 확정하지 않습니다.

새 설정 파일은 Android용입니다. iOS Google 로그인 설정은 별도로 필요합니다.
