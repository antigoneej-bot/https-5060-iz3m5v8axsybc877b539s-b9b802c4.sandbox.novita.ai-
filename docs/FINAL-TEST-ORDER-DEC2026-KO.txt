통과 기록은 버전·날짜와 함께 남겨주세요. 실행하지 않은 항목은 '미검증'으로 둡니다.

개인 기록을 지키는 준비
- 개인 기록이 있는 Android 사용자에서는 업데이트와 기존 기록 열람을 먼저 확인합니다. 앱 삭제, 데이터/저장공간 초기화, 계정 삭제, 복원 실패 실험을 하지 않습니다.
- 복원·계정 전환·선물·결제 취소/실패는 별도 Android 사용자와 테스트 계정에서 진행합니다. 삼성 Buddy3의 별도 사용자 기능을 사용하거나 별도 테스트 기기를 사용합니다. USB 연결은 필요 없습니다.
- 이웃 검증에는 테스트 계정 A와 B가 필요합니다. 다른 테스터가 B를 맡아도 됩니다. 계정이 준비되지 않으면 해당 항목을 보류하고 나머지를 진행합니다.
- 백업 암호·로그인 비밀번호·인증 코드·토큰은 채팅이나 결과표에 쓰지 않습니다.
- 내부 테스트 참여자와 Play 라이선스 테스터는 구분됩니다. 결제창에 테스트 구매 안내와 테스트 결제 수단이 보이는지 먼저 확인합니다. 실제 카드 결제 화면이면 결제를 중단합니다.

1단계 — 업데이트와 기존 기록 보존 (가장 먼저)
T01 [ ] 설치 버전 확인
  Play 내부 테스트에서 업데이트하고 앱 정보의 버전/빌드 코드를 기록합니다. 업데이트 대신 앱 삭제를 요구하면 멈춥니다.
  기대: 기존 설치 위에 업데이트되고 앱이 정상적으로 열림.
T02 [ ] 기존 기록 비교
  업데이트 전후 같은 고양이 이름·외형, 기존 편지 2개, 식물 2개(성장/위치/오늘 물주기), 씨앗 수를 비교합니다. 업데이트 전 캡처가 없다면 기억나는 기록의 원문과 날짜부터 확인합니다.
  기대: 기록이 남고 식물·재화가 임의 초기화되지 않음. 앱을 닫았다 열어도 동일.
  기록이 사라지거나 다른 사람 기록이 보이면 여기서 중단하고 알려주세요.

2단계 — 고양이와 마음 기록 (별도 테스트 데이터)
T03 [ ] 동반 고양이 6종과 이름
  6종을 하나씩 선택해 홈에 반영되는지 보고 이름을 정한 뒤 앱을 다시 엽니다. 영어로 바꿔도 직접 지은 이름은 그대로여야 합니다.
  기대: 선택한 외형과 이름 유지. 감정 고양이 37종 선택 때문에 동반묘가 바뀌지 않음.
T04 [ ] 고양이 움직임과 하루 보상
  눈 깜박임·터치 반응을 보고, 고양이 움직임 OFF/ON, 정원 배경 효과 OFF, 다른 탭 이동, 백그라운드 복귀를 각각 확인합니다. 휴대폰 동작 줄이기도 확인합니다.
  기대: 고양이 움직임 OFF/동작 줄이기에서 불필요한 동작 중지, 정원 효과 OFF만으로 홈 눈 깜박임은 꺼지지 않음. 첫 인사 보상 이후 연속 터치로 보상이 반복 지급되지 않음(80번 이후의 하루 첫 인사 보상 정책 유지).
T05 [ ] 기록 저장과 재진입
  테스트 편지에 구분되는 짧은 문장을 적고 감정 고양이를 선택해 저장합니다. 지난 기록·캘린더·통계에서 확인한 뒤 앱을 닫고 다시 엽니다.
  기대: 원문·날짜·감정이 맞고 중복 저장되지 않음. 기존에 받은 답장도 열람 가능. 새 답장 생성 기능을 추가했다고 가정하지 않음.

3단계 — 실제 정원에서 심기·찾기·돌보기
T06 [ ] 진입 경로와 위치 찾기
  정원 탭, 홈 정원 카드, 모든 기능의 내 정원 경로로 각각 들어갑니다. 내 식물에서 화면 밖 식물을 선택합니다.
  기대: 같은 저장 정원이 열리고 심기/물주기/내 식물 도구를 사용할 수 있음. 식물을 찾으면 해당 위치와 이름이 보임.
T07 [ ] 심기 취소·완료·중복 터치
  심을 수 있는 기존 종류를 선택해 위치 선택을 취소하고 씨앗 수를 확인합니다. 다시 유효한 위치에 심을 때 확인 버튼을 연속으로 눌러봅니다.
  기대: 취소 시 씨앗 유지. 성공 시 한 번만 차감·생성되고 실제 새싹과 위치가 저장됨. 같은 종류를 임의로 여러 개 만들지 않음. 이미 전부 심었다면 해당 조건을 기록하고 T08로 진행.
T08 [ ] 기존 식물에 마음 남기기·물주기·이동
  기존 식물에 테스트 마음을 남기고 추억을 확인합니다. 오늘 아직 물을 주지 않은 식물에 물을 주고 재시도합니다. 위치 옮기기에서 취소 후 확정도 해봅니다.
  기대: 마음 추가/이동으로 씨앗·성장·기존 추억이 초기화되지 않음. 물주기 하루 제한과 물방울 표시가 일치. 이동 확인 전 좌표 유지, 확정 후 재실행해도 위치 유지. 하루 성장 경과는 다음 날 확인하며 휴대폰 날짜를 바꾸지 않음.
T09 [ ] 가로 정원·전체 지도·장식
  가꾸는 정원과 쉬어가는 정원을 가로로 열고 드래그/확대/축소, 도구 접기/펼치기, 전체 지도→정원 복귀를 확인합니다.
  기대: 도구를 접어도 캔버스가 줄지 않고 이전 카메라로 돌아옴. 장식 위치 유지. 쉬어가는 정원/이웃 정원에는 내 식물 편집 조작이 없음.

4단계 — 백업·복원 (개인 기록이 없는 별도 환경에서만)
T10 [ ] 암호화 파일 백업
  테스트 편지·고양이·식물 상태를 적어두고 모든 기능 → 기록 보관·백업·잠금 → 암호화 백업 파일 저장을 실행합니다. 파일을 실제로 찾을 수 있는지 확인합니다.
  기대: 성공 안내와 실제 파일이 있고 백업 암호를 별도로 보관할 수 있음.
T11 [ ] 파일 복원·잘못된 암호
  같은 테스트 환경에서 백업 파일을 선택해 잘못된 암호로 먼저 시도하고, 올바른 암호로 미리보기→복원을 실행합니다. 같은 백업을 다시 복원해봅니다.
  기대: 잘못된 암호로 기존 기록이 바뀌지 않음. 정상 복원 결과가 원문/정원 상태와 맞고 반복 복원으로 중복 증가하지 않음. 성공/추가 기록 수 안내를 기록.
T12 [ ] 서버 백업·끊김 복구
  테스트 계정 A로 '지금 서버에 백업' 후 서버 백업 목록/복원을 확인합니다. 네트워크를 끊어 백업을 시도하고 다시 연결합니다.
  기대: 실패를 성공으로 표시하거나 마지막 성공 시간을 갱신하지 않음. 재연결 후 재시도 성공. 자동 백업 OFF가 재실행 후에도 유지. 새 환경에서 같은 계정 A로 복원하는 검사가 없으면 '다른 환경 복원 미검증'으로 기록.

5단계 — 이웃 A/B 교차 검증 (두 테스트 계정)
T13 [ ] 초대와 읽기 전용 방문
  A가 B의 초대 코드로 찾아 요청하고 B가 수락합니다. 서로 정원을 방문합니다.
  기대: 요청/수락 상태 일치, 상대 정원을 수정할 수 없음. 무작위 방문만으로 친구 등록이나 개인 기록 공유가 생기지 않음.
T14 [ ] 공개 동의·철회·즐겨찾기
  B가 무작위 이웃 방문 허용을 직접 켭니다. A가 방문해 즐겨찾기한 후 B가 비공개/허용 해제로 바꿉니다. A에서 목록 갱신·재방문합니다.
  기대: 동의 전 무작위 목록에 임의 공개되지 않음. 즐겨찾기해도 철회 후 접근 불가. 상대 편지·감정 원문·이메일·비공개 나무 메모/날짜가 보이지 않음. 별도 명시 공유한 내용만 허용.
T15 [ ] 양방향 차단과 신고
  A가 B를 차단하고 양쪽에서 새로 방문/선물을 시도합니다. 차단 해제 후 상태를 다시 확인합니다.
  기대: 어느 한쪽 차단으로 양방향 접근 제한. 차단한 상태에서 즐겨찾기로 우회 불가. 신고 창 진입/취소를 확인하되 실제 사용자를 테스트로 신고하지 않음. 실제 신고 전송은 관리자와 테스트 대상/정리를 합의한 경우에만 진행.
T16 [ ] 응원·선물 중복과 내역
  A가 허용된 응원/선물 하나를 B에게 보내며 연속 터치와 화면 재진입을 확인합니다. A의 보낸 내역과 B의 받은 내역/수령을 비교합니다.
  기대: 한 번 전송한 선물이 중복 차감/수령되지 않음. 보낸 내역은 A의 내역만 보임. 받을 수 없는 상대에게 실패 안내가 나오고 재화가 잘못 줄지 않음.
T17 [ ] 느린 연결·반복 추천·빈 상태
  연결을 끊었다 다시 켜 이웃 첫 진입/재시도를 확인하고, 공개 정원이 여럿이면 다른 정원으로 여러 번 이동합니다.
  기대: 무한 로딩 없이 실패/재시도 안내, 직전 정원 연속 반복 방지. 추천 가능한 정원이 없으면 빈 상태 안내. 해당 상황을 만들 수 없으면 보류로 기록하고 운영 사용자 데이터를 바꾸지 않음. 첫 진입과 재진입 시간을 따로 적음.

6단계 — 계정·결제 (Play 테스트 결제만)
T18 [ ] 로그인 취소·실패·로그아웃
  별도 테스트 환경에서 로그인 창 취소, 연결 끊김, 정상 로그인, 로그아웃·재로그인을 확인합니다.
  기대: 취소/실패를 로그인 성공으로 표시하지 않고 로컬 기록이 사라지지 않음. 계정 전환 시 온라인 이웃·선물·구독·백업이 다른 계정에 섞이지 않음. 앱 안내대로 기기 로컬 기록이 로그아웃 후 남는 것 자체는 오류로 보지 않음.
T19 [ ] 구매 취소·실패·성공·복원
  Play 라이선스 테스터임을 확인하고 테스트 결제 수단으로 취소/거절/성공을 확인합니다. 재실행 후 구매 복원, 이미 구독 중일 때 다시 누르기를 확인합니다.
  기대: 상태가 맞고 실제 결제나 중복 구독을 만들지 않음. 테스트 보류/만료/계정 전환은 준비된 테스트 계정에서만 확인.
  중요: 현재 전체 개방 빌드에서는 기능이 열린 것만으로 유료 권한 검증에 통과한 것이 아닙니다. 최종 출시 전 잠금 설정의 앱/서버 조합으로 T19를 다시 확인합니다. 지금 서버 테스트 개방을 임의로 끄지 않습니다.

7단계 — 알림·오디오·언어·사용성
T20 [ ] 알림과 오디오
  알림 권한 거절/허용, 설정 OFF→앱 재실행, 한국어/영어 알림 수신, 알림을 눌러 목적지로 이동을 확인합니다. 명상 음원을 재생하고 탭 이동·백그라운드·복귀·앱 종료를 확인합니다.
  기대: 설정과 안내에 맞게 동작하고 소리가 중복 재생되지 않음. 알림 취소 실패는 실패/대기 안내가 나오며 OFF 의사가 재실행 후 ON으로 바뀌지 않음.
T21 [ ] Buddy3 화면·접근성·성능
  세로/가로, 큰 글자, 키보드 표시, TalkBack으로 기록·심기·물주기·백업 버튼을 사용합니다. 정원을 10분 사용하고 백그라운드에서 돌아옵니다.
  기대: 얼굴/귀와 핵심 버튼이 잘리지 않고 스크롤로 접근 가능. 버튼의 역할을 읽어줌. 반복 종료·지속적 심한 버벅임·비정상 발열 여부와 시작/종료 배터리 % 기록(단순 % 차이만으로 배터리 결함 확정하지 않음).
T22 [ ] 영어와 광고
  영어로 홈·내 정원·이웃·백업·설정·구독 안내를 확인합니다. 앱 기본 이름/안내가 영어이고 직접 쓴 이름·편지는 유지돼야 합니다.
  광고는 테스트 설정에서만 확인하고 실제 광고를 반복 클릭하지 않습니다. 유료 광고 제거 조건은 잠금 설정 출시 후보에서 별도로 확인합니다.

8단계 — 개발자와 함께 마감할 항목
D01 [ ] Crashlytics: 개인 기록 없는 전용 테스트 실행에서 오류 보고 동의 후 통제된 오류의 실제 Firebase 수신, 원문 미첨부, 동의 OFF 유지, 필요한 심볼/매핑을 확인. 개인 기록이 있는 앱을 강제 종료시키는 검사를 하지 않음. 일반 98 앱에는 사용자가 누를 강제 크래시 버튼을 추가하지 않음.
D02 [ ] GitHub 자동 검사: 최종 소스 커밋의 원격 실행 성공을 확인하고 링크/커밋 기록.
D03 [ ] 출시용 권한: 사용자 승인 시점에만 앱/서버 테스트 전체 개방 해제, 실제 유료 상태와 무료 접근, 광고 제거, 구매 복원/만료를 테스트 결제로 확인. 가격·상품 ID 변경 없음.
D04 [ ] Play 마감: 전체 트랙/업로드 번들의 최대 코드 확인, 더 높은 코드·기존 서명·동일 패키지로 최종 AAB 생성. 실제 공개된 개인정보/계정 삭제 안내와 Play 데이터 보안 신고 대조. 이번 점검표는 법적 적합성 전체 검토를 대신하지 않음.
D05 [ ] 최종 후보 재확인: 최종 AAB를 내부 테스트에서 설치하고 T01~T02, T05~T08, T10~T12, T14~T16, T19~T20의 핵심 경로를 다시 확인. 결함 수정 때는 영향받은 항목을 재확인하며 과거 버전 통과를 새 버전 결과로 옮기지 않음.

12월 초까지의 권장 일정 — 자동 실행/자동 출시 일정이 아닙니다
11/7~11/15: 1~3단계. 업데이트/고양이/기록/정원 기본 흐름을 먼저 확정.
11/16~11/22: 4~6단계. 별도 계정으로 복원·이웃·테스트 결제 예외를 확인.
11/23~11/26: 7단계와 D01~D02. 실기기 알림/오디오/성능·진단·원격 CI 확인.
11/27~11/30: D03~D05. 출시 설정과 최종 후보를 고정하고 핵심 회귀 확인.
12/1~12/7: 사용자가 결과를 보고 출시 여부 결정. Play 심사 완료 시각은 보장하지 않으며 제출 준비는 미리 진행. 미완료 항목은 통과로 처리하지 않음.

중단하고 먼저 알려야 할 결과

- 허용하지 않은 실제 과금, 중복 결제/차감, 차단·공개 철회 우회
- 복원 실패로 원본 손상, 반복적인 앱 종료, 핵심 버튼 사용 불가
