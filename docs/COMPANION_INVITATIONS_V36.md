# 고양이 소식 · 버전 1.0.33+36

정원과 마음 돌보기의 같은 반려 고양이가 밥·놀이·쓰다듬기·같이 쉬기를 청하는 기기 내 알림입니다. 서버 배포나 별도 로그인 설정 변경은 필요하지 않습니다.

## 사용 방법

1. 마이 → 돌보기 리마인더 → 고양이 소식을 켭니다. 고양이 돌보기 화면에서도 같은 설정을 바꿀 수 있습니다.
2. 기기 알림 권한을 허용합니다. 기본은 OFF, 시간은 19:00입니다.
3. 시간을 누르면 숫자로 시·분을 지정합니다. 허용 시간은 08:00~21:59입니다.
4. 알림을 누르면 고양이 돌보기 화면이 열립니다. 알림을 여는 것만으로 돌봄이 처리되지는 않습니다.
5. 밥 주기·놀아주기·쓰다듬기·빗질하기·같이 쉬기를 선택합니다. 기존 이름, 성장 기록, 정원의 고양이와 연결됩니다.

## 동작 규칙

- 고양이 소식은 날짜별 최대 한 번입니다. 다른 종류의 기존 알림과는 별개입니다.
- 오늘 직접 돌봤다면 오늘의 고양이 소식 예약을 취소합니다. 보관함의 사료·츄루·브러시 사용도 돌봄으로 기록합니다.
- 날짜별 메시지를 번갈아 예약하며, 실제 생물학적 배고픔이나 건강을 추정하지 않습니다.
- 미래 최대 7개의 알림만 일회성으로 예약합니다. 오랫동안 앱에 돌아오지 않으면 더 이상 반복하지 않습니다. 다시 방문하면 예약을 갱신합니다.
- 이미 예정 시각이 지난 날은 전달된 것으로 보수적으로 취급합니다. 시간을 바꾸거나 껐다 켜도 같은 날 재발송하지 않습니다.
- 오늘의 돌봄 기록과 첫 밥·첫 놀이 기억은 저장됩니다. 여러 번 돌봐도 성장일은 하루 한 번만 쌓이고, 쉬었다고 감소하지 않습니다.
- 이름 변경 시 앞으로 예약된 알림의 이름도 갱신합니다.
- 기기별 알림 동의와 발송 이력은 개인 기록 백업에 포함하지 않습니다.
- Android는 부정확 알람을 사용하므로 절전 상태 등에서 지정 시간보다 늦게 전달될 수 있습니다. 정확한 알람 권한은 새로 요구하지 않습니다.
- 기존 로그인·결제·Firebase·서명·패키지·이웃 알림은 유지합니다. 새 이미지나 오디오 파일은 추가하지 않습니다.

## 구현과 검증

- `CompanionReminderSettings`, `CompanionInvitation`, 순수 일정 생성 함수로 동의·payload·시간대·일일 제한을 분리했습니다.
- 기존 NotificationService의 직렬 처리 안에서 설정 저장·예약·취소를 수행합니다. 실패 시 이전 설정으로 되돌리며, 네이티브 취소 성공 전에는 OFF로 표시하지 않습니다.
- 알림 ID 2200~2207만 다룹니다. 다른 알림을 일괄 삭제하지 않습니다.
- 돌봄 저장과 알림 큐가 완료된 호출 영역을 계속 참조하지 않도록 정리했습니다. 동시 작업 순서는 유지합니다.
- 자동 테스트에서 권한 거절, 예약 실패, 설정 변경 경쟁, 당일 재발송 방지, 앱 재개, cold/warm payload, 저장·성장 유지, 보관함 소모품, 360/390px 및 큰 글씨 조작을 확인합니다.
- 빌드 검증 결과는 배포 파일과 함께 제공하는 Verification JSON을 기준으로 합니다.

## 실제 휴대전화에서 확인할 항목

1. Play 내부 테스트로 업데이트 후 로그인·구독이 유지되는지 확인합니다.
2. 오늘 아직 돌보지 않은 테스트 상태에서 알림을 켜고, 허용 시간 내 현재보다 3~5분 뒤로 지정합니다. 이미 돌봤거나 오늘 발송 시각이 지났다면 다음 날부터 대상입니다.
3. 앱을 배경으로 보낸 뒤 알림 도착과 탭 시 돌보기 화면 이동을 확인합니다. Android 강제 종료는 사용하지 않습니다.
4. 밥/놀이 후 정원과 마음 돌보기에서 같은 이름·성장일·첫 기억을 확인합니다.
5. 알림을 끈 뒤 후속 고양이 소식이 오지 않는지 확인합니다.

실제 기기에서의 OS 알림 전달, Play 업데이트 및 실결제는 자동 테스트만으로 보증하지 않습니다.
