# 마음냥 정원 · 사용 흐름과 저장 안정성 정리 (누적 v5)

## 이번 변경

1. 고요 모드에서 감정 강도는 미선택 상태로 시작합니다. 아무것도 고르지 않으면 null로 저장하며, 통계에 임의의 보통(3점)을 넣지 않습니다. 선택 해제도 가능합니다. 메모·강도를 작성하고 닫으면 확인하고, 심기·저장 중에는 뒤로가기를 막습니다. 실패 후 재시도는 같은 세션 ID와 내용을 유지합니다.
2. 아침·저녁 알림은 기기 예약/취소와 설정 저장을 직렬화했습니다. 예약/저장 실패를 성공으로 숨기지 않고 이전 상태 복원을 시도합니다. 초기화 실패 후 재시도할 수 있으며, 설정 화면은 연속 탭을 막고 성공 후 시간을 갱신합니다. 재방문·돌봄 알림은 켜는 즉시 예약하며, 답장 알림도 실패와 권한 거부를 표시합니다. OS 예약과 설정 저장은 하나의 트랜잭션이 될 수 없어, OS 자체 장애 시 복원이 실패할 가능성은 남습니다.
3. 3일 미접속 알림을 위험 감지처럼 보이게 하던 '위기 알림' 표시를 '다시 쉬어가기'로 바꿨습니다. 고양이가 외롭다는 부담을 주는 문구도 쉬어가기 안내로 완화했습니다. 기존 저장 키/알림 ID는 유지합니다. 미접속만으로 정신건강을 진단하지 않습니다.
4. 명상 후 기분은 암호화 Hive 저장으로 이전합니다. 전체 레거시 목록 검증 → 누락 항목 복사 → flush → 평문 삭제 순서입니다. 손상된 원본은 조용히 버리지 않습니다. 같은 세션 후기를 덮어쓰지 않습니다. 최근 90개를 접힌 목록에서 다시 보고 개별 삭제할 수 있으며, 삭제해도 정원 성장·완료 보상은 바꾸지 않습니다. 90개를 넘어선 기존 암호화 기록은 자동 삭제하지 않습니다.
5. 명상 후기를 암호화 백업 대상에 추가하고, 즐겨찾기·최근 목록·과정 진행 설정도 포함합니다. 후기 ID·내용 및 명상 과정 구조를 복원 전에 검증합니다. 현재 기기의 명상 설정이 있으면 가져온 설정으로 덮어쓰지 않습니다. 이전 백업 파일에 삭제된 후기가 남을 수 있다는 안내를 유지합니다.
6. 정원 도감에서 만나러 이동할 때 하위 카드와 기록·활동 도구창을 닫습니다. 오래된 `MongiLobbyScreen`은 현행 `MongiExperience`로 연결하는 호환 진입점으로 정리했습니다. 외부 호출 호환을 위해 클래스는 남겼습니다. 사용되지 않는 별도 `MongiPlayScreen` 파일은 삭제하지 않았습니다.
7. 자기돌봄 후기 수정 중 뒤로가기를 확인하고 저장 중 이탈을 막습니다. 명상 목록과 알림 설정의 불러오기 실패도 다시 시도할 수 있습니다.

## 미실행과 남은 확인

**Flutter analyze/test, 웹·APK 빌드 및 실기기 검증은 수행하지 못했습니다.** 설치된 Flutter SDK가 없으며 SDK/목록 다운로드 요청은 HTTP 404, 미러 목록은 HTTP 403을 반환했습니다. Dart 구문 검사는 Flutter 컴파일이나 UI 조작 검증을 대체하지 않습니다.

추가·수정한 Flutter 회귀 테스트는 미실행입니다. 명상 후기 암호화 이전/백업 복원/손상 원본 보존, 고요 모드 저장 중 뒤로가기/재시도, 자기돌봄 후기 이탈 확인을 다룹니다. 실제 암호화 저장·OS 알림은 이 검증이 필요합니다.

적용 후 Flutter 환경에서 한 번씩 실행:

```sh
python3 tool/verify_refinement.py --web
# 출시 검증에서 전체 테스트가 필요하면 위 명령 대신:
python3 tool/verify_refinement.py --full --web
```

오류가 나면 다음 단계와 빌드를 중단하고 `verification/flutter-refinement/` 로그를 남깁니다. 전체 테스트의 과거 실패 개수는 현재 결과의 허용 기준으로 사용하지 않습니다. 서버 재가동·배포는 하지 않습니다.

360/390px 및 큰 글씨에서 확인할 실제 흐름:
- 고요 모드: 미선택 완료, 메모 입력 후 뒤로가기, 저장 실패 후 재시도, 앱 복귀.
- 명상: 구버전 후기 이전, 접힌 후기 목록 열기/스크롤/삭제, 백업 → 새 기기 복원.
- 알림: 권한 거부, 켜기/끄기/시각 변경, 실제 시간 도착, 앱 종료 상태에서 탭. 현재 시간대는 기존 정책인 한국 시간(KST)을 유지합니다.
- 정원: 도감 → 고양이 만나기, 도구창 잔류 여부, 움직임 켜기/끄기, 일시정지/복귀.
- 실제 폰 간 응원·선물, 서버 접근권한, 결제·복원·해지, iOS/Android 종료·복원 동작은 별도 출시 검증 대상입니다.
