# 마음냥정원 — 기록에서 정원으로

## 이번 변경
- 편지 저장 직후 선택 명상 화면, 완료 화면, 첫 기록 온보딩에서 현재 기억의 나무와 다음 시각적 성장까지 남은 기록 일수를 표시하고 넓은 정원으로 연결한다. 별도 자동 팝업이나 강제 명상을 추가하지 않는다.
- 넓은 정원과 공개 정원의 나무 단계는 기존 MongiGardenStore recordDays 누적 성장 기록을 사용한다. 정원 진입 및 공개 전 현재 편지와 정합성을 맞춘다. 같은 날짜를 여러 번 쓰거나 삭제 후 다시 써도 중복 성장하지 않는다.
- 일반 편지 삭제 전 기존 편지 날짜의 성장 기록 저장을 완료한다. 이 저장이 실패하면 삭제를 진행하지 않으며 화면에서 재시도를 안내한다. 삭제 성공을 기다린 후 화면을 닫는다.
- 날짜별 편지 열람은 현재 보관된 원문만 읽는다. 성장 기록은 날짜만 유지하며 삭제된 본문이나 감정을 복사하지 않는다. 이미 삭제되어 어느 저장소에도 남지 않은 과거 기록은 복구하지 않는다.
- 성장 정보는 기존 정원 스냅샷 및 기존 백업 경로를 그대로 사용한다. 별도 저장소/서버 필드 없음. 공개 정원에는 기존처럼 나무 단계만 전달한다.
- 실제 나무 이미지가 변하는 1·3·6일에 맞춰 다음 변화 안내를 작성한다. 6일 이후에는 없는 이미지 단계를 약속하지 않는다. 내부 공개 단계 0~4 호환성은 유지한다.
- 첫 기록 입력창을 3줄로 줄이고 자동 키보드 노출을 해제한다. 감정만 남기기 안내 및 기록 건너뛰기를 제공한다. 기존 이름 정하기 저장소를 그대로 사용한다.
- 일반 기록 화면에서 초안을 지우지 않고 정원에 쉬러 갈 수 있다. 첫 만남 배너를 고양이 수집 수 대신 부담 없는 환영 문구로 바꾼다.
- 응원 꽃 목록에 실제 수신 날짜와 꽃 소식 전달 대기 상태를 표시한다. 과거 수신 날짜가 없는 기록에는 날짜를 지어내지 않는다. 꽃 소식의 서버 전달 로직은 변경하지 않았다.
- 구독 설명은 정원 장식과 이야기를 먼저 보여준다. 기존 가격/권한/무료 범위는 그대로이며 오프라인 클래스가 현재 구독 혜택이 아님을 표시한다.
- 기록 삭제 후 남는 성장 날짜에 대해 앱 내 정보 보관 안내를 보완했다.

## 검증 결과와 한계
- 직접 Dart 실행: tool/check_garden_record_progress.dart 8개 검사 통과(같은 날 중복, 삭제/직렬화 복원, 재작성, 다음 날 성장, 미래 날짜, 시계 보정, 실제 이미지 단계 안내).
- 백엔드 node --test 46개 통과. 응원 심기 중복 방지, 소유자 검증, 24시간 만료, 공개 데이터 비공개 항목 제외 등 포함. 실제 운영 계정 간 전송을 수행한 것은 아니다.
- 변경 Dart 소스 포맷/구문 검사 완료. flutter_lints 의존성을 찾을 수 없다는 경고가 있으므로 정적 분석 또는 빌드 통과를 의미하지 않는다.
- test/mongi_garden_data_test.dart에 실제 정원 데이터 모델의 삭제 후 유지/재작성/다음 날 성장 회귀 검사를 추가했으나, Flutter 테스트 실행은 미완료다.
- 최신 Flutter 전체 빌드·실기기·UI 렌더·결제·백업 실제 복원은 미검증이다. 이전 의존성 설치가 클라우드 메타데이터 접근으로 자동 승인 검토에서 거절되었으며 같은 작업을 재시도하거나 우회하지 않았다.
- 기존 서버 변경은 운영 배포되지 않았다. 실제 두 계정 응원 및 꽃 소식은 서버 배포 후 확인해야 한다.

## 실제 기기에서 이어서 확인할 항목
1. 처음 설치: 이름 지정 → 한 줄 또는 감정 기록 → 나무 안내 → 정원 → 원문 열람. 기록 건너뛰기도 별도로 확인.
2. 같은 날 여러 편지 저장 → 앱 재실행 → 하나씩 삭제 → 전부 삭제 → 같은 날 재작성 시 나무 단계가 줄거나 중복 증가하지 않음.
3. 다음 날 기록 시 누적 성장, 기존 백업 복원 후 보존. 삭제된 원문은 나무 목록에서 보이지 않음.
4. 두 실제 계정에서 꽃 수신/심기/전달 대기/재접속/꽃 소식 1회 수신, 비공개 원문 미노출.
5. 작은 화면 및 큰 글자에서 새 카드·긴 응원 날짜·구독 안내가 잘리지 않음. 정원 휴식 후 복귀 시 작성 중 초안 유지.
