# 마음냥 정원 1.0.23+26 — 달력 예약

## 사용 방법

운영자: 정원소식 작성/수정 → 종류 '이벤트' → 예약 날짜 추가 → 달력에서 날짜 선택 → 시작·종료 시간을 숫자로 입력 → 모집 정원 입력 → 날짜와 시간 저장 → 정원소식 작성하기/수정 완료.

- 시간은 24시간 기준이다. 오후 2시 30분은 시작 시에 14, 분에 30을 입력한다. 시계 바늘 화면은 사용하지 않는다.
- 보통은 같은 날 종료한다. 날짜가 넘어가는 일정은 종료 날짜를 달력에서 따로 고를 수 있다.
- 기본 신청 기간은 게시 후 바로 시작하고 모임 시작 시간에 마감한다. 신청 시작일/마감일, 일정 이름, 신청 상태는 '추가 설정'에서 관리한다.
- 날짜와 시간 저장은 편집 중인 소식에 일정을 추가한다. 소식의 작성하기/수정 완료를 눌러야 서버에 공개된다.

참여자: 정원소식 → 달력에서 일정이 있는 날짜 선택 → 숫자로 표시된 가능한 시간 선택 → 신청하기 → 날짜·시간 확인 후 신청 확인.

- 운영자가 실제 등록한 일정만 예약할 수 있다. 정원 마감/신청 전/취소/마감 시간은 선택할 수 없다.
- 다른 날짜를 누르면 이전 날짜의 시간 선택이 해제된다. 예약 확인창에 최종 날짜와 시간을 표시한다.
- 신청 후에는 선택한 일정과 신청 완료 상태, 취소 버튼을 표시한다.
- 날짜가 없는 기존 공지는 기존 방식대로 유지된다. 기존 공지에 날짜를 등록하려면 운영자가 일정을 추가해야 하며, 기존 신청자가 있는 일정의 변경 제한은 유지된다.

## 데이터 및 배포

- 기존 sessions/sessionId API와 서버의 좌석·마감 검사를 그대로 사용한다. 이번 버전은 서버 변경 및 재배포가 필요 없다.
- 기존 신청자의 일정 ID, 시작/종료 시각, 예약 인원을 유지한다. 신청자가 있는 일정은 날짜/시간 변경과 인원 이하의 정원 축소를 막는다.
- 카카오 로그인, App Check, 결제, 패키지명, Firebase 설정은 변경하지 않았다.
- AAB 1.0.23(26)을 내부 테스트에 업로드한 뒤 앱을 업데이트한다. 실제 운영자 저장·다른 계정 신청·취소 확인은 기기에서 진행해야 한다.

## 검증 범위

- 달력 날짜별 시간 표시, 마감된 시간 차단, 날짜 변경 시 이전 시간 해제.
- 360px/확대 글씨에서 숫자 시간 입력과 저장, 잘못된 시·분 및 종료 순서 차단.
- 기존 예약 일정의 정확한 시각/ID/인원 보존, 접힌 추가 설정의 잘못된 시간 차단.
- 달력에서 최종 선택한 일정 ID가 예약 API로 전송되는지 및 예약 성공 표시.
- 전체 테스트와 최종 AAB의 검증 결과는 함께 제공하는 검증 기록을 참조한다.
