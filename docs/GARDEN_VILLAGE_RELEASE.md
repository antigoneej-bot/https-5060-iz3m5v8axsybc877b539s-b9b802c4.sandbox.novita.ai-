# 냥이 마을 업데이트 — 1.0.13+16

## 이번 소스에 구현된 흐름

나의 정원 상단의 **냥이 마을**에서 **내 이웃 / 둘러보기 / 받은 마음**으로 이동합니다. 큰 3D 마을이나 홈 화면 개편은 추가하지 않았습니다.

- 내 초대 코드를 복사·공유하거나 상대 코드를 입력해 이웃을 신청합니다. 상대가 수락해야 내 이웃이 됩니다. 코드만 안다고 비공개 정원이 열리지는 않습니다.
- 정원 공개 범위는 비공개·이웃 공개·전체 공개입니다. 둘러보기 목록 노출은 별도 동의가 필요합니다. 기존 공개 정원도 목록 노출에 자동 동의하지 않습니다.
- 방문 화면은 상대가 저장한 정원 스냅샷을 읽기 전용으로 표시합니다. 편지 본문·감정 통계·개인 기억 메모는 공개하지 않습니다. 정원 배치 변경은 공개 설정 화면에서 다시 저장해야 반영됩니다.
- 응원은 하트·별·포옹·나비 4종이며 정원 표시가 24시간 지속됩니다. 기록은 받은 마음에서 확인합니다. 무료 응원에는 심을 꽃이 생기지 않습니다.
- 수락된 이웃에게 데이지·튤립·수국·안개꽃·라벤더 중 오늘의 꽃을 무료로 보낼 수 있습니다. 응원과 오늘의 꽃은 각각 상대별 한국 날짜 기준 하루 한 번입니다.
- 보관한 꽃 선물은 서버가 확인한 **받은 꽃 중 아직 심지 않은 꽃**만 옮깁니다. 성공하면 원래 보관함에서 빠집니다. 내 기기에만 저장된 씨앗·재화·유료 상품은 전송 대상이 아닙니다.
- 꽃에는 보낸 사람과 받은 날짜가 남습니다. 탈퇴한 보낸 사람의 이름은 다음 서버 동기화 때 익명 처리됩니다. 응원과 선물 목록은 최근 항목 중심이며 전체 무제한 기록 조회 기능은 아닙니다.
- 이웃 제거·차단·차단 해제·신고·선물 수신 끄기를 제공합니다. 신고는 운영자 검토용 접수이며 자동 제재나 운영자 푸시 알림은 구현하지 않았습니다.

## 데이터 처리

새 꽃 심기는 서버 확인 후 로컬 정원에 반영되므로 인터넷 연결이 필요합니다. 다른 기기에서 같은 꽃을 심거나 옮기는 동작이 함께 성공하지 않도록 서버 트랜잭션으로 처리합니다. 응답을 못 받은 뒤 같은 요청을 재시도해도 중복 선물이 생성되지 않습니다.

계정이 바뀌면 이전 계정의 진행 중 응답을 버립니다. 전송 완료한 원본 꽃은 로컬에도 이전 표시를 남겨 늦게 도착한 목록 응답으로 되살아나지 않게 했습니다. 일시적인 차단·조회 불가는 전송 완료로 간주하지 않습니다.

## 적용·배포 순서

1. 기존 프로젝트를 백업한 뒤 패치의 해시 검사를 실행합니다. 현재 작업본이 기준 소스와 다르면 자동 적용을 중단하고 해당 변경을 병합합니다. 전체 소스 덮어쓰기로 별도 작업을 없애지 마세요.
2. Android 서명키, 기존 Firebase 프로젝트 설정·비밀값, 로그인 제공자 설정을 유지합니다. 기존 빌드의 `GARDEN_BACKEND_URL` 등 실행 설정도 유지해야 합니다.
3. 올바른 기존 Firebase 프로젝트를 선택한 상태에서 `firebase deploy --only firestore:indexes`를 실행합니다. 추가된 collection-group 인덱스 3종이 준비될 때까지 기다립니다. 계정 삭제 정리에 필요합니다.
4. 그 뒤 `firebase deploy --only functions:gardenApi`로 변경된 정원 API를 배포합니다. 현재의 인증·App Check·Firestore/Storage 접근 제한을 풀지 않습니다. 세부 계약은 `backend/village-api.md`를 참고합니다.
5. `flutter pub get`, 분석·테스트 후 기존 배포 설정으로 Android APK/AAB를 새로 빌드합니다. 버전은 `1.0.13+16`입니다. 이미 더 높은 버전 코드를 사용 중이라면 그보다 높여야 합니다.
6. 새 APK를 서로 다른 실제 계정의 두 기기에 설치해 아래 흐름을 확인합니다. 이전 APK에는 이번 화면이 나오지 않습니다.

코드 공유는 텍스트 복사·시스템 공유 방식입니다. 앱 자동 실행 초대 링크나 QR 코드는 이번 범위에 포함하지 않았습니다.

## 두 기기에서 확인할 흐름

| 확인 | 기대 결과 |
|---|---|
| A 코드 입력 → B 신청 → A 수락 | 양쪽 내 이웃 목록에 나타남 |
| 비공개 → 이웃 공개 → 전체 공개, 목록 노출 별도 설정 | 허용한 사람만 방문하고 별도 동의한 정원만 둘러보기에 나타남 |
| B가 A에게 응원과 오늘의 꽃 보내기 | A의 받은 마음에 각각 도착, 응원만 보냈을 때 꽃이 생기지 않음 |
| A가 꽃 심기 | 정원과 보관함 상태 반영, 보낸 사람·날짜 확인 |
| A가 미심기 꽃을 B에게 선물, 같은 요청 재시도 | 한 번만 이동, A 원본 제거, B에게 한 송이 도착 |
| 같은 꽃을 두 기기에서 동시에 심기·선물 | 둘 중 하나만 성공 |
| 선물 수신 끄기 / 차단 / 이웃 제거 | 상대 동작에 즉시 권한 제한 반영 |
| 로그아웃 → 다른 계정 로그인 | 이전 계정의 이웃·응원·진행 중 결과가 새 계정에 나타나지 않음 |
| 계정 삭제 | 초대·이웃 관계 제거, 다른 사람에게 남은 선물의 보낸 사람 익명화 |

## 검증 범위

이 소스의 자동 테스트·분석·웹 빌드 결과는 배포 ZIP의 검증 파일과 전달 보고에 기록합니다. 실제 Firebase 배포, 실제 기기 두 대 통신, 서명 APK/AAB 생성 및 스토어 제출은 이 환경에서 수행하지 않았습니다. 서버 설정이 없는 웹 미리보기나 테스트의 가상 계정 응답을 실제 연결 성공으로 간주하지 않습니다.
