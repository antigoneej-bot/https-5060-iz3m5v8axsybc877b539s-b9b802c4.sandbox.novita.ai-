# 마음냥 정원 1.0.55 (58)

명상 · 힐링에 아래 기존 기능을 연결했습니다.

- 마음 버블 정원
- 고요하게 마음 마주하기
- 혼자 읽는 응원 모음
- 감사 한 줄 · 작은 성취
- 하루 닫기

홈의 ‘명상 · 힐링’ 또는 마음돌보기 페이지의 ‘명상 · 힐링’에서 찾을 수 있습니다. 전체 기능 목록에도 ‘명상·힐링’ 분류를 적용했습니다. 힐링 메뉴 박스에는 제목만 표시합니다.

기존 호흡·명상 선택과 재생 구성은 변경하지 않았습니다. 응원은 앱에서 준비한 문구이며 이웃이 보낸 메시지가 아닙니다. 감사·성취와 버블 기록은 기존 저장소를 그대로 사용합니다. 고요하게 마음 마주하기에서 감정을 선택하는 것만으로 기록을 만들지 않습니다.

추억 카드의 바로가기는 힐링 화면에서 제외했으며 기존 수집·교환 화면과 다른 메뉴의 연결은 유지합니다. 말씀 콘텐츠는 추후 추가 계획으로만 남겨두었으며 이번 버전에는 들어 있지 않습니다.

- 기존 Play Console 테스트 트랙에 Mindnyang-1.0.55-58-TestOpen.aab 업로드

- 이번 변경은 앱 메뉴 연결이며 Google Cloud 재배포 불필요
- 실제 Play 업로드 및 실기기 테스트는 수행하지 않았습니다.
