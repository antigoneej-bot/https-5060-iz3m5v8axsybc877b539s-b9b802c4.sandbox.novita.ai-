마음냥 정원 v76 · 사용성 수정 소스 (2026-11-02)

이 ZIP은 사용자가 올린 1.0.73+76 전체 소스에 수정한 소스입니다.
새 APK/AAB가 아닙니다. 버전과 서명 설정을 변경하지 않았습니다.
이전 문서의 Flutter 테스트·빌드 성공 기록은 원본 시점 결과이며 이번 수정본의 결과가 아닙니다.

반영 항목
1. 내 식물 목록과 선택 카드에 ‘위치 옮기기’ 추가. 유효한 땅을 선택하고 확인할 때 좌표만 저장합니다. 씨앗 수·성장 단계는 변경하지 않습니다.
2. 색칠/이동 전환을 상시 표시. 두 번째 손가락 입력 시 진행 중 붓질을 취소합니다. 이동 모드에서는 색칠하지 않습니다. 일반·전체화면 모두 도구 접기/펼치기를 지원합니다.
3. 산책 기본 이동 속도 180→250, 보물 속도 220→320. 위·아래·기본·물결 경로를 추가했습니다. 보물은 고양이 근처에서 획득 가능한 높이에 도달합니다. 기존 시간·보상 상한은 유지합니다.
4. 주간·월간 만화책은 기존 편지와 정원 일기 실제 기록으로 구성됩니다. 기간별 요약, 기록 전체 페이지 분할, 빈 기간을 코드로 확인했습니다. 새 실행 검증은 하지 못했습니다.
5. 캘린더 날짜에 기록된 감정 고양이를 표시합니다. 편지는 저장된 고양이 ID를 그대로 사용하고, 정원 일기는 기존 감정에 대응하는 고양이 그림을 사용합니다. 반려묘 6종 외형과 감정 카드 고양이는 별개입니다.
6. ‘나의 마음 보관함’에 캘린더/고양이 카드 전환, 월별/전체 기록, 감정 필터, 원문 보기, 만화책 연결 추가. 기존 저장 데이터를 읽으며 기록을 복제하지 않습니다. 알 수 없는 옛 감정은 발바닥 아이콘으로 표시합니다.
7. 메인 네 페이지의 좌우 넘김을 복원했습니다. 내장 정원의 카메라 제스처는 끄고 가로 전체보기에서 이동·확대를 사용해 페이지 넘김과 충돌을 줄였습니다.
8. 일일 미션 수령 표시와 정수·별조각 지급을 하나의 복구 가능한 저장 거래로 통합했습니다. 저장 중단·중복 수령 테스트를 추가했습니다. 모든 기능에 새 보상을 임의로 추가하지는 않았습니다. 아래 보상 조사 참고.
9. 데이지·튤립·해바라기 화분, 고양이 방석, 초승달 조명, 새집 6종 추가(기존 13종→19종). 기존 구매·배치·보관 흐름 사용. 정원에 꾸미기 진입 버튼 추가.
10. 정원 전체보기는 별도 가로 화면으로 열립니다. 두 정원 모두 지원하며 카메라 이동·확대, 도구 접기/펼치기, 돌아올 때 세로 복원을 연결했습니다. 전체 정원의 비율을 유지하므로 화면 비율에 따른 여백은 가능합니다.
