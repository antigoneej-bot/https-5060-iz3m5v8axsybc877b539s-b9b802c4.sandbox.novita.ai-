삭제 정보 최소화 변경 및 복구 계획

적용 전 기준: a0cc3df, 작업 브랜치 finish-release-69.
범위: 사용자가 서버 계정 삭제를 명시적으로 요청한 경우에만 socialAuthIdentities 문서의 uid 필드를 지움.
유지: 해시 문서 키, 제공사, generation, 계정 삭제 방지 표식. 소셜 로그인은 uid 필드가 아닌 해시 키와 generation으로 UID를 계산함.
영향 없음: 활성 계정, 기기 감정 기록·편지, 기존 백업 형식, 정원/고양이/구독 혜택.
기존 사용자 대상 일괄 마이그레이션이나 기존 삭제 계정 데이터 정리는 실행하지 않음.
배포 전: 기존 배포 소스와 리비전을 백업하고 Auth/DB 설정 대조. 이번 수정은 아직 운영 서버에 배포하지 않음.
복구: 수정 이전 서버 코드로 복구 가능. 기존 로그인 코드도 uid 필드를 읽지 않고 키·generation으로 계산하므로 uid가 없어도 재가입 분리가 유지됨.
주의: 삭제 상태·세대·구매 표식을 일괄 만료시키면 이전 계정이나 구매가 재연결될 위험이 있어 임의 TTL을 추가하지 않음.
검증: 실제 API 핸들러 테스트에서 대상 UID 제거·다른 계정 보존·삭제 재시도, 소셜 로그인에서 UID 없는 연결 문서의 재가입 세대 분리 확인.
