남은 외부 의존성
- Firebase 공식 연결은 제안했으나 연결 완료는 미확인. 연결 후 실제 서버 설정·계정 삭제·규칙·배포 소스 대조 필요.
- Play Console 자동 접속이 승인 검토에서 거절됨: play.google.com 요청과 google.play 감지 주소 불일치. 우회하지 않음. 콘솔 URL 입력/정식 출시 제출은 변경되지 않음.
- 공개할 개인 운영자 실명/개인정보 담당자명은 미확인. 사업자명·사업자번호를 만들지 않음.
- 제공사별 실제 계약/국외 이전, 운영 로그·문의 보유기간, 이메일 삭제 처리기한은 검증되지 않음.
- 남은 최소 삭제 표식은 무기한 TTL 미설정 상태. 임의 만료는 이전 구매/삭제 계정 재생성 위험이 있으므로 보관 근거·기간과 안전 전환안을 확정해야 함.
- 최신 운영 버전 코드, 기존 업로드 서명, 실제 구독·환불·복원 및 실기기 업그레이드 결과는 기존 테스트를 이어서 대조해야 함.
