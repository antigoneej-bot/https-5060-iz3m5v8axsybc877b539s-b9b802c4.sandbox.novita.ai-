마음냥 정원 1.0.79+82 · 이웃 디자인 검증본

첨부 82번을 검증된 80번의 별도 브랜치에 적용했습니다.
원본 ZIP과 이전 80번 소스·APK/AAB는 보존했습니다.
원본 START-82-KO.txt와 review82는 작성자 참고 자료이며 이번 실행 결과가 아닙니다.
이번 실행 결과·점검표·캡처·영상·파일 해시는 ZIP 루트 review/에서 확인하세요.

보완
- 보낸 선물 탭에서 새로고침 시 새 이력을 다시 조회합니다.
- 모두 받기 도중 성공한 항목은 후속 목록 조회가 실패해도 재요청하지 않습니다.
  실제 지급은 기존 서버/Provider가 담당하며 화면에서 재화를 만들지 않습니다.
- 계정 전환(원래 계정으로 돌아오는 경우 포함)·화면 종료 시 후속 수령을 중단합니다.
- 홈 인사말은 얼굴 위 대신 고양이 아래 안내 공간에 표시합니다.
- 새 위젯 검사의 저장 완료·종료 처리를 실제 완료 조건에 맞추고 캡처 경로를 이식 가능하게 보완했습니다.

보존
5페이지, 선택한 6종 동반묘·이름·성장·눈 깜박임, 기존 정원·개인 기록·재화·좌표·백업을 유지합니다.
81/82번의 산책 속도·홈 하트 인사·새 신청/선물함 디자인을 유지합니다.
구독 가격·상품 ID·권한·로그인·서명 키를 바꾸지 않았습니다.
내부 테스트 전체 개방 유지: UNLOCK_ALL_PREMIUM=true, APP_CHECK_DEBUG_PROVIDER=false, RELEASE_ENV=internal.
이는 실제 유료 구매·복원 성공을 뜻하지 않습니다.
새 카드 그림은 공통 일러스트이며 상대가 선택한 실제 고양이라고 주장하지 않습니다.

서버 변경은 미배포
보낸 선물 이력에는 gardenApi의 새 listSentGardenGifts 경로와 발송 이력 기록,
탈퇴 시 익명화/정리, sentGardenGifts.recipientId 컬렉션 그룹 인덱스가 필요합니다.
새 서버 반영 이후 발송부터 기록되며 과거 이력을 임의로 복구하지 않습니다.
이번 작업은 서버·인덱스를 배포하거나 스토어에 업로드하지 않습니다.
구 서버에서는 보낸 선물 탭에 오류/재시도를 표시합니다.
모두 받기는 불러온 페이지 대상이며 서버 요청 제한·네트워크 실패 시 일부만 완료될 수 있습니다.
실제 두 계정 왕복과 운영 인덱스 준비는 별도 검증해야 합니다.

빌드

Play 설치본과 업로드 키 APK의 인증서가 다를 수 있습니다. 서명 불일치를 앱 삭제로 해결하지 마세요.
